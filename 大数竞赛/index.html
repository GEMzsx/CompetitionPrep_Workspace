怎么用

1

本地复习

克隆或下载本仓库后，双击 index.html 即可离线使用 —— 公式渲染内置 MathJax 本地文件，不依赖网络。

2

在线访问

仓库推送至 GitHub 后，在 Settings → Pages 选择 main 分支开启 GitHub Pages，即可获得在线地址，手机也能看。

3

打印成册

任意知识框架页支持 Ctrl+P 打印 / 导出 PDF，导航栏自动隐藏，排版已做打印优化，考前突击直接打一沓。
