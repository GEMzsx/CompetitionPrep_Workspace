阶段 1 · 第 7 课 · 2026-10-20

非正弦周期电流电路

傅里叶级数、谐波分析、有效值与功率的谐波合成 —— 电网"电能质量"的理论底座，南网特色考点。正弦是理想，非正弦是现实；但傅里叶保证：再丑的周期波形，都是正弦波的合唱团。

预计 2 小时 依赖：阶段0 第2课（相量）、第2课（叠加）、第5课（谐振） 电网谐波理论 · 笔试中频

1本课核心思想：老工具打新怪

前面所有课都在处理单一频率正弦。但真实电源和信号千奇百怪：方波（逆变器输出）、整流波（充电器）、含尖峰的畸变波（带电力电子负载的电网）。周期性非正弦信号怎么办？

傅里叶级数给出神谕：任何满足狄里赫利条件的周期函数，都能展开成"直流 + 一堆不同频率正弦波"的叠加。于是新问题瞬间变成旧问题——电路的世界观再次升级：

方法论三件套（全部是学过的）：① 傅里叶分解电源 → ② 对每次谐波单独用相量法（叠加定理的频率版）→ ③ 瞬时值叠加各次响应。本课不引入任何新定理，学的是"组合拳"。
南网视角现代电网充满谐波源（变频器、开关电源、电弧炉、光伏逆变器），"电能质量"是供电局天天面对的指标——谐波限值（GB/T 14549）、滤波器设计、谐波治理都是行业日常。本课概念题在南网笔试稳定出现，且通向高电压、电力电子专业课。

2傅里叶级数与谐波"成分表"

周期为 T 的信号 f(t)（基波角频率 ω₁ = 2π/T）的傅里叶展开：

f(t) = a₀ + Σk=1..∞ [ akcos(kω₁t) + bksin(kω₁t) ] a₀：直流分量；k=1 项：基波；k≥2 项：k 次谐波（频率为基波的 k 倍）

对称性 = 谐波"体检报告"（考试白送分）

对称性质数学表达谐波成分
偶对称（纵轴对称）f(−t) = f(t)只含余弦项（无正弦）
奇对称（原点对称）f(−t) = −f(t)只含正弦项（无余弦），无直流
半波对称（镜像对称）f(t ± T/2) = −f(t)只含奇次谐波（1、3、5…无偶次、无直流）

常见波形的谐波档案（记结论就行）

  • 对称方波：只有奇次谐波，幅度按 1/k 衰减（基波最强，5 次、7 次仍是麻烦制造者）
  • 三角波：只有奇次，按 1/k² 衰减（收敛快，波形越"圆滑"高次越少）
  • 半波整流：含直流 + 奇、偶次都有
  • 全波整流：含直流 + 只有偶次（2、4…次）
  • 尖峰越尖锐 → 高次谐波越丰富（尖脉冲的谐波谱可以拖得很长）
考法预警"某波形半波对称，问 2 次谐波分量是多少？"——答案是零，根本不用算系数。对称性判断题是白送分，半波对称 → 无偶次这条最常考。

3有效值：方均根合成（本课第一计算考点）

有效值定义是方均根（对完整周期），不同频率正弦的乘积在周期内积分平均为零，于是各次谐波"各自贡献、互不掺和"：

I = √I₀² + I₁² + I₂² + I₃² + … I₀ 为直流分量，I₁、I₂… 为各次谐波的有效值 —— "平方和开根"，缺谁少谁都不行

电压同理：U = √(U₀² + U₁² + U₂² + …)。注意——是有效值的平方相加；如果给的是振幅 Ak，先除 √2 再平方。

头号陷阱不同频率的正弦量不能相量相加（相量加法只对同频成立）。叠加只能用瞬时值，合成有效值只能用方均根。把 10∠0° + 3∠0°（不同次谐波）"加"成 13，是本课最经典的扣分姿势。

4功率：只有同频才有平均功率

瞬时功率 p(t) = u(t)·i(t)，求平均时"不同频率的乘积项"积分后消失（正交性），只剩同频配对的项：

P = U₀I₀ + U₁I₁cosφ₁ + U₂I₂cosφ₂ + … φₖ 是第 k 次谐波电压、电流的相位差 —— 每次谐波各自一套功率因数

三个衍生结论：

  • 直流只和直流配对：P₀ = U₀I₀（纯阻时 I₀ = U₀/R）
  • 电压有某次谐波、电流没有 → 该次功率为零（如纯电阻上，电容把 3 次谐波电流挡住了，3 次谐波电压再大也不产生功率）
  • 视在功率 S = UI（U、I 均为合成有效值），但此时 S² ≠ P² + Q²——多出一个"畸变功率 D"，功率三角形变成"功率四面体"。这是非正弦电路的标志性现象，概念题爱考

5分析流程三步走 + L、C 的"频率偏心"

非正弦电源激励下的稳态响应，标准流程：

  1. 分解：把激励展开为傅里叶级数（题目通常直接给各次分量，不用自己算系数）
  2. 逐频计算：对直流（L 短路、C 开路）和每次谐波（k 次角频率 kω₁）分别画电路、分别相量法求解。核心变化：
    XL(k) = kω₁L　　XC(k) = 1kω₁C
  3. 瞬时值叠加：把各次响应写回时域正弦表达式再相加——绝不能把不同次的相量直接相加

L 和 C 的"偏心"：滤波器的原理

  • 电感：XL = kωL 随 k 增大——"通低频、阻高频"（高频扼流圈；高频噪声被电感拦下）
  • 电容：XC = 1/(kωC) 随 k 减小——"通高频、阻低频"（旁路电容；纹波经电容入地）
  • 组合起来就是低通 / 高通 / 带通滤波器：整流器后面的平滑滤波（电容+电感）、通信线路的高频通道，原理全在此
谐波的谐振放大——电力系统真实事故原理第 5 课（阶段 0）学过：L、C 谐振频率 ω₀ 固定。若电网中恰好存在某次谐波（如 5 次、7 次）与系统电感电容组合谐振，该次谐波会被显著放大——电容器组烧毁、保护误动多源于此。所以电网装电容补偿时必须"躲开"谐波谐振点。这条链把"谐振 + 谐波"两个考点焊在了一起，南网面试也可能问。

6三相电路中的谐波：3 的倍数次是"零序家属"

对称三相电源本身只有基波，但变压器励磁电流、非线性负载会产生谐波。三相系统中谐波有个独特规律——3、6、9 次（3 的倍数次）谐波三相同相位（各相本就差 120°，3 次谐波把 3×120° = 360° 甩回同相）：

  • 3 的倍数次谐波 = 零序性质（呼应第 6 课对称分量法的"零序"）
  • 星形无中线：零序电流无通路 → 线电流中无 3 次；线电压 = 相电压之差，3 次同相互相抵消 → 线电压中永无 3 次谐波（线电压波形比相电压"更正弦"）
  • 三角形接法电源：3 次谐波在闭合三角内自成环流（外面测不到，但环流增加损耗——变压器用三角形接法"消化"3 次谐波）
  • 有中线时：3 次谐波全部涌入中线——中线电流可能比相线还大（谐波治理的现实痛点）
南网概念题素材谐波危害清单（背五条）：① 附加损耗使电机变压器发热 ② 电容器过载甚至谐振烧毁 ③ 继电保护误动/拒动 ④ 电能计量误差 ⑤ 通信干扰 + 精密设备死机。治理手段：滤波器（无源 LC / 有源 APF）、增加整流脉波数、Delta 接线隔离 3 次。出"多选题"时这份清单就是标准答案库。

7例题精讲（三道模板题）

例 1 · 有效值合成：先把"振幅"翻译成"有效值"

某支路电流 i(t) = [10 + 10√2·sin(ω₁t) + 3√2·sin(3ω₁t)] A。求电流有效值。

  1. 认清各分量：直流 I₀ = 10 A；基波有效值 I₁ = 10 A（振幅 10√2 除 √2）；3 次谐波有效值 I₃ = 3 A
  2. 方均根合成：I = √(I₀² + I₁² + I₃²) = √(100 + 100 + 9) = √209
  3. I ≈ 14.5 A
答：I = √209 ≈ 14.5 A

两步防错：① 振幅 → 有效值先除 √2（别把 10√2 直接平方）；② 直流项别忘（10² = 100 占了半壁江山）。合成的结果 14.5 比直觉的"10+10+3"小得多——方均根天然"稀释"。

例 2 · 逐频响应：一个电路、三套参数

RL 串联电路，R = 10 Ω，L = 0.1 H，电源 u(t) = [100√2·sin(100t) + 30√2·sin(300t)] V。求电流瞬时值与有效值。

  1. 基波单独作用（ω₁ = 100）：Z₁ = R + jω₁L = 10 + j10 Ω，|Z₁| = 14.14，∠−45°。İ₁ = 100∠0°/(10 + j10) = 7.07∠−45° A
  2. 3 次谐波单独作用（3ω₁ = 300）：XL 翻三倍 → Z₃ = 10 + j30 Ω，|Z₃| = 31.6。İ₃ = 30∠0°/(10 + j30) = 0.95∠−71.6° A
  3. 瞬时值叠加：i(t) = [7.07√2·sin(100t − 45°) + 0.95√2·sin(300t − 71.6°)] A
  4. 有效值：I = √(7.07² + 0.95²) = √(50 + 0.9) ≈ 7.13 A
答：i(t) = [7.07√2 sin(100t − 45°) + 0.95√2 sin(300t − 71.6°)] A，I ≈ 7.13 A

看懂数字背后的物理：3 次谐波电压虽达基波的 30%，但电感阻抗翻了三倍，3 次电流只剩基波的 13%——电感"欺软怕硬"地偏爱低频。这就是扼流圈原理的现场演示：加个铁芯电感，波形立即变干净。

例 3 · 功率合成：谁和谁配对

某负载端电压 u = [50 + 100√2·sin(ωt)] V，电流 i = [10√2·sin(ωt − 36.9°) + 2√2·sin(2ωt)] A。求平均功率。

  1. 清点配对：直流电压 50 V，但直流电流 = 0 → P₀ = 0（电压有直流、电流没有，配不上）
  2. 基波配对：P₁ = U₁I₁cosφ₁ = 100 × 10 × cos36.9° = 1000 × 0.8 = 800 W
  3. 2 次谐波：电流有 2 次（2 A 有效值），但电压无 2 次 → P₂ = 0
  4. 合计：P = 0 + 800 + 0 = 800 W
答：P = 800 W（只有基波在干活）

本题浓缩了功率合成的全部要点：同频才配对。直流电压配不上直流电流、2 次电流配不上 2 次电压——它们都"单相思"零功率。谐波电流在纯基波电压下流窜，不干活还制造损耗（线路 I²R 发热），这正是谐波"有害无功"的本质。

8限时练习（建议 20 分钟，做完再展开）

练 1有效值速算基础模板展开对答案 ▾
电压 u(t) = [100 + 80√2·sin(ωt) + 60√2·sin(2ωt)] V，求有效值。
U = √(100² + 80² + 60²) = √(10000 + 6400 + 3600) = √20000 ≈ 141.4 V

直流 100、基波 80、二次 60 勾股合成 141.4——顺手的数字提示这是"3-4-5"家族的放大版（60-80-100）。

练 2对称性判谐波概念题展开对答案 ▾
四个周期波形：① 原点对称且半波对称的方波；② 全波整流波形；③ 纵轴对称的三角波；④ 原点对称的锯齿波。问：哪些无直流分量？哪些只含奇次谐波？哪些含 2 次谐波？
无直流：①③④（凡原点对称必无直流）；只含奇次：①（半波对称）；含 2 次：②（全波整流只含偶次，2 次最强）和④（锯齿波奇偶次都有）。③纵轴对称三角波：只含余弦项、奇偶次兼有？——注意三角波半波对称仍只含奇次（三角波 f(t±T/2)=−f(t) 也成立），修正为只含奇次余弦。

判断顺序建议：先看半波对称（决定有无偶次）→ 再看轴对称（决定正弦还是余弦）→ 最后定直流。

练 3电容的"偏爱"反向题逐频响应展开对答案 ▾
RC 串联电路，R = 10 Ω，C = 100 μF，电源含 1、3 次谐波（ω₁ = 100 rad/s）：u = [30√2·sin(100t) + 10√2·sin(300t)] V。哪个谐波在电容上"更响"（分得电压比例更高）？
基波：XC1 = 1/(100×10⁻⁴) = 100 Ω → |Z| = √(10²+100²) ≈ 100.5，电容分压占比 ≈ 100/100.5 ≈ 99.5%。3 次：XC3 = 100/3 ≈ 33.3 Ω → |Z| = √(10²+33.3²) ≈ 34.8，电容分压占比 ≈ 33.3/34.8 ≈ 96%。答：基波在电容上分得比例更高——频率越高电容越"短路"，高频都被电容"漏掉"了。

电容与电感正好相反：XC 随 k 递减 → 高频畅通。本题的 RC 是高通滤波器雏形（电容输出端取高频），反过来从电阻端取输出就是低通——一个电路两种滤波，全看你从哪个端子引出。

9自测清单：全勾才算过关

  • 能写出傅里叶级数展开式，说清直流分量、基波、k 次谐波的定位
  • 能用对称性预判谐波成分（偶对称→余弦；奇对称→正弦无直流；半波对称→只含奇次），秒杀概念题
  • 能默写有效值方均根合成 I = √(I₀²+I₁²+…)，记得振幅先除 √2、直流别漏（例 1 全对）
  • 能默写功率配对公式 P = U₀I₀ + ΣUkIkcosφk，说清"同频才配对"、S² ≠ P² + Q² 的畸变功率
  • 会逐频分析三步法（分解 → 逐频相量法，XL=kωL / XC=1/(kωC) → 瞬时值叠加），知道不同频相量不能相加
  • 能说清三相谐波特性（3 的倍数次零序、线电压无 3 次、三角环流）与谐波危害五条清单，限时练习 3 题全对
