阶段 1 · 第 4 课 · 2026-10-16

二阶动态电路

RLC 暂态的过阻尼 / 临界阻尼 / 欠阻尼三种形态 —— 一阶的续集，振荡的起点。三要素法在这里失效，但换来一个更深的视角：电阻到底"阻"的是什么。为第 6 课谐振深化和电力系统暂态打底。

预计 2 小时 依赖：第 3 课（换路定则、初值） 期末中频 · 振荡直觉

1本课核心思想：两个储能元件，一场"能量拔河"

第 3 课的一阶电路里只有一个储能元件，能量只能"单向泄"，所以曲线是指数形的、单调的。一旦电容和电感同时存在（二阶电路），能量就有了两个仓库——它会在这两个仓库之间来回倒腾，这就是振荡的起源。

电阻 R 决定这场拔河的"刹车力度"：R 大，能量很快被耗光，来不及振荡（过阻尼）；R 小，能量能倒腾很多个来回（欠阻尼）；恰好卡在分界线上，就是临界阻尼。

先说结论（考试重心）：二阶电路完整求解微分方程在期末出现频率中等，但"判断响应类型 + 欠阻尼参数计算 + 定性画波形"几乎必会。本课把完整解法给你，但重点磨"判型直觉"。
课程链地位本课的 ω₀、衰减振荡、品质因数，将在第 6 课《谐振深化》以正弦稳态的面孔重新登场；电力系统短路暂态、变电站操作过电压，用的都是同一套"阻尼振荡"语言。这课是在给电网主业铺路。

2标准模板：RLC 串联的零输入响应

最经典的二阶电路：电容已充好电（uC(0⁻) = U₀），t = 0 时经 R、L 放电。沿回路列 KVL，代入 i = −C·duC/dt，得到：

LC · d²uC/dt² + RC · duC/dt + uC = 0 二阶常系数齐次微分方程 —— 换元成标准形：s² + (R/L)s + 1/(LC) = 0（特征方程）

一阶方程只有一个特征根、一个待定常数；二阶方程有两个特征根、两个待定常数——这正是"需要两个初值"的根源：

s1,2 = −R2L ± √(R/2L)² − 1/(LC) 根号里的正负，就是三种形态的分水岭

定义两个标志性参数（后文全靠它们说话）：

α = R2L（衰减系数）　　ω₀ = 1√LC（固有振荡角频率） 判型只看 α 与 ω₀ 谁大：等价于 R 与 2√(L/C) 谁大

3三种形态：一张表定乾坤

形态判别条件特征根响应形式波形特征
过阻尼R > 2√(L/C)
(α > ω₀)		两个不相等负实根 s₁、s₂A₁es₁t + A₂es₂t单调缓慢衰减，无振荡
临界阻尼R = 2√(L/C)
(α = ω₀)		二重根 s = −α(A₁ + A₂t)e−αt不振荡，且最快无超调回到稳态
欠阻尼R < 2√(L/C)
(α < ω₀)		共轭复根 −α ± jωdAe−αtsin(ωdt + φ)衰减振荡，包络 ±Ae−αt

其中欠阻尼的振荡角频率（阻尼振荡角频率）：

ωd = √ω₀² − α² α 越小 → ωd 越接近 ω₀；R = 0 时 α = 0，ωd = ω₀，等幅振荡（理想 LC 永动）

物理直觉（考试答"为什么"用）

  • 过阻尼：R 太大，电容放电的电流刚起来就被电阻抽干能量，电感存不进多少——整场戏电容单方面放电，曲线单调趴下。
  • 临界阻尼：刹车恰到好处，不振荡且以最快速度归零。自动控制系统（比如指针仪表）最爱这个状态——"快而不晃"。
  • 欠阻尼：R 小，能量在 C（电场能）和 L（磁场能）之间来回倒腾，每倒一次被 R 抽走一点，形成衰减振荡。
  • 无阻尼（R = 0）：没有耗散，能量永动循环，等幅正弦振荡，频率 ω₀。
判型口诀（RLC 串联）：算 2√(L/C)，与 R 比大小——大二过、等二临、小二欠。先算 2√(L/C) 再比 R，三秒定形态，这永远是此类题的第一问。
头号陷阱判型不等式只对RLC 串联成立。若是并联电路（G、L、C 并联），判型条件对偶地变为 G 与 2√(C/L) 比较，α = G/2C。看到题目先看拓扑再套公式，别拿串联公式硬套并联题。

4欠阻尼细看：考试最爱的一档

欠阻尼响应 uC(t) = Ae−αtsin(ωdt + φ) 里有三个可考参数，各自管一件事：

参数公式管什么考法
衰减系数 αR/2L包络线 ±Ae−αt 下沉的快慢"衰减多快""经过几周衰减到多少"
阻尼振荡角频率 ωd√(ω₀²−α²)振荡多快（一秒倒腾几回）"振荡周期 T = 2π/ωd"
固有角频率 ω₀1/√(LC)无阻尼时的振荡频率（只由 L、C 决定）与 α、ωd 构成勾股关系

勾股关系是记住三参数的钥匙：α² + ωd² = ω₀²——α 和 ωd 是直角边，ω₀ 是斜边。衰减越猛（α 大），振得越慢（ωd 小）；完全不衰减（α=0）时 ωd = ω₀ 取满。

与阶段 0 第 6 课的暗线：谐振课里出现过 Q = ω₀L/R（品质因数）。在欠阻尼里 Q = ω₀/2α——Q 大 = 衰减小 = 振得久。谐振回路要"振得纯"，暂态分析要"振得快停"，同一个 Q，两种立场。第 6 课会正式接上这条线。

5完整解法：经典法四步（以过阻尼为例）

  1. 列方程：KVL / KCL + 元件约束，整理成标准形式 s² + 2αs + ω₀² 对应的微分方程。
  2. 解特征方程：得 s₁、s₂，按判型写出齐次通解框架（含两个待定常数 A₁、A₂）。
  3. 找特解：直流激励下，特解 = 新稳态值（电容开路 / 电感短路来求）。零输入响应特解为 0。全解 = 特解 + 齐次通解。
  4. 两个初值定常数：这一步是二阶与一阶最大的不同——
    • 初值①：uC(0⁺)（换路定则直接给）
    • 初值②：duC/dt(0⁺) = iC(0⁺)/C——由 0⁺ 电路里的电容电流（往往就是 iL(0⁺)）换算来
    把 t = 0 代入全解及其导数，联立两个方程解出 A₁、A₂。
区分度所在一阶只要一个初值，二阶要函数值 + 导数值。导数初值的来源（duC/dt = iC/C 或 diL/dt = uL/L）是阅卷时最容易丢分的一步，也是出题人故意设置区分度的地方。

6例题精讲（三道模板题）

例 1 · 判型题：永远是第一问

RLC 串联电路，R = 4 Ω，L = 1 H，C = 1 F。判断响应类型；若 R 减小到 2 Ω，再判断一次。

  1. 算分界线：2√(L/C) = 2√(1/1) = 2 Ω
  2. 第一次比：R = 4 Ω > 2 Ω → 过阻尼（R 比临界电阻大）
  3. 第二次比：R = 2 Ω = 2 Ω → 临界阻尼（恰好卡在分界线）
答：R = 4 Ω 过阻尼；R = 2 Ω 临界阻尼（此时 s = −R/2L = −1，二重根）

套路固定：先算 2√(L/C)，再比 R——顺序别反。顺带留意：本题的 2√(L/C) = 2 Ω 恰好等于 2√(L/C) 的"2"×√(L/C)，算的时候别漏乘 2。

例 2 · 欠阻尼参数三件套

RLC 串联，R = 2 Ω，L = 1 H，C = 1/4 F。求 α、ω₀、ωd 与振荡周期 T，并写响应骨架。

  1. 判型：2√(L/C) = 2√4 = 4 Ω > R = 2 Ω → 欠阻尼
  2. α = R/2L = 2/2 = 1 s⁻¹
  3. ω₀ = 1/√(LC) = 1/√(1/4) = 2 rad/s
  4. ωd = √(ω₀² − α²) = √(4 − 1) = √3 rad/s
  5. T = 2π/ωd = 2π/√3 ≈ 3.63 s；响应骨架 uC(t) = Ae−tsin(√3t + φ)
答：α = 1，ω₀ = 2，ωd = √3 rad/s，T = 2π/√3 ≈ 3.63 s；包络 ±Ae−t

校验勾股：α² + ωd² = 1 + 3 = 4 = ω₀² ✓。三个参数算完必自检这一条，30 秒防错。

例 3 · 过阻尼完整求解：两个初值定两个常数

RLC 串联零输入，R = 2.5 Ω，L = 1 H，C = 1 F，uC(0⁻) = 6 V，iL(0⁻) = 0。求 uC(t)。

  1. 判型：2√(L/C) = 2 Ω < R = 2.5 Ω → 过阻尼，响应形如 uC = A₁es₁t + A₂es₂t
  2. 特征根：s² + 2.5s + 1 = 0 → s = (−2.5 ± 1.5)/2 → s₁ = −0.5，s₂ = −2
  3. 通解：uC(t) = A₁e−0.5t + A₂e−2t
  4. 初值①：uC(0⁺) = uC(0⁻) = 6 → A₁ + A₂ = 6
  5. 初值②：duC/dt(0⁺) = iC(0⁺)/C = 0（串联电路 iC = iL，iL(0⁺) = 0）→ −0.5A₁ − 2A₂ = 0
  6. 联立求解：A₁ = 8，A₂ = −2
答：uC(t) = 8e−0.5t − 2e−2t V，t ≥ 0

两处自检：t = 0 时 8 − 2 = 6 ✓；求导 −4e−0.5t + 4e−2t 在 t = 0 时为 0 ✓。本题最关键的一步是初值②——电流初值换算成电压导数初值，这是二阶定常数的命门。

7限时练习（建议 20 分钟，做完再展开）

练 1快速判型基础模板展开对答案 ▾
RLC 串联，R = 1 Ω，L = 1 H，C = 1 F。判断响应类型，并指出特征根的性质。
2√(L/C) = 2 Ω > R = 1 Ω → 欠阻尼；特征根为共轭复根 −0.5 ± j(√3/2)

α = R/2L = 0.5，ω₀ = 1，ωd = √(1 − 0.25) = √3/2 ≈ 0.866 rad/s。

练 2临界阻尼的参数重根情形展开对答案 ▾
RLC 串联，R = 4 Ω，L = 2 H，C = 0.5 F。判断响应类型，求特征根。
2√(L/C) = 2√(2/0.5) = 2√4 = 4 Ω = R → 临界阻尼；重根 s = −R/2L = −4/4 = −1（二重），响应形如 (A₁ + A₂t)e−t

临界阻尼的标志：特征方程是完全平方——s² + 2αs + α² = (s + α)²。

练 3导数初值的来源区分度题展开对答案 ▾
RLC 串联零输入电路中，uC(0⁺) = 10 V，iL(0⁺) = 2 A，C = 0.5 F。求 duC/dt(0⁺)。若改求 diL/dt(0⁺)，还需要知道什么？
串联电路 iC = iL，故 duC/dt(0⁺) = iC(0⁺)/C = 2/0.5 = 4 V/s。若求 diL/dt(0⁺) = uL(0⁺)/L，需要先在 0⁺ 电路里用 KVL 求出 uL(0⁺)（= −uC(0⁺) − R·iL(0⁺)，零输入情形）。

记忆锚点：求导数初值永远走"另一元件"——电容的导数初值用电感电流（iC/C），电感的导数初值用电容电压（uL/L）。

8自测清单：全勾才算过关

  • 能列 RLC 串联的特征方程 s² + (R/L)s + 1/(LC) = 0，并说清它从 KVL 而来
  • 能背判型口诀"大二过、等二临、小二欠"，并知道判的是 R 与 2√(L/C) 的大小（串联）
  • 能默写三种形态的特征根性质与响应形式，画出各自波形草图（过阻尼单调、临界最快、欠阻尼衰减振荡）
  • 能算欠阻尼三件套 α、ω₀、ωd，并用勾股关系 α² + ωd² = ω₀² 自检
  • 知道二阶需要两个初值，能从 iC(0⁺)/C 拿到 duC/dt(0⁺)（练 3 的命门）
  • 限时练习 3 题独立做对；知道并联电路判型条件与串联对偶（G vs 2√(C/L)），不混用
