互感与变压器

同名端、耦合系数、理想变压器与阻抗变换 —— 电力变压器（变电站里最贵的设备）的电路模型。两个线圈靠磁场"隔空握手"：这是"磁耦合"第一次正式进场，也是电力系统"变压不变频"的全部秘密。

预计 2 小时 依赖：阶段0 第2课（相量）、第3课（电感） 笔试中频 · 电力设备基础

1本课核心思想：磁的耦合——能量隔空传递

自感是"线圈自己感自己"（磁通全部穿过自己绕的线圈）；互感是"线圈感别人"——线圈 1 的电流产生的磁通，有一部分穿过了线圈 2。于是线圈 1 的电流变化，会在线圈 2 上隔空感应出电压，一根导线都不用连。

把这个现象工程化、极致化，就是变压器：原边线圈接电源，副边线圈接负载，能量全靠磁场跨过去。变电站里那台嗡嗡响的大家伙，电路模型就是本课内容。

课程链地位：前面所有课的元件都是"两端的"（R、L、C 都只有一对端子），互感元件是第一个四端元件——它有两条支路、靠磁场（而不是导线）传递信号。理解了它，第 8 课二端口网络的"端口思维"就有了台阶。
南网视角电力变压器是电网"电压的枢纽"：发电机发出的电靠它升压远距离输送（减小线损），到城市再降压分配入户。110 kV / 10 kV 这样的数字，就是变压器两边的电压比。南网笔试既考电路计算（阻抗变换），也考设备概念（变压器原理、损耗）。

2互感系数 M 与耦合系数 k

线圈 1 的电流 i₁ 变化，在线圈 2 上感应的互感电压：

uM2 = M · di1/dt　　（正弦稳态相量形式：U̇M2 = jωM · İ1） M：互感系数，单位亨利（H）——和 L 同量纲，因为它就是"别人家的电感"作用的度量

耦合系数 k 衡量两个线圈"握手的紧密程度"：

k = M√(L₁L₂)　　0 ≤ k ≤ 1 k = 1：全耦合（无漏磁）；k 越小，漏磁越多，耦合越松
  • 铁芯变压器：磁通几乎全走铁芯，k ≈ 0.99+，接近全耦合
  • 空心线圈：磁通大量漏到空气里，k 可能只有零点几
  • 反过来由 k 也能算 M：M = k√(L₁L₂) —— k 给定时 M 是确定值，不是随便标
常见考法给 L₁、L₂、M 求 k（或反向求 M）。数值上注意 √(L₁L₂) 是几何平均——别算成 (L₁+L₂)/2。

3同名端：互感电路的"极性地图"

互感电压的方向（正极在哪个端子）取决于绕向 + 电流方向，每题都要重新判断太麻烦。于是定义同名端一劳永逸：

定义：从两线圈各选一个端子，当两电流同时从这两个端子流入（或同时流出）时，产生的磁场相互增强——这两个端子就是一对同名端，图上用 · 或 * 标记。

同名端怎么判断（考试画图题）

  1. 假设电流从线圈 1 的某端流入，用右手螺旋定则判断磁通方向（四指沿电流绕向，拇指即磁通方向）。
  2. 再假设电流从线圈 2 的某端流入，同样判断磁通方向。
  3. 两次磁通同向（叠加） → 这两个流入端是同名端；反向（抵消） → 该端与另一端是同名端。

绕向不同（顺绕/反绕）、位置不同（同轴/并排/相对），同名端就不同——所以画图题给绕向，就是要你走这三步。

同名端的真正用处：定互感电压的极性

电流从线圈 1 的同名端流入且增大 → 线圈 2 感应电压的同名端为正 口诀：流入同名端，同名端出正电压（"同进同正"）

有了这句话，任何互感电路的电压符号都不用现场推导：看电流从哪端流入、看感应端是同名端还是异名端，符号立判。

头号陷阱自感电压 L·di/dt 的符号由本支路的电压电流参考方向决定（关联取正）；互感电压 ±jωM·İ 的符号由两支路电流与同名端的相对关系决定。两套规则互不相干，混着用必错。

4耦合电感的伏安方程与去耦等效

正弦稳态下，两线圈端口电压（各取关联参考方向）：

U̇₁ = jωL₁·İ₁ ± jωM·İ₂
U̇₂ = jωL₂·İ₂ ± jωM·İ₁ 符号规则："同进取正"——两电流都从各自同名端流入（或都从异名端流入）取 +；一同一异取 −

去耦等效（T 型）：互感电路的"卸妆水"

互感电路背着 ±jωM 不好算，工程上把它等效成普通 T 型三电感电路，之后全是熟悉的阻抗串并联。两线圈有一端相连时（公共节点）：

连接方式T 型三臂（左臂 / 中臂 / 右臂）口诀
同名端相连L₁ − M　｜　M　｜　L₂ − M"同连减 M"
异名端相连L₁ + M　｜　−M　｜　L₂ + M"异连加 M"

串联的快速结论（从去耦直接推出）

顺接（异名端相连，磁场增强）：Leq = L₁ + L₂ + 2M
反接（同名端相连，磁场削弱）：Leq = L₁ + L₂ − 2M 由此得到实验室测 M 的标准方法：M = (L顺 − L反)/4 —— 常考填空
易错提醒"顺接 = 异名端相连"容易记反：顺接时电流一个从同名端进、一个从异名端进（沿串联路径必然如此），磁场才增强。判据别背反了——记不住就现场用右手螺旋验一次磁通方向，比背错强。

5理想变压器：一个参数 n 管全部

把耦合电感推向三个极限，就得到理想变压器：

  • 全耦合：k = 1，无漏磁
  • 无损耗：绕组电阻为零，铁芯无涡流、无磁滞损耗
  • 自感无穷大：L₁、L₂、M → ∞，但比值保持为匝比平方（L₁/L₂ = n²）

理想变压器只剩一个参数 n = N₁/N₂（匝比），三大关系全部由它决定：

变压：U̇₁U̇₂ = n　　变流：İ₁İ₂ = 1n　　阻抗：Zin = n²·ZL 电压比 = 匝比；电流比 = 匝比倒数；副边阻抗折算到原边乘 n²

功率守恒是理想变压器的灵魂：U̇₁İ₁* = U̇₂İ₂*，它自己不储能、不耗能，只做"即时转发"。这和耦合电感（储能动态元件，3 个参数 L₁、L₂、M）有本质区别——理想变压器是无记忆元件，直流稳态下它"短路/开路"没有物理意义（实际变压器靠磁通变化工作，直流不工作）。

阻抗变换——本课最重要考点：副边接 ZL，从原边看进去就是 n²ZL。电阻变大还是变小看 n：
• n > 1（降压变压器）：折算后阻抗变大 n² 倍
• n < 1（升压变压器）：折算后阻抗变小
记忆："从哪边看，乘哪边匝数的平方、除另一边的"——本质是功率不变（U 变 n 倍，I 变 1/n 倍，U/I 自然变 n² 倍）。

最大功率匹配：变压器的经典应用

信号源内阻 RS、负载 RL 不匹配（比如音响 8 Ω 喇叭 vs 数千欧输出级），中间插一个变压器，选匝比使 n²RL = RS，负载即获得最大功率——这就是第 2 课最大功率传输定理的"工程实现版"：

n = √RS / RL 把负载"折算"到信号源一侧，凑成阻抗匹配

6电力视角：为什么电网离不开变压器

输电线路损耗 Ploss = I²Rline，同样功率下电压越高电流越小、线损越小。所以电力系统"高出力必先升压"：

  • 发电机出口 ~20 kV → 升压到 220/500 kV 远距离输送
  • 到城市逐级降压：220 kV → 110 kV → 10 kV → 380/220 V 入户
  • 每一级降压，电路模型都是本课的"降压变压器"；其额定容量（kVA）、变比、联结组别是南网设备类笔试的概念题素材

此外电力系统中大量"折算"思想（把副边参数折算到原边做统一计算）用的正是 Z′ = n²Z——本课学的不是应试技巧，是电力行业的基础语言。

7例题精讲（三道模板题）

例 1 · 同名端判断：三步走

两线圈绕在同一铁芯上：线圈 1 顺绕，线圈 2 绕向与线圈 1 相同、且两线圈首端位于磁芯同侧（同名端位置待判）。请说明判断流程并给出"同进同正"验证。

  1. 定电流：设电流 i₁ 从线圈 1 的 a 端流入、i₂ 从线圈 2 的 x 端流入。
  2. 螺旋定则：i₁ 产生的磁通 Φ₁ 方向、i₂ 产生的磁通 Φ₂ 方向（两线圈绕向相同、位置同侧 → 磁通同向）。
  3. 结论：Φ₁ 与 Φ₂ 叠加增强 → a 与 x 为同名端。验证口诀：i₂ 从同名端 x 流入且增大时，线圈 1 的同名端 a 感应出正电压——"同进同正" ✓
答：绕向相同、位置同侧时两首端（a、x）为同名端；若线圈 2 反绕（或位置对调），则 a 与 y 为同名端。

画图题的命门永远是"绕向"和"位置"两个变量——只改其中一个，同名端就换。判断顺序固定：假设电流 → 螺旋定则 → 比磁通方向。

例 2 · 串联测 M：两读数定三个参数

两耦合线圈，顺向串联时等效电感 0.9 H，反向串联时 0.3 H。求互感 M；若 L₁ = L₂，再求耦合系数 k。

  1. 求 M：M = (L顺 − L反)/4 = (0.9 − 0.3)/4 = 0.15 H
  2. 求 L：L₁ + L₂ = (L顺 + L反)/2 = (0.9 + 0.3)/2 = 0.6 H；若 L₁ = L₂ = L，则 L = 0.3 H
  3. 求 k：k = M/√(L₁L₂) = 0.15/0.3 = 0.5（半耦合）
答：M = 0.15 H；L₁ = L₂ = 0.3 H 时 k = 0.5

两个串联读数"十字相减再除四"拿 M、"相加除二"拿自感总和——这是实验测耦合参数的标准考法，公式值得当模板背。

例 3 · 阻抗匹配：变压器的"中介"角色

正弦信号源 U̇S = 10∠0° V，内阻 RS = 800 Ω，负载为 8 Ω 扬声器。中间加理想变压器匹配，求匝比 n（N₁/N₂）与扬声器获得的最大功率。

  1. 匹配条件：从原边看，n²RL = RS（第 2 课最大功率传输的变压器版）
  2. 求 n：n = √(RS/RL) = √(800/8) = √100 = 10
  3. 原边电路：匹配时原边电流 İ₁ = U̇S/(RS + n²RL) = 10/1600 = 6.25 mA
  4. 功率：扬声器折算阻抗上消耗 P = I₁² · n²RL = (6.25×10⁻³)² × 800 ≈ 31.25 mW（即电源供出功率的一半，另一半耗在内阻）
答：n = 10（降压变压器，N₁:N₂ = 10:1）；扬声器获最大功率约 31.25 mW

校验直觉：n² × 8 Ω = 100 × 8 = 800 Ω = RS ✓。这就是收音机/音响输出变压器的原理——数欧的喇叭配数千欧的放大器，全靠一个铁芯线圈"翻译"。若不匹配直连，8 Ω 负载只能拿到不到 0.3 mW——差百倍。

8限时练习（建议 20 分钟，做完再展开）

练 1耦合系数计算基础模板展开对答案 ▾
L₁ = 0.4 H，L₂ = 0.1 H，M = 0.1 H。求耦合系数 k，并判断耦合松紧。
k = M/√(L₁L₂) = 0.1/√(0.4×0.1) = 0.1/√0.04 = 0.1/0.2 = 0.5（半耦合，有漏磁）

√(L₁L₂) 是几何平均——0.4 和 0.1 的几何平均是 0.2，不是算术平均 0.25。

练 2同名端符号判断口诀应用展开对答案 ▾
两耦合线圈，1 和 2 为同名端。i₁ 从线圈 1 的 1 端流入且增大。问：线圈 2 的感应电压在哪个端子为正？若 i₁ 减小呢？
i₁ 增大：感应电压 2 端为正（"同进同正"）。i₁ 减小：di₁/dt 变号，感应电压随之反号——1′ 端（2 的对端）为正。

符号跟着 di/dt 走：电流减小与电流反向是一回事，感应电压极性自动翻转。

练 3理想变压器折算阻抗变换展开对答案 ▾
理想变压器 n = 4（N₁:N₂ = 4:1），副边接 ZL = (2 + j2) Ω。求从原边看入的阻抗 Zin；若原边电压有效值 100 V，求副边电压与负载电流。
Zin = n²ZL = 16 × (2 + j2) = (32 + j32) Ω。副边电压 = 100/4 = 25 V；负载电流 = 25/|2+j2| = 25/2√2 ≈ 8.84 A。

折算时模和辐角都不变，只把模乘 n²——"阻抗乘匝比平方，电压电流一个除 n 一个乘 n"。

9自测清单：全勾才算过关

  • 能说清互感现象的物理机制（磁通穿过对方线圈），写出互感电压 uM2 = M·di₁/dt 及相量形式
  • 能默写 k = M/√(L₁L₂) 并正反运用（k 求 M / M、L 求 k）
  • 能用三步法（假设电流 → 螺旋定则 → 比磁通）判断同名端，会背"同进同正"口诀
  • 能写耦合电感伏安方程并正确取 ± 号（"同进取正"），知道它与自感符号规则互不相干
  • 会去耦等效（同连减 M / 异连加 M）与串联结论 L = L₁+L₂±2M，记得 M = (L顺−L反)/4
  • 能默写理想变压器三大关系（变压 n、变流 1/n、阻抗 n²）与匹配公式 n = √(RS/RL)，限时练习 3 题全对
