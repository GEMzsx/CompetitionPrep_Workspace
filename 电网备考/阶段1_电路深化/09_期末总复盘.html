期末总复盘：八课混考与 85+ 冲刺

八门正课到此合体 —— 一张知识地图串起整条链，六道混考大题检验跨课调用能力，一套冲刺策略瞄准期末 85+。这是阶段 1 的收官之战，也是绩点前 10% 的地基浇筑。

预计 3 小时（含 90 分钟限时混考） 依赖：第 1–8 课全部 收官任务 · 期末 85+

1八课知识地图：一条链，不是八个盒子

期末复习最忌"一课一课孤立的看"。八课是一条链：第 1 课的节点/网孔法是万能引擎；第 2 课的定理是化简捷径；第 3、4 课给电路加上时间维度；第 5 课让能量跨过磁场传递；第 6、7 课把正弦交流推向电力系统的真实形态；第 8 课把一切封装成黑盒子。期末卷 = 这条链的随机组合。

2混考六题：期末大题的真实形态

期末大题从不"单课裸考"，最爱把两三个课的套路焊在一道题里。下面六题覆盖六种最常见的组合拳。

玩法（认真执行）：先限时 90 分钟把六题当一张期末卷子做（纸上完整写过程），再逐题展开核对。得分 ≥ 5/6 → 具备 85+ 实力；< 5 → 把错的那题的"所属课号"记进错题本，回去重做该课练习。
混考 1戴维南 × 三要素 —— 一阶题万能组合拳第2课 × 第3课展开 ▾

含源电阻网络 N 从 a-b 端口看进去的戴维南等效为 Uoc = 10 V、Req = 2 kΩ。电容 C = 100 μF 原已充电至 2 V，t = 0 时接入端口。求 t ≥ 0 的 uC(t) 与 iC(t)。

拆解：戴维南负责"压缩"（源 + 电阻网络 → 一条支路），三要素负责"释放"（套公式）。

  1. uC(0⁺) = 2 V（换路定则，电容电压不能突变）
  2. uC(∞) = Uoc = 10 V（稳态电容开路，电压全部落在 C 上）
  3. τ = Req·C = 2000 × 100μ = 0.2 s
uC(t) = 10 + (2−10)·e−t/0.2 = 10 − 8e−5t V；　iC(t) = C·duC/dt = 4e−5t mA

自检：t = 0 时 iC = (10−2)/2000 = 4 mA ✓ 与解出的初值一致。任何一阶题卡住，先想"能不能先戴维南"。

混考 2互感串联实验 —— 一组数据拆出三个参数第5课展开 ▾

两个耦合线圈串联，测得顺接等效电感 0.7 H、反接 0.3 H；又知 L₁ = 0.4 H。求 M、L₂ 与耦合系数 k。

  1. M = (L顺 − L反) / 4 = (0.7 − 0.3)/4 = 0.1 H
  2. L₁ + L₂ = (0.7 + 0.3)/2 = 0.5 H → L₂ = 0.1 H
  3. k = M / √(L₁L₂) = 0.1 / √(0.04) = 0.5
M = 0.1 H，L₂ = 0.1 H，k = 0.5（中等耦合）

这是实验室测 M 的标准操作：一次顺接一次反接，M 由差值蹦出来。k = 1 为全耦合（无漏磁），k < 0.5 一般算松耦合。

混考 3三相断线 —— 中性点位移的定量版第6课 × 第1课展开 ▾

对称三相源相电压 220 V，Y 形负载 ZA = ZB = 10 Ω，C 相负载断线，无中线。求中性点位移电压、A/B 相负载实际电压、C 相断口电压。

拆解：弥尔曼三步 —— 列各相导纳、代入相电压、除以总导纳。

  1. U̇N'N = (U̇A + U̇B) / 2 = −U̇C/2 = 110∠−60° V（C 相导纳为零，分子只剩两项）
  2. U̇A' = U̇A − U̇N'N = 220∠0° − 110∠−60° = 190.5∠30° V（B 相同理 190.5 V）
  3. 断口电压 U̇C' = U̇C − U̇N'N = 220∠120° − 110∠−60° = 330∠120° V
UN'N = 110 V；A、B 相降到 190.5 V（欠压发暗）；C 相断口高达 330 V

"重载拉低、轻载遭殃"的极端版本：A/B 欠压变暗，断口电压却比线电压还高 —— 维修工不知道这一点就会出事。中线的全部作用，就是把这 110 V 位移电压钳回零。

混考 4谐波逐频 —— 电容"通高频"的定量账第7课 × 阶段0相量展开 ▾

u(t) = 100 + 100√2·sin(1000t) + 50√2·sin(2000t) V 加于 R = 10 Ω 与 C = 100 μF 的串联电路。求电流有效值与电路吸收的平均功率。

  1. 直流：电容隔直 → I₀ = 0（注意：100 V 直流全部落在电容上）
  2. 一次谐波：XC1 = 1/(ωC) = 10 Ω，|Z₁| = √(10²+10²) = 14.14 Ω → I₁ = 100/14.14 = 7.07 A
  3. 二次谐波：XC2 = 5 Ω，|Z₂| = √(10²+5²) = 11.18 Ω → I₂ = 50/11.18 = 4.47 A
  4. 有效值方均根：I = √(7.07² + 4.47²) = 8.37 A
  5. 功率只看电阻：P = R·I² = 10 × 70 = 700 W
I ≈ 8.37 A；P = 700 W（全部耗在 R 上，电容不耗能）

三件事各管一段：逐频算阻抗（XC = 1/kωC，频率越高电容越"通"—— 本题二次谐波电流占比远超电压占比）、方均根合成、功率"同频才配对"且只有 R 耗能。检验：P 也可写成 P = ΣR·Iₖ² = 10×(50+20) = 700 W ✓

混考 5二端口加载 —— 参数方程 + 端口条件联立第8课 × 第2课展开 ▾

某二端口 Z 参数为 [[12, 4], [4, 10]] Ω，入口接 İ₁ = 2∠0° A 电流源。① 出口开路时 U̇₂ = ？② 出口改装 RL = 5 Ω 后，负载电流与功率各多少？

  1. ① 开路 → İ₂ = 0 → U̇₂ = Z₂₁·İ₁ = 4 × 2 = 8 V
  2. ② 接负载后端口条件：U̇₂ = −RL·İ₂（负载上电流方向与 İ₂ 相反）
  3. 代入参数方程：4×2 + 10·İ₂ = −5·İ₂ → 8 = −15·İ₂ → İ₂ = −8/15 A
  4. 负号 = 电流实际流出端口 2，即流进负载：IL = 8/15 ≈ 0.533 A
  5. PL = I²·RL = (8/15)² × 5 ≈ 1.42 W
① U̇₂ = 8 V；② IL ≈ 0.533 A，PL ≈ 1.42 W

二端口题的通用套路 = 参数方程 + 外电路端口条件联立。İ₂ 的负号不是算错，是"电流实际流进负载"的另一种说法 —— 方向约定（第 8 课讲的"都从上端流入"）一以贯之。

混考 6二阶判型 —— 30 秒内出形态第4课展开 ▾

RLC 串联放电电路：R = 2 Ω、L = 1 H、C = 1/4 F，uC(0) = 1 V、i(0) = 0。判别响应类型并求 uC(t)。

  1. α = R/2L = 1，ω₀ = 1/√(LC) = 2 → α < ω₀，欠阻尼（口诀"小二欠"），ωd = √(4−1) = √3
  2. 设 uC = e−t(A·cos√3t + B·sin√3t)，uC(0) = 1 → A = 1
  3. duC/dt(0) = i(0)/C = 0 → −A + √3·B = 0 → B = 1/√3
  4. 勾股自检：α² + ωd² = 1 + 3 = 4 = ω₀² ✓
uC(t) = e−t(cos√3t + (1/√3)·sin√3t) V，欠阻尼衰减振荡

判型只看 α 与 ω₀ 的大小关系（"大二过、等二临、小二欠"），不用真解方程。两个初条件各定一个系数：uC(0) 定 A，导数初值 i(0)/C 定 B —— 这是二阶题固定的两步收尾。
