阶段 1 · 第 3 课 · 2026-10-15

一阶动态电路与三要素法

换路定则、RC / RL 暂态、三要素法（初值 + 终值 + 时间常数）—— 总纲点名的必会题，期末必出一道大题的"稳拿分"章节。学完本课，任何一阶电路都只有一行公式，且这道公式还能顺手把第 2 课的戴维南等效用上。

预计 2.5 小时 依赖：第 2 课（戴维南等效） 期末大题 · 稳拿分

1本课核心思想：暂态是"电的惯性"，三要素是万能钥匙

前面所有课学都是稳态——电路早就稳定了，电流电压不再变化。但只要电路里有储能元件（电容存电场能、电感存磁场能），一"换路"（开关动作、电源突变），能量没法瞬间改变，电路就会经历一段过渡过程（暂态），然后才进入新的稳态。

动态电路的难点本来在于"要解微分方程"，但一阶电路（只含一个等效储能元件）有一条万能钥匙——三要素法。背下这一个公式，微分方程一步都不用解：

f(t) = f(∞) + [ f(0⁺) − f(∞) ] · e−t/τ f 可以是任一支路的电流或电压；三要素 = 初值 f(0⁺)、终值 f(∞)、时间常数 τ
本课的骨架：换路定则（拿初值）→ 稳态电路（拿终值）→ 从动态元件看进去求等效电阻（拿 τ）→ 代公式。全程不解微分方程，考场上就是"三步取值 + 一行公式"。
南网 / 期末视角动态电路是期末必出一道大题的高频章节（通常 10–15 分），也是南网笔试电路部分常考的"求 uC(t) / iL(t)"题型。它同时是第 4 课（二阶电路）的地基。

2换路定则：储能元件的值不能突变

换路瞬间（记作 t = 0），电容电压和电感电流必须连续——因为它们对应能量（WC = ½CuC²、WL = ½LiL²），能量不能突变：

uC(0⁺) = uC(0⁻)　　iL(0⁺) = iL(0⁻) 换路定则 —— 只有这两个量不突变，其余都可突变

怎么求初值 f(0⁺)：两步走

  1. 先求 0⁻ 稳态：换路前电路已达稳态，此时电容相当于开路（电流为 0）、电感相当于短路（电压为 0），据此算出 uC(0⁻) 或 iL(0⁻)。
  2. 再画 0⁺ 等效电路：换路后的电路里，把动态元件替换成"已知值"，其余元件保留，解出目标量在 t = 0⁺ 时的值。
动态元件在 0⁺ 等效电路里替换为特殊情况
电容 C电压源，值 = uC(0⁺)uC(0⁺) = 0 → 直接用导线短路
电感 L电流源，值 = iL(0⁺)iL(0⁺) = 0 → 直接断开开路
头号陷阱别搞错"不突变"的对象！不突变的只有 uC 和 iL。电容电流 iC、电感电压 uL、以及电阻上的电流电压，在换路瞬间都可以跳变。所以求 iC(0⁺)、uL(0⁺) 时，必须先拿到 uC(0⁺)/iL(0⁺)，再用 KCL / KVL 在 0⁺ 电路里算——不能想当然。

3三要素：初值、终值、时间常数

要素含义怎么求
初值 f(0⁺)换路瞬间的值换路定则 + 0⁺ 等效电路（上一节）
终值 f(∞)换路后新稳态的值换路后电路稳态：电容开路、电感短路，按稳态电路算
时间常数 τ过渡过程的快慢从动态元件两端看进去求等效电阻 Req
RC 电路：τ = Req · C　　RL 电路：τ = LReq Req：把电源全部置零后，从动态元件两端看进去的等效电阻
第二个陷阱τ 里的电阻不是"回路总电阻"，而是从动态元件两端看进去的等效电阻 Req。求它就是把第 2 课的戴维南方法搬过来：独立源置零（压源短路、流源开路），从动态元件端口向外看；含受控源时必须用外加电源法或开路短路法，不能直接串并联。

为什么 τ 用 Req？直观理解：电容放电是"电流流过外电路"，外电路越"堵"（Req 越大），放电越慢；电感储的是电流，外电路电阻越小，"泄流"越快（τ = L/Req 与 Req 成反比）。

4指数曲线直觉：τ 到底是什么

三要素公式画出来是一条从 f(0⁺) 出发、渐近到 f(∞) 的指数曲线。记住这三条数轴刻度，判断和估算就都有了：

时间已完成的改变量（占总量的比例）工程含义
t = 1τ63.2%τ 是"快慢的尺度"，不是"过程结束时间"
t = 3τ95.0%工程上通常认为已进入稳态
t = 5τ99.3%教材默认"过渡过程结束"
  • τ 越大：曲线越平缓，过程越长（大电阻、大电容使放电慢）
  • τ 越小：曲线越陡，几乎"瞬间"完成
  • 若 f(0⁺) = 0：整条曲线是充电上升（1 − e−t/τ 形态）；若 f(∞) = 0：是放电衰减（e−t/τ 形态）
速判技巧：考试若问"经过多久达到某值"，把三要素代回公式解 t 即可：e−t/τ = [f(∞) − f(t)]/[f(∞) − f(0⁺)]，再取对数。别死记"3τ"。

本课讨论的一阶电路，指只含一个等效储能元件（一个 C，或一个 L；多个同类元件可先合并）。若同时含 C 和 L，则是二阶电路——那是第 4 课的内容。

5例题精讲（三道模板题）

例 1 · RC 充电：三要素法的最基本形态

电路：10 V 电压源经开关 S、串联 R = 2 kΩ 与 C = 1 μF 接通到地。t = 0 前 S 断开、电容未储能；t = 0 合上 S。求 uC(t) 及电流 i(t)。

  1. 初值：换路前电容未储能 → uC(0⁻) = 0，由换路定则 uC(0⁺) = 0
  2. 终值：t → ∞ 稳态，电容开路（无电流），电阻上无压降 → uC(∞) = 10 V
  3. 时间常数：从电容两端看进去 Req = R = 2 kΩ（电压源短路后就是它自己）→ τ = ReqC = 2×10³ × 1×10⁻⁶ = 2 ms
  4. 代公式：uC(t) = 10 + (0 − 10)e−t/0.002 = 10(1 − e−500t) V
  5. 求电流：i(t) = (10 − uC)/R = 10e−500t/2000 = 5e−500t mA（0⁺ 瞬间为 5 mA，稳态为 0）
答案：uC(t) = 10(1 − e−500t) V，t ≥ 0

校验：t = τ = 2 ms 时 uC = 10 × 63.2% = 6.32 V ✓；t = 3τ = 6 ms 时达 9.5 V，进入稳态。注意 0⁺ 时电容电压为 0（相当于短路），而电流却最大（5 mA 可突变）——这正是"不突变的只有 uC"的活例。

例 2 · RL 电路：先用第 2 课的戴维南求 τ 与终值

电路：24 V 电压源串 4 Ω 电阻到节点 a，节点 a 经 12 Ω 电阻接地；电感 L = 0.5 H 接在 a 与地之间（t = 0 起接通，电感初始无电流）。求 iL(t)。

  1. 初值：iL(0⁻) = 0 → iL(0⁺) = 0
  2. 终值：稳态时电感短路，即 a-地 被短接 → 电感所在支路两端电压为 0，a 点被钳到 0 V → iL(∞) = 24/4 = 6 A
  3. 时间常数：从电感两端（a-地）看进去，电压源短路 → Req = 4 Ω ∥ 12 Ω = 3 Ω → τ = L/Req = 0.5/3 = 1/6 s ≈ 0.167 s
  4. 代公式：iL(t) = 6 + (0 − 6)e−6t = 6(1 − e−6t) A
答案：iL(t) = 6(1 − e−6t) A，t ≥ 0

看套路：τ 里的 Req 正是第 2 课"从端口看进去的等效电阻"（4 ∥ 12 = 3 Ω）；终值 6 A 恰好是"戴维南 Uoc = 18 V 除以 Req = 3 Ω"。第 2 课练熟的戴维南，在这里直接变成取 τ 和终值的工具——这就是课程链的价值。

例 3 · 换路切换：初值来自换路前，终值与 τ 来自换路后

电路：开关 S 有两个位置。t < 0 时 S 在位置 1，20 V 电源经 4 Ω 给 C = 0.5 μF 充电，已达稳态；t = 0 时 S 拨到位置 2，改为 10 V 电源经 10 Ω 与电容相连。求 uC(t)（t ≥ 0）。

  1. 初值（来自换路前）：t < 0 稳态，电容开路无电流，4 Ω 上无压降 → uC(0⁻) = 20 V → uC(0⁺) = 20 V
  2. 终值（来自换路后稳态）：位置 2 稳态，电容开路 → uC(∞) = 10 V
  3. 时间常数（来自换路后电路）：从电容两端看，位置 2 的电压源短路 → Req = 10 Ω → τ = 10 × 0.5×10⁻⁶ = 5 μs
  4. 代公式：uC(t) = 10 + (20 − 10)e−t/5μs = (10 + 10e−2×10⁵t) V
答案：uC(t) = 10 + 10e−2×10⁵t V，t ≥ 0

三要素各有出处，别用混：初值只认换路前（20 V），终值和 τ 只认换路后（10 V、10 Ω）。这是换路类题最容易翻车的地方——把旧电路的电阻拿去算 τ，或把旧稳态值当终值。

6限时练习（建议 20 分钟，做完再展开）

练 1RC 充电三要素基础模板展开对答案 ▾
电路：6 V 电压源经 3 kΩ 与 C = 2 μF 接通，电容初始未储能，t = 0 合上开关。求 uC(t) 和达到 3.79 V 需要多久。
初值 0；终值 6 V；τ = 3×10³ × 2×10⁻⁶ = 6 ms → uC(t) = 6(1 − e−t/6ms) V。达到 3.79 V（即 63.2% × 6 V = 3.79 V）所需时间 = 1τ = 6 ms

记住"1τ 完成 63.2%"这条刻度，这类"求时间"题不用解对数。

练 2RL 电路求 iL(t)τ = L / Req展开对答案 ▾
电路：15 V 电压源串 5 Ω 与 L = 2 H 回到源，电感初始无电流，t = 0 合上开关。求 iL(t) 及 3τ 时的电流值。
初值 0；终值 iL(∞) = 15/5 = 3 A；从电感两端看 Req = 5 Ω → τ = 2/5 = 0.4 s → iL(t) = 3(1 − e−2.5t) A。3τ = 1.2 s 时 iL = 3 × 95% = 2.85 A
练 3τ 易错点：看进去的等效电阻戴维南 · 区分度展开对答案 ▾
电路：12 V 电压源串 6 Ω 到节点 a，节点 a 经 3 Ω 接地；电感 L = 0.6 H 接在 a 与地之间，初始无电流，t = 0 接通。求 iL(t)。
陷阱：τ 能不能用 L/(6 + 3)？
不能！Req 是从电感两端（a-地）看进去：电压源短路 → 6 Ω ∥ 3 Ω = 2 Ω → τ = 0.6/2 = 0.3 s。终值：稳态电感短路，a 点电压钳到 0 → iL(∞) = 12/6 = 2 A。故 iL(t) = 2(1 − e−t/0.3) = 2(1 − e−3.33t) A

若错用 L/(6+3) = 0.067 s，τ 就差了 4.5 倍，整条曲线全错。记住：从动态元件两端向外看，不是沿回路把电阻相加。

7自测清单：全勾才算过关

  • 能默写换路定则 uC(0⁺) = uC(0⁻)、iL(0⁺) = iL(0⁻)，并说清"为什么只有这两个量不突变"
  • 能独立求初值：换路前稳态（C 开路 / L 短路）→ 换路定则 → 画 0⁺ 等效电路（C 换电压源、L 换电流源）
  • 能默写三要素公式 f(t) = f(∞) + [f(0⁺) − f(∞)]e−t/τ，并说清三个要素各自的来源
  • 能正确求 τ：从动态元件两端看进去求 Req，τ = ReqC 或 L/Req；含受控源时知道要用第 2 课的外加电源法
  • 记得 1τ = 63.2%、3τ ≈ 95%、5τ ≈ 99.3%，并能用它做速算估算
  • 限时练习 3 题全部独立做对，特别是练 3 的 τ 没有误用回路总电阻
