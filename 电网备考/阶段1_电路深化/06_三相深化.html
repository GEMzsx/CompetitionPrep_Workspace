阶段 1 · 第 6 课 · 2026-10-17

三相深化

不对称三相、功率测量（二表法）、中性点位移、对称分量法 —— 阶段 0 第 6 课"三相入门"的续集，南网笔试三相题的完整火力。对称是理想，不对称是现实；谁吃透不对称，谁就拿稳电网的入场券。

预计 2.5 小时 依赖：阶段0 第6课（√3 口诀）、第1课（弥尔曼定理） 南网笔试核心

1本课核心思想：从"理想对称"到"真实不对称"

阶段 0 学的三相是理想对称：三相电源对称、三相负载相同、一切公式优美（√3 口诀横着走）。但真实电网随时在不对称：

  • 居民单相负载（照明、家电）天然不均衡——A 相满载、B 相轻载是常态
  • 故障：单相接地短路（占电网故障的 80%+）、一相断线
  • 谐波（第 7 课）造成的波形不对称

对称时三相问题"化成一相算"，不对称时怎么办？本课补上三块拼图：中线的作用（三相四线制为什么是居民供电的标准形态）、中性点位移（无中线不对称的后果——烧设备的元凶）、二表法（三相功率怎么测）。最后给一把进阶钥匙：对称分量法——电力系统故障分析的官方语言。

南网视角三相是南网笔试电路部分的核心章节：二表法、中线规则、相序、不对称故障概念都是高频题。且它们直接通向后续专业课（电力系统分析、继电保护）——本课每一分都是双倍收益。

2中线：三相四线制的灵魂

居民供电为什么是三相四线制（三根相线 + 一根中线）？因为家用负载几乎全是单相的（220 V），要挂在某一相上。三相各挂的负载不一样重，中线负责"兜底"：

有中线（且中线阻抗≈0）时：负载中点 N′ 被中线和电源中点 N 钉在同一电位 → 每相负载稳稳获得相电压 220 V，各相独立计算、互不干扰——A 相开灯关灯完全不影响 B 相。这就是"各算各的"原则。

中线电流：İN = İA + İB + İC。对称时三相电流和为零，中线无电流（但绝不能拆——它是保险机制）；不对称时中线流过不平衡电流。

生死攸关的规则：中线为什么不能装熔断器、不能断开

  1. 中线一旦断开 → 不对称星形负载的公共点"失锚" → 中性点位移（下一节）
  2. 后果：轻载相电压升高超过 220 V 烧毁电器，重载相电压不足、灯光发暗——一栋楼里有的住户电器烧了、有的住户灯不亮，就是中线断了
  3. 所以规程规定：中线上严禁安装熔断器和开关，中线导线还要保证机械强度
概念高频题"为什么居民楼三相负载要尽量均衡分配？""为什么中线不能装熔丝？"——两问的答案都是本节内容：均衡→中线电流小→损耗小；熔丝一旦断，中性点位移烧设备。

3中性点位移：弥尔曼定理的高光时刻

无中线的不对称星形负载（三相三线制），负载中点 N′ 与电源中点 N 不再等电位——两者之间的电压 U̇N′N 叫中性点位移电压。求它，正是第 1 课弥尔曼定理（两节点电路秒杀公式）的直接应用：

U̇N′N = U̇A/ZA + U̇B/ZB + U̇C/ZC1/ZA + 1/ZB + 1/ZC 各相负载电压 = 电源相电压 − U̇N′N（相量减法！）

拿到 U̇N′N 后逐相修正，每相负载上的实际电压：

U̇A′ = U̇A − U̇N′N　　U̇B′ = U̇B − U̇N′N　　U̇C′ = U̇C − U̇N′N 注意是相量减法不是模值相减——必须带角度算

定性结论（判断题常客）

  • 重载相（阻抗小）电压被拉低，轻载相（阻抗大）电压被抬高——"重的吃亏，轻的遭殃"
  • 一相短路（ZA → 0）：位移电压 = U̇A，B、C 相负载电压升到线电压 380 V（√3 倍过压）——最严重的故障形态
  • 一相开路（ZA → ∞）：B、C 两相串联挂在线电压 U̇BC 上，按阻抗比分压——两相都偏离 220 V
  • 若 B、C 两相阻抗相等，一相开路时 B、C 各分得 UBC/2 = 190 V（双双欠压）
计算模板不对称三相大题的固定三步：①弥尔曼求 U̇N′N → ②逐相相量减法求实际负载电压 → ③按欧姆定律求各相电流（电流 = 电压差 ÷ 该相阻抗）。全部工具都是学过的——这就是课程链的复利。

4二表法：三相三线制功率测量的标准姿势

问题：三相三线制（无中线，如电动机、工业变压器）的总功率怎么测？直观想法是每相一块表（三表法），但三线制没法"每相单独接表"。答案是：两块就够了。

原理：三线制的 KCL 是"免费午餐"

三相三线制中 iA + iB + iC = 0 恒成立，三个电流只有两个独立——所以测两个线电流，第三个就"白送"。两块表分别接：

  • 表 1：电压线圈接 U̇AC，电流线圈串 İA → P₁ = UACIAcos∠(U̇AC, İA)
  • 表 2：电压线圈接 U̇BC，电流线圈串 İB → P₂ = UBCIBcos∠(U̇BC, İB)
  • 总功率 P = P₁ + P₂（代数和），与负载是否对称、是否纯阻统统无关

对称负载下的读数公式（计算题主力）

P₁ = ULILcos(φ − 30°)　　P₂ = ULILcos(φ + 30°) P₁ + P₂ = √3 ULILcosφ（自动回到阶段 0 的总功率公式 ✓）
负载性质功率因数角P₁P₂判读
纯电阻φ = 0°P₁ = P₂P₁ = P₂两表相等
一般感性0° < φ < 60°较大较小但为正都正，P₁ > P₂
临界φ = 60°P₁ > 0P₂ = 0表 2 读零
深感性 / 纯感φ > 60°正负表 2 反转（读数为负）
容性φ < 0°较小较大P₁ < P₂
三个高频坑① φ > 60° 时一块表读数为负（指针反偏要换接线极性），总功率仍是代数和 P₁ + P₂——不是扔掉负数；② 二表法只适用三线制，四线制（有中线电流）必须三表法；③ 对称负载下 P₁、P₂ 单独都不等于任何物理功率，只有和才有意义——别拿单表读数当某相功率。

5对称分量法：给"不对称"装上分解术（进阶）

处理不对称的"终极武器"是把不对称系统分解成三套对称系统再分别求解——这是电力系统专业的官方方法，本课建立框架：

分量三相关系相序系统中的形象
正序大小相等、互差 120°A → B → C正常运行的成分
负序大小相等、互差 120°A → C → B不对称 / 故障的标志
零序大小相等、同相位无相序接地故障、中线电流的成分

任何一组不对称三相相量 = 正序 + 负序 + 零序的叠加（数学上可证明这是唯一分解）。分解与合成借助旋转算子 a = 1∠120°（a³ = 1，1 + a + a² = 0）：

İA1 = İA + aİB + a²İC3　İA2 = İA + a²İB + aİC3　İA0 = İA + İB + İC3 零序一眼看：三相之和除 3 —— 对称运行时零序为 0，这就是中线电流的来源

为什么它强大：在对称的线性网络里，三套分量互相独立（正序、负序、零序各自单独求解，互不耦合），最后叠加。电力系统短路计算就是"三个序网分别列方程再合成"——本课不深入，但框架和 a 算子要先立住。

快速结论（记住两条就够）：① 三相电流之和为零 → 无零序分量（三线制内部永远无零序）；② 单相接地短路 → 正、负、零序三者俱全且相等（专业课再展开）。对称分量在南网笔试以概念题出现，计算题更多在考研。

6例题精讲（三道模板题）

例 1 · 中性点位移：三步模板完整走一遍

三相三线制，电源相电压 220 V（U̇A = 220∠0°，U̇B = 220∠−120°，U̇C = 220∠120°），星形负载 ZA = 10 Ω，ZB = ZC = 20 Ω（纯阻）。求中性点位移电压和各相负载电压。

  1. 弥尔曼求位移电压：分子 = 220∠0°/10 + 220∠−120°/20 + 220∠120°/20 = 22 + 11∠−120° + 11∠120°。后两项是等幅共轭对，之和 = −11（用 1∠−120° + 1∠120° = −1）。分子 = 22 − 11 = 11；分母 = 0.1 + 0.05 + 0.05 = 0.2
  2. U̇N′N = 11 / 0.2 = 55∠0° V
  3. 逐相修正：U̇A′ = 220 − 55 = 165 V（实数同相直接减）；U̇B′ = |220∠−120° − 55∠0°| = √(220² + 55² − 2×220×55×cos120°) = √63525 ≈ 252 V；同理 U̇C′ ≈ 252 V
答：U̇N′N = 55∠0° V；负载电压 A 相 165 V（重载被拉低），B、C 相各约 252 V（轻载被抬高、过压 15%）

验证直觉：A 相阻抗最小（10 Ω，重载）电压最低；B、C 相阻抗大（轻载）过压——"重载拉低、轻载抬高" ✓。若 B、C 负载是精密电器，252 V 已经开始危险了。这就是为什么供电规程盯着三相平衡不放。

例 2 · 二表法读数：对称感性负载

对称三相三线制，线电压 380 V，每相负载 Z = 10 + j10 Ω（星形）。两表法测量，求 P₁、P₂ 和总功率。

  1. 求线电流：IL = UP/|Z| = 220/√(100+100) = 220/14.14 ≈ 15.6 A
  2. 求阻抗角：φ = arctan(10/10) = 45°（感性）
  3. 表 1：P₁ = ULILcos(φ − 30°) = 380 × 15.6 × cos15° ≈ 380 × 15.6 × 0.966 ≈ 5720 W
  4. 表 2：P₂ = 380 × 15.6 × cos75° ≈ 380 × 15.6 × 0.259 ≈ 1530 W
  5. 总功率：P = 5720 + 1530 ≈ 7250 W
  6. 校验：√3 ULILcosφ = 1.732 × 380 × 15.6 × 0.707 ≈ 7250 W ✓（两路答案吻合）
答：P₁ ≈ 5720 W，P₂ ≈ 1530 W，P ≈ 7250 W

φ = 45° < 60°，两表都为正且 P₁ > P₂（感性判据）。做完必用 √3 总功率公式反验——这是二表法题的自带校验器，30 秒防计算失误。

例 3 · 一相开路：定性 + 定量双杀

三相三线制星形负载，ZA 开路（断线故障），ZB = ZC = 20 Ω 纯阻，相电压 220 V。求 B、C 相负载电压，并判断两相电器的工作状态。

  1. 定性：A 相断开后，B、C 两相负载串联挂在线电压 U̇BC = 380 V 上
  2. 定量：串联分压，两阻抗相等 → 各分一半：UB′ = UC′ = 380/2 = 190 V
  3. 判断：190 V < 220 V，B、C 两相同时欠压约 14%——电灯变暗、电机出力不足、接触器可能吸不上；长期欠压电机电流增大反而发热
答：B、C 相各 190 V，双双欠压；A 相负载完全失电

"一相开路 → 剩余两相串联分线电压"是断线故障的标准画像。若两相阻抗不等，按 ZB : ZC 分 380 V——阻抗大的那相分得多（可能过压），又是一例"轻载遭殃"。

7限时练习（建议 25 分钟，做完再展开）

练 1中线电流三相四线展开对答案 ▾
三相四线制，U̇A = 220∠0° V，纯阻负载 ZA = 22 Ω、ZB = 11 Ω、ZC = 11 Ω（星形）。求中线电流；若中线断开，哪个相最危险？
İA = 10∠0° A，İB = 20∠−120° A，İC = 20∠120° A；İN = 10 + 20∠−120° + 20∠120° = 10 + 20(−0.5 − j0.866) + 20(−0.5 + j0.866) = 10 − 10 − j17.3 + −10 + j17.3 → İN = 10∠180° A = −10 A（量 10 A）。中线断开后 A 相阻抗最大（轻载）→ A 相过压最危险。

对称时中线电流为零，不对称时不为零——本例 |İN| = 10 A 正好等于不平衡的"缺口"。注意 B、C 相电流对称抵消，只剩 A 相的 10 A 没人配对。

练 2二表法判负载性质概念深化展开对答案 ▾
二表法测得 P₁ = 1200 W，P₂ = −400 W（表 2 反偏，倒接后读 400 W）。求总功率与负载性质，并估算功率因数角的范围。
P = P₁ + P₂ = 1200 + (−400) = 800 W。P₂ < 0 → φ > 60°（感性）。由 P₂ = 0 需 φ = 60°、P₂ = −P₁ 需 φ = 90°，本题 |P₂| = P₁/3 介于两者之间 → φ ≈ 70°~80° 区间（精确 arctan 计算为约 75.5°，量级判断即可）。

核心认知：负读数不是"测量错误"，是深感性负载的正常现象；总功率永远是代数和。

练 3零序分量速判对称分量展开对答案 ▾
三相电流 İA = 100∠0° A、İB = 100∠−120° A、İC = 100∠120° A。求零序分量；若 İC 突变为 0（C 相断线），零序分量变为多少？
对称时：İA0 = (İA+İB+İC)/3 = 0（三相对称和为零）→ 零序 = 0。C 相断开后：İA0 = (İA+İB)/3 = (100∠0° + 100∠−120°)/3 = 100∠−60°/3 ≈ 33.3∠−60° A——零序出现，正是"不对称产生零序"的活例子。

零序是最容易算的分量（三相相加除 3），也是接地保护、中线电流的理论根据——记住"和为零则零序零"。

8自测清单：全勾才算过关

  • 能说清中线的兜底作用："有中线 → 各相独立吃 220 V"，以及中线上为什么严禁熔断器/开关
  • 能用弥尔曼定理求中性点位移电压 U̇N′N，并做逐相相量减法求实际负载电压（例 1 三步全走通）
  • 能背定性结论："重载拉低、轻载抬高"；一相短路 → 其余两相升到 380 V；一相开路 → 剩余两相串联分线电压
  • 能写二表法两表的接法（U̇AC×İA、U̇BC×İB）与总功率 P = P₁ + P₂（代数和），知道它只适用三线制
  • 能算对称负载读数 P₁ = ULILcos(φ∓30°)，并判读两表大小关系对应的负载性质（φ = 60°、φ > 60° 的两个临界点）
  • 能说清对称分量法的框架（正序/负序/零序 + a 算子 + 各序独立），会速算零序（三相和除 3），限时练习 3 题全对
