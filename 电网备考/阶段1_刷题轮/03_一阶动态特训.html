1本课定位与刷题法

知识轮（阶段 1 电路深化）解决"懂不懂"，本链解决"快不快、稳不稳"。一阶动态题的失分从来不在"不会三要素"，而在三个手生点：τ 求错电阻（没从储能元件端口做戴维南）、0+ 电路画错（电容 / 电感的"开关身份"记反）、全响应分解写错符号。本课要求每道动态大题 8 分钟内做完且用第二条路互检（电流关系式 ∩ 三要素直接算）——期末大题 12 分，模板化后就是保底 10 分的题。

每课统一的刷题四步（背下来）

  1. 先遮答案做例题：6 道例题先独立做（每题 ≤ 8 分钟），卡壳才看步骤，看完合上再复演一遍
  2. 限时训练整段计时：10 道题连续 40 分钟，不翻书、不查公式卡、不中途对答案
  3. 对答案评分：≥ 9 过关；错题逐道标注错因（计算 / τ 错 / 0+ 电路错 / 概念不清）
  4. 按回溯表回炉：错题按"对应知识轮坐标"回到姊妹链《一阶动态电路与三要素法》对应节，重看该节并重做该课练习
本课两条新铁律：① 换路定则只保两个量——电容电压 uC 与电感电流 iL 不能跃变，其余一切量（iC、uL、电阻电压电流）都可跃变，0+ 电路全靠"uC 当电压源、iL 当电流源"这两张身份牌画出；② τ 只认端口戴维南——源全部置零后从 C / L 两端看进去的等效电阻，τC = ReqC、τL = L/Req；用错电阻（如把串联总阻当 Req）全题报废。题目全部原创、数字全部干净可验算；看解不算练——展开过的题，隔天必须遮住重做一次。

3例题精讲（6 道 · 先遮答案独立做）

例 1 · 换路定则与 0+ 电路 —— 一切动态题的第一分钟

电路：12 V 电压源经开关 S 串 2 kΩ 接节点 a；a 经 4 kΩ 接地；a 经电容 C 接地（C 与 4 kΩ 并联）。t < 0 时 S 断开已久，t = 0 时 S 闭合。求 uC(0+)、iC(0+)、iR2(0+)，以及稳态 uC(∞)。

  1. 换路前（0−）：无源、无电荷 → uC(0−) = 0 → 换路定则 uC(0+) = 0（电容电压不能跃变）
  2. 画 0+ 电路：uC = 0 的电容 = 0 V 电压源（短路）→ a 点被钳到 0 V → iR2(0+) = 0/4k = 0；2 kΩ 上电流 = 12/2k = 6 mA，全部灌进电容 → iC(0+) = 6 mA（电容电流从 0 跳到 6 mA——完全合法，换路定则不管它）
  3. 稳态（∞）：电容开路 → 纯电阻分压 → uC(∞) = 12 × 4/(2+4) = 8 V；iC(∞) = 0
  4. KCL 全程自检：0+ 时 6 = 0 + 6 ✓；∞ 时 iR1 = iR2 = 12/6k = 2 mA、iC = 0 ✓
答案：uC(0+) = 0，iC(0+) = 6 mA，iR2(0+) = 0；uC(∞) = 8 V

卡壳回炉：0+ 电路把电容画成开路 →《知识轮第 3 课》§2"0+ 电路身份牌"：uC 已知 → 当电压源（0 V 即短路）；iL 已知 → 当电流源。本例电路是后续例 2 / 例 5 / 例 6 的母电路。

例 2 · 三要素完整流程 —— RC 充电模板

承例 1 电路：R1 = 2 kΩ，R2 = 4 kΩ，C = 3 μF，t = 0 闭合开关（uC(0−) = 0）。写出 uC(t) 与 iC(t) 的完整表达式，并求 t = τ 时刻的 uC。

  1. 三要素：uC(0+) = 0（例 1 已求）；uC(∞) = 8 V；τ = ReqC，其中 Req 从 C 两端看（12 V 置零短路）：2k∥4k = 4/3 kΩ → τ = 4 ms
  2. uC(t)：uC(t) = 8 + (0−8)e−t/4ms = 8(1 − e−t/4ms) V
  3. iC(t) 三要素直接求：iC(0+) = 6 mA、iC(∞) = 0、τ 同上 → iC(t) = 6e−t/4ms mA（三要素不只属于 uC，对任意支路量都成立）
  4. 互检（iC = C·duC/dt）：duC/dt = 8/4ms·e−t/τ = 2000e−t/τ V/s → iC = 3μ×2000e = 6e mA ✓
  5. t = τ：uC = 8 × 63.2% ≈ 5.06 V（充电过六成的锚点位置）
答案：uC(t) = 8(1 − e−t/4ms) V；iC(t) = 6e−t/4ms mA；t = τ 时 uC ≈ 5.06 V

卡壳回炉：τ 算成 (2k+4k)×C 或 2k×C →《知识轮第 3 课》§3：Req 必须"从 C 的端口"做戴维南——源置零后 R1、R2 恰好并联在 C 两端。

例 3 · RL 零输入放电 —— 电流不跃变，电压随便跳

RL 串联支路（R = 5 Ω，L = 0.1 H）：t < 0 时接在 10 V 电源上已达稳态，t = 0 时电源被断开、支路自行短接成闭合回路放电。求 iL(t)、uL(t)，并算出放电全程电阻总共耗散多少能量。

  1. 0− 稳态：电感短路（uL = 0）→ iL(0−) = 10/5 = 2 A → 换路定则 iL(0+) = 2 A
  2. τ：τ = L/R = 0.1/5 = 20 ms（零输入，无源回路，Req = R 本身）
  3. iL(t)：从 2 A 衰减到 0 → iL(t) = 2e−50t A
  4. uL(t)：uL = L·diL/dt = 0.1 × (−100e−50t) = −10e−50t V —— 换路瞬间 uL 从 0 跳到 −10 V（方向反转：放电时电感当"源"，驱动电流继续流）
  5. 能量账本：初始储能 W = ½LI² = ½ × 0.1 × 4 = 0.2 J；放电终了电感清空 → 电阻总共耗散 0.2 J（能量守恒，一步到位，不用积分）
答案：iL(t) = 2e−50t A；uL(t) = −10e−50t V；电阻共耗散 0.2 J

卡壳回炉：以为电感电压也不能跃变 →《知识轮第 3 课》§2：换路定则只保 uC 和 iL 这一对"储能状态量"；uL、iC 是"功率量"，换路瞬间随便跳。0 → −10 V 这一跳就是证据。

例 4 · 阶梯网络的 τ 与"电容开路无电流" —— 两课联动

电路：18 V 电压源串 6 Ω 接节点 M；M 经 12 Ω 接地；M 经 4 Ω 接节点 N；N 经 C = 25 μF 接地。t = 0 闭合开关接入电源（uC(0−) = 0）。求 uC(t) 与 iC(0+)。

  1. 稳态 uC(∞)：电容开路 → 4 Ω 中无电流、无压降（第 2 课例 2 的老朋友）→ uC(∞) = VM(∞) = 18 × 12/18 = 12 V
  2. Req 从 C 端口看：18 V 置零 → 从 N 看：4 Ω 串到 M，M 处 6∥12 = 4 Ω → Req = 4 + 4 = 8 Ω → τ = 8 × 25μ = 200 μs
  3. uC(t) = 12(1 − e−t/200μs) V
  4. iC(0+)：0+ 时 C 短路 → N 钳 0 → M 对地等效 12∥4 = 3 Ω → VM(0+) = 18×3/9 = 6 V → iC(0+) = 6/4 = 1.5 A（稳态时 0）
  5. 彩蛋：VM 自己也是动态量（6 V → 12 V）——"节点电位也能用三要素"，别死盯电容两端
答案：uC(t) = 12(1 − e−t/200μs) V；iC(0+) = 1.5 A

卡壳回炉：Req 只算了 4 Ω（漏并 M 处网络）或算了 6+12+4 →《知识轮第 2 课》§3 戴维南 +《第 3 课》§3：阶梯网络从储能元件端口"往回折"——这正是第 2 课练 8 的动态版。

例 5 · 非零初始 —— 全响应的两种分解

承例 1 电路（R1 = 2 kΩ，R2 = 4 kΩ，C = 3 μF，τ = 4 ms，稳态 8 V），但换路前电容已充电 uC(0−) = 5 V。写出 uC(t)，并分解为零输入 + 零状态两分量验证。

  1. 三要素：uC(0+) = 5 V（不能跃变）；uC(∞) = 8 V；τ = 4 ms（τ 与初始值无关）→ uC(t) = 8 + (5−8)e−t/4ms = 8 − 3e−t/4ms V
  2. 零输入分量（源不算了、只靠初始储能）：5e−t/τ
  3. 零状态分量（初始储能清零、只靠源）：8(1 − e−t/τ)
  4. 验证两种分解：零输入 + 零状态 = 5e + 8 − 8e = 8 − 3e ✓；另一种分解：稳态分量 8 + 暂态分量 −3e−t/τ ✓ —— 两套账本同酬
  5. 起点终点自查：t = 0 → 5 V ✓；t → ∞ → 8 V ✓；5 < 8 → 单调上升，不回头
答案：uC(t) = 8 − 3e−t/4ms V；零输入 5e−t/τ + 零状态 8(1 − e−t/τ) 之和与全响应一致

卡壳回炉：暂态系数写成 (0−∞) 而非 (初−终) →《知识轮第 3 课》§3：三要素是"终值 + (初值 − 终值)e"；分解验算是防符号错的最好保险。

例 6 · 压轴 —— 电阻电流的三要素 + 双路互检

承例 1 / 例 2 电路（uC(0−) = 0，τ = 4 ms，uC(∞) = 8 V）：求 4 kΩ 电阻中电流 iR2(t) 的完整表达式，并用第二条路互检；顺带写出 iR1(t)。

  1. 路一（三要素直接作用在 iR2 上）：iR2(0+) = 0（例 1）；iR2(∞) = 8/4k = 2 mA；τ 统一 4 ms → iR2(t) = 2 + (0−2)e−t/τ = 2(1 − e−t/4ms) mA（方向 a→地，单调上升）
  2. 路二（支路关系式）：iR2 = uC/4k = 8(1−e)/4k = 2(1−e) mA ✓ 两路一致
  3. iR1(t)：三要素：iR1(0+) = 6 mA、iR1(∞) = 2 mA → iR1(t) = 2 + 4e−t/4ms mA（从 6 衰减到 2，不归零——源一直在喂）
  4. KCL 全程核账：任意时刻 iR1 = iR2 + iC：左 = 2+4e；右 = 2−2e + 6e = 2+4e ✓ 每一个时刻都闭合
  5. 压轴结论：同一电路所有动态量共用一个 τ（一阶电路只有一个储能"惯性"）；三个电流的 0+ 与 ∞ 各验一次 KCL，就是全套答案的免费检查器
答案：iR2(t) = 2(1 − e−t/4ms) mA（双路一致）；iR1(t) = 2 + 4e−t/4ms mA

卡壳回炉：以为三要素只能求 uC、iL →《知识轮第 3 课》§3：三要素对电路里任何电压电流都成立，τ 全电路共享——求电阻电流不必先解 uC 再代数，直接套模板更快。

练 1换路定则判断题组换路定则 · ★展开对答案 ▾
判断对错并说一句理由：① 换路瞬间电容电压不能跃变；② 换路瞬间电感电流不能跃变；③ 换路瞬间电容电流可以跃变；④ 换路瞬间电感电压可以跃变；⑤ 换路瞬间电阻上电压不能跃变。
① 对（电荷不能瞬间生灭，q = Cu）｜ ② 对（磁链不能瞬间生灭，Ψ = Li）｜ ③ 对（iC 不是状态量，0+ 电路里它由外电路决定）｜ ④ 对（同③，uL = L·di/dt，di 有限时 du 可以跳）｜ ⑤ 错（电阻是即时的，uR 跟着电路跳）

⑤ 是埋雷项——"不能跃变"只属于 uC、iL 这对储能状态量。把这条边界记牢，0+ 电路题的"身份牌"就不会戴错。

练 2RL 换路：0+ 电感当电流源0+ 电路 · ★★展开对答案 ▾
电路：12 V 源串 4 Ω 接节点 a；a 经 8 Ω 接地；a 经电感 L = 0.24 H 接地（L 与 8 Ω 并联）。t < 0 稳态（开关位置 1），t = 0 双掷开关切断电源支路、同时把电感两端经 8 Ω 闭合成独立回路（位置 2）。求 iL(0+)、uL(0+)、8 Ω 电流的 0+ 值，以及 iL(t)。
0− 稳态：L 短路 → Va = 0 → iL(0−) = 12/4 = 3 A（8 Ω 被短路无电流）｜ 换路定则：iL(0+) = 3 A ｜ 0+ 电路：电感 = 3 A 电流源灌入 8 Ω 回路 → uL(0+) = −3×8 = −24 V（从换路前的 0 V 跳到 −24 V——电压随便跳的又一例）｜ τ = L/8 = 30 ms → iL(t) = 3e−t/30ms A

0− 稳态时 8 Ω 电流为 0（被短路电感旁路），0+ 时却全部扛下 3 A——0+ 与 0− 是两张不同的电路图，各算各的，别拿 0− 的图凑 0+ 的数。

练 3RC 放电经典锚点零输入 · ★展开对答案 ▾
已充电 uC(0) = 10 V 的电容 C = 2 μF 经 R = 1 kΩ 放电。求 t = τ、2τ、3τ 时的 uC；再算降到 1 V 需要多久；最后算放电全程电阻共耗散多少能量。
τ = RC = 2 ms ｜ 10×0.368 = 3.68 V；10×0.135 = 1.35 V；10×0.05 = 0.5 V（36.8% / 13.5% / 5% 三锚点）｜ 降到 1 V：10e−t/2ms = 1 → t = 2ms × ln10 ≈ 4.6 ms（≈ 2.3τ）｜ 能量 = ½CU² = ½×2μ×100 = 100 μJ（初始储能全数转热，免积分）

"ln10 ≈ 2.3"值得背——"降到十分之一要 2.3τ"，与 63.2% / 36.8% / 5% 三个锚点合成一条指数时间轴的完整直觉。

练 4三要素完整模板（含 τ 坑）三要素 · ★★展开对答案 ▾
电路：15 V 源串 3 kΩ 接节点 a；a 经 6 kΩ 接地；a 经 C = 5 μF 接地。t = 0 接入电源（uC(0−) = 0）。求 uC(t)、iC(t) 与 t = τ 时的电容电流。
uC(∞) = 15×6/9 = 10 V ｜ Req = 3k∥6k = 2 kΩ（从 C 端口！不是 3k 也不是 9k）→ τ = 10 ms ｜ uC(t) = 10(1 − e−t/10ms) V ｜ iC(0+) = 15/3k = 5 mA、∞ = 0 → iC(t) = 5e−t/10ms mA ｜ t = τ：iC = 5×0.368 ≈ 1.84 mA

本题的坑全在 τ：并联 2 kΩ ≠ 串联 3 kΩ ≠ 回路总阻 9 kΩ。0+ 电流 15/3k 用的才是"电源侧串联电阻"——求 0+ 量和求 τ 用的是两张不同的图，分清楚。

练 5RL 接通：电流爬坡与电压滑落三要素 · ★★展开对答案 ▾
24 V 源串 6 Ω 接电感 L = 0.3 H（无其他电阻）。t = 0 闭合开关。求 iL(t)、uL(t)；算 iL 到达 3 A 所需时间；并问 t = τ 时电流是终值的百分之多少。
iL(∞) = 24/6 = 4 A；τ = 0.3/6 = 50 ms ｜ iL(t) = 4(1 − e−20t) A ｜ uL(t) = 24e−20t V（0+ 时全电压落电感、∞ 时归零——与 RC 充电的 iC 完全对偶）｜ 到 3 A：4(1−e−20t) = 3 → e−20t = 0.25 → t = ln4/20 ≈ 69.3 ms（≈1.39τ）｜ t = τ：1−0.368 = 0.632 → 63.2%

RC 与 RL 的对偶记法：电容充电"电压爬坡、电流滑落"，电感接通"电流爬坡、电压滑落"——爬坡量终值 63.2% @ τ，滑落量剩 36.8% @ τ，两句话一套锚点。

练 6并联结构的 τ 与计时点τ 坑 · ★★展开对答案 ▾
电路：10 V 源串 2 Ω 接节点 a；a 经 3 Ω 接地；a 经 C = 5 μF 接地。t = 0 接入（uC(0−) = 0）。求 τ 与 uC(t)，并算 uC 升到 3 V 需要多久。
Req = 2∥3 = 1.2 Ω → τ = 1.2×5μ = 6 μs ｜ uC(∞) = 10×3/5 = 6 V → uC(t) = 6(1 − e−t/6μs) V ｜ 升到 3 V：6(1−e−t/6μs) = 3 → e−t/6μs = 0.5 → t = 6μs × ln2 ≈ 4.16 μs

两个易错点一次打包：① τ 用了 2 Ω 或 5 Ω（置零后源串阻与并联阻都在端口上，必须并联）；② ln2 ≈ 0.69 记不住就会在"到一半要 0.69τ"上卡壳——与练 3 的 ln10 ≈ 2.3 一并收进公式卡。

练 7L 与 C 同框：0+ 与 ∞ 的四张身份牌开关对偶 · ★★★展开对答案 ▾
电路：12 V 源串 2 kΩ 接节点 a；a 经 6 kΩ 接地；a 经 L 接地；a 又经（3 kΩ 串 C）接地。t = 0 接入电源，初始全零。求 0+ 与 t → ∞ 两个时刻的 Va、iL、iC（C 支路电流）。
0+ 电路（uC = 0 → C 支路 = 3 kΩ；iL = 0 → L 开路）：a 到地只剩 6k∥3k = 2 kΩ → Va(0+) = 12×2/(2+2) = 6 V；iL(0+) = 0；iC(0+) = 6/3k = 2 mA ｜ ∞ 电路（L 短路、C 开路）：Va(∞) = 0 V（L 把 a 钳到地）；iL(∞) = 12/2k = 6 mA；iC(∞) = 0（3 kΩ 白串，无电流无压降）

四张身份牌一题全齐：0+ 时 L 开路、C 短路；∞ 时 L 短路、C 开路。特别体会 Va 的落差（6 V → 0 V）：稳态图里电感把节点拖到地，0+ 图里电感把节点晾在半空——同一个元件，两张图两个性格。

练 8感性负载断路：续流二极管的价值电力电子接口 · ★★★展开对答案 ▾
RL 负载（R = 10 Ω，L = 0.2 H）由 20 V 源经开关供电，已达稳态 iL = 2 A。t = 0 断开开关。① 若无任何保护，uL 理论峰值多大？会看到什么现象？② 若在负载两端并联续流二极管（理想），写出 iL(t) 并说明二极管的作用。
① 断路瞬间 di/dt → −∞ → uL = L·di/dt → 理论无穷大（实际表现为开关触点间拉弧 / 高压击穿——储能 ½×0.2×4 = 0.4 J 要在瞬间泄放，能量不大电压极大）｜ ② 二极管为电流留退路：iL 经 D—R 回路续流，τ = L/R = 20 ms → iL(t) = 2e−t/20ms A，电压被钳在安全范围，电流体面退休

这就是电力电子里"感性负载必配续流二极管"的原理级解释——斩波电路、继电器驱动、晶闸管两端，处处是它的身影；模电第 8 课直流电源、电力电子整流章都会再会面。概念题"为什么要续流二极管"的满分答案：给电感电流一条低阻泄放路径，避免 di/dt 尖峰。

练 9全响应分解验算分解 · ★★展开对答案 ▾
某一阶电路换路后 uC(0+) = 6 V、uC(∞) = 12 V、τ = 20 ms。写出全响应，并分别写出零输入分量与零状态分量加以验证；再求 t = τ 时的 uC。
全响应：uC(t) = 12 − 6e−t/20ms V ｜ 零输入 = 6e−t/τ；零状态 = 12(1 − e−t/τ)；两者之和 = 6e + 12 − 12e = 12 − 6e ✓ ｜ t = τ：12 − 6×0.368 ≈ 9.79 V

考试写全响应后花 20 秒做这步加法验算——两分量在 t = 0 时刻必须分别回到 6 V 与 0 V、t → ∞ 都落到 0 与 12，端点对不上立刻能抓出符号错。

练 10双阶段压轴：先充后放、τ 中途易主综合 · ★★★展开对答案 ▾
电路：10 V 源串 2 kΩ 经开关 S1 接节点 a；a 经 C = 4 μF 接地；另有一条 R2 = 5 kΩ 支路从 a 到地、由开关 S2 控制。阶段一：t = 0 闭合 S1（S2 断开），uC(0−) = 0；充电充分后进入阶段二：t = T（T ≫ 阶段一时间常数）断开 S1 同时闭合 S2，电容经 R2 放电。求两阶段的 uC(t) 表达式与两阶段充电 / 放电电流的 0+ 值，并算放电全程 R2 耗散的能量。
阶段一：只有 2 kΩ 回路，τ₁ = 2k×4μ = 8 ms；uC(∞) = 10 V → uC(t) = 10(1 − e−t/8ms) V；充电电流 iC(0+) = 10/2k = 5 mA（0+ 时电容短路、源压全落 2 kΩ）｜ T 时刻 uC(T) ≈ 10 V ｜ 阶段二：回路只剩 R2，τ₂ = 5k×4μ = 20 ms，起点 10 V、终点 0 → uC(t) = 10e−(t−T)/20ms V（时间轴平移，从 T 重新起表）；放电 0+ 电流 = 10/5k = 2 mA ｜ 能量 = ½×4μ×10² = 200 μJ 全部由 R2 转热

同一只电容，两个阶段两个 τ（8 ms / 20 ms）——τ 跟着"当时所在的回路"走，开关一动就要重做端口戴维南。分段计时（第二段从 T 起表）是双阶段题的标准写法，忘写 (t−T) 是最冤的丢分。

6自测清单：全勾才算过关

  • 换路定则边界张口就来：只有 uC、iL 不能跃变，其余量都可跃变（练 1）
  • 0+ 电路身份牌默写：uC → 电压源（0 V 即短路）、iL → 电流源；0+ 时 L 开路、C 短路（例 1、练 2、练 7）
  • 稳态电路身份牌默写：∞ 时 C 开路、L 短路，纯电阻分析（例 1、练 7）
  • 三要素模板零迟疑：f(t) = f(∞) + [f(0+) − f(∞)]e−t/τ，对任意支路量成立（例 2、例 6、练 4–5）
  • τ 只认端口戴维南：源置零后从储能元件两端求 Req，并联 / 阶梯结构先"往回折"（例 2、例 4、练 4、练 6）
  • 指数锚点成套背：63.2% / 36.8% / 13.5% / 5%，降到十分之一 2.3τ、到一半 0.69τ（练 3、练 6）
  • 全响应两种分解会互验：稳态+暂态 = 零输入+零状态，端点对齐才收工（例 5、练 9）
  • 同一电路所有动态量共用一个 τ；双阶段换路后 τ 要重算（例 6、练 10）
  • 感性断路会拉弧，续流二极管给电流留退路——能说清原理与写表达式（练 8）
  • 能量账本一步到位：½CU² / ½LI² 最终全数转热，不积分（例 3、练 3、练 10）
