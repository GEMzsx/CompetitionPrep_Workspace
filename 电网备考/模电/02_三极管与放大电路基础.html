三极管与放大电路基础

模电期末的题量担当：三极管电流分配与三种工作状态 → 静态工作点估算 → 微变等效电路求动态参数。第 1 课的 PN 结在这里两个一组组装成"电流控制电流"的放大器件——期末计算大题的主产区。

16 题 · 6 例题精讲 + 10 限时训练 限时训练建议 45 分钟 期末 85+ · 电力电子前置

壹本课定位：从"造元件"到"搭电路"

第 1 课学透 PN 结，这一课用两个 PN 结拼出三极管，并第一次搭出"能放大信号的电路"。

这一课在期末卷上的分量：模电计算大题的传统主产区基本就是本章——Q 点估算 → 动态参数 → 失真判断三连，一套流程吃掉 15~20 分。对电力电子的地基意义同样直接：三极管工作在截止 / 饱和两个极端就是"开关状态"，开关电源、驱动电路全是它。

学法上，本课固化模电第二套核心动作——"先直流、后交流"。任何放大电路都拆成两套通路：直流通路求 Q 点（电容全部开路），交流通路求动态参数（电容短路、直流源置零）。两套图分开画、分开算，永远不混——这是本章第一大失分源（电容画错一套，全盘皆错）。

贰三极管：电流分配与三种工作状态

概念题（选择 / 填空）高频区，判断题的动作源头。

结构与符号速记

要点内容
结构NPN / PNP 两个背靠背的 PN 结：发射结（e–b）、集电结（c–b）。
箭头位置永远在发射极，指向发射结正偏时的电流方向：NPN 朝外（e 流出），PNP 朝内（e 流入）。
三区工艺发射区掺杂浓度最高；基区最薄且掺杂最低；集电区面积最大。所以 e、c 不能倒着用。
放大条件发射结正偏 + 集电结反偏。NPN 放大态电位关系：VC > VB > VE。

电流分配三式（必背）

IE = IB + IC　；　IC = β IB　；　IC = α IE，α = β/(1+β) ≈ 1 β：几十到几百，β ≫ 1，所以 IC ≈ IE ≫ IB；基极小电流控制集电极大电流 = "放大"的本质

三种工作状态（判断动作：先判结、再定态）

状态发射结集电结特征
截止反偏 / 零偏反偏IB ≈ 0，IC ≈ 0，相当于开关断开
放大正偏（硅 ≈ 0.7 V）反偏IC = β IB，UCE 有较大摆动空间
饱和正偏正偏UCE ≈ UCES ≈ 0.3 V，IC < β IB（由外电路决定），相当于开关闭合
判断动作固化：拿到三个极的电位，第一步算两个结的偏置——VB − VE 定发射结、VB − VC 定集电结——状态直接读表。跳过判断直接套 IC = β IB，是本章第一大坑（饱和区该式不成立，见练 3）。
温度链：温度 ↑ → β ↑、UBE ↓（约 −2 mV/℃）、ICBO ↑ → 三者同向推 IC ↑ → Q 点上移。第 1 课"本征激发随温度加剧"的因果在这里落地——分压偏置就是为压制它而生（见 §叁）。

叁放大电路：Q 点估算与微变等效——两套引擎

为什么要 Q 点：让信号整个周期都待在放大区，不失真。所有分析都是"先直流、后交流"。

两套通路（画图规则必背）

通路电容处理直流源求什么
直流通路全部开路保留Q 点：IBQ、ICQ、UCEQ
交流通路全部短路置零（接地）动态：Au、Ri、Ro

Q 点估算：两种偏置电路

固定偏置：IBQ = (VCC − UBE) / RB → ICQ = β IBQ → UCEQ = VCC − ICQ RC 结构最简，但 Q 点随 β 和温度漂——温度 ↑ → IC ↑ → Q 点上爬
分压偏置：VB = VCC·RB2/(RB1+RB2) → VE = VB − 0.7 → IEQ = VE/RE ≈ ICQ → UCEQ = VCC − ICQ(RC+RE) 工程默认电路：分压电流 ≫ IB 时 VB 被钳住，Q 点几乎与 β 无关；RE 的负反馈自动稳 Q（IC↑ → VE↑ → UBE↓ → IB↓ → 压回去）
旁路电容 CE——一脚两用 RE 稳 Q 点，但交流信号也会被它吃掉增益。并上大电容 CE：直流走 RE（稳 Q），交流被 CE 短路（保增益）。期末默认分压偏置 = RE 带 CE 旁路，微变等效里 RE 视为短路；若题目故意不并 CE，增益公式变为 Au = −βRL′/[rbe+(1+β)RE]——负反馈压增益换稳定，识别这个变体是大题加分点。

微变等效电路：三极管的小信号模型

把管子等效成两个元件：B–E 之间一个电阻 rbe，C–E 之间一个受控电流源 β ib。剩下的就是普通电路分析。

rbe = rbb′ + (1+β)·26 mV / IEQ　（rbb′ 常取 300 Ω，题目不给就用） 注意分子用的是发射极电流 IEQ，不是 IBQ；rbe 由 Q 点决定——直流算错，交流跟着全错
共射（RE 旁路）：Au = −β RL′ / rbe，RL′ = RC // RL；Ri = RB1 // RB2 // rbe；Ro ≈ RC 负号 = 输出与输入反相，这个符号在失真判断里是关键一步（见例 6）

三种组态对比（概念题必考表）

组态电压增益电流增益RiRo典型分工
共射（CE）大、反相大（β）中（rbe 量级，kΩ）中（≈ RC）电压放大主力、中间级
共集（CC，射随）≈ +1、同相大（1+β）大（可到几百 kΩ）小（十几 Ω）缓冲、输入级 / 输出级
共基（CB）大、同相≈ α < 1小（几十 Ω）大高频 / 宽频带电路

记忆锚点：只有共射电压、电流增益同时大于 1；射随"增益一、阻坑两头大反差"；共基"高频专用"。

失真判断（期末概念题最爱）

NPN 共射口诀：输出顶部削平 = 截止失真（Q 偏低）；输出底部削平 = 饱和失真（Q 偏高）。推理只有两步：vo 顶部 = iC 谷底（反相）→ 谷底触底 = 管子截止。修复方向：截止失真抬 Q（固定偏置 RB↓；分压偏置 RB1↓ 或 RB2↑），饱和失真压 Q（反向调）。

肆例题精讲 × 6

每题先自己 3 分钟，再看解法。重点学"先判结再定态、先直流后交流"的顺序感。

例 1★工作状态判断 · 电位法

NPN 硅管电路中测得三个极电位：VB = 2.7 V，VE = 2 V，VC = 6 V。判断管子工作状态。

展开解法
判发射结：VBE = 2.7 − 2 = 0.7 V > 0 → 正偏导通。
判集电结：VC − VB = 6 − 2.7 = 3.3 V > 0 → 集电极电位高于基极 → 集电结反偏。
读表：发射结正偏 + 集电结反偏 → 放大状态。
放大状态
点评：两个结的偏置各算一次，状态直接读表——"先判结、再定态"六字诀。同时满足 VC > VB > VE（NPN 放大态电位阶梯），可作快速自检。
例 2★固定偏置 · Q 点估算

固定偏置共射电路：VCC = 12 V，RB = 300 kΩ，RC = 3 kΩ，β = 50，UBE = 0.7 V。求 Q 点（IBQ、ICQ、UCEQ）。

+12 V ──┬──[RB 300k]── b｜三极管 β=50｜c ──[RC 3k]── +12 V，e 接地
展开解法
直流通路：电容全开路，基极回路就是 VCC → RB → 发射结 → 地。
IBQ = (12 − 0.7)/300 k = 11.3/300k ≈ 37.7 μA。
ICQ = 50 × 37.7 μA ≈ 1.88 mA。
UCEQ = 12 − 1.88 m × 3 k ≈ 6.35 V。
自检：UCEQ = 6.35 V，处在 (0.3, 12) 中段偏上 → 放大状态成立，Q 点健康。
IBQ ≈ 37.7 μA，ICQ ≈ 1.88 mA，UCEQ ≈ 6.35 V
点评：三步流程——基极回路求 IB、乘 β 得 IC、集电极回路求 UCE。算完必做一步"UCEQ 是否 > UCES"的自检，防饱和陷阱（练 3 专考）。
例 3★★分压偏置 · Q 点估算

分压偏置共射电路：VCC = 12 V，上偏 RB1 = 30 kΩ，下偏 RB2 = 10 kΩ，RC = 2 kΩ，RE = 1 kΩ（并 CE），β = 50，UBE = 0.7 V。求 Q 点。

展开解法
基极电位被钳住（分压电流 ≫ IB）：VB = 12 × 10/(30+10) = 3 V。
VE = 3 − 0.7 = 2.3 V → IEQ = 2.3/1k = 2.3 mA ≈ ICQ。
UCEQ = 12 − 2.3 m × (2k + 1k) = 12 − 6.9 = 5.1 V。
自检：5.1 V 位于中段 → 放大区健康；且 Q 点表达式里没有 β——换一只 β=100 的管子，Q 点几乎不动，这就是分压偏置的价值。
ICQ ≈ 2.3 mA，UCEQ = 5.1 V
点评：分压偏置四步——分压、减 0.7、除 RE、集射回路。注意 UCEQ 回路里是 (RC + RE) 两个电阻。本例电路将在例 4、例 6 连用两次，把它的参数记熟。
例 4★★微变等效 · 动态参数

承例 3 电路（空载 RL = ∞，RE 已被 CE 旁路，rbb′ = 300 Ω）。求 rbe、Au、Ri、Ro。

展开解法
rbe（用例 3 的 IEQ = 2.3 mA）：rbe = 300 + 51 × 26/2.3 ≈ 300 + 576 ≈ 876 Ω ≈ 0.88 kΩ。
Au（空载 RL′ = RC = 2 kΩ）：Au = −50 × 2/0.876 ≈ −114。
Ri：RB1 // RB2 // rbe = 30k // 10k // 0.88k = 7.5k // 0.88k ≈ 0.79 kΩ。
Ro：≈ RC = 2 kΩ（管子 C–E 理想受控源，输出电阻由 RC 定）。
rbe ≈ 876 Ω，Au ≈ −114，Ri ≈ 0.79 kΩ，Ro ≈ 2 kΩ
点评：三个高频坑——① rbe 公式分子是 (1+β)·26mV 除 IEQ；② 分压偏置的 Ri 要并上两个偏置电阻，但最终由 rbe 主导；③ 负号必须带——后面失真判断全靠它。
例 5★★射极跟随器 · 动态参数

共集电路（射随）：VCC = 12 V，RB = 200 kΩ，RE = 3 kΩ，β = 60，UBE = 0.7 V，rbb′ = 300 Ω，信号源内阻忽略。求 Q 点、Au、Ri、Ro。

展开解法
Q 点：IBQ = (12 − 0.7)/200k ≈ 56.5 μA → IEQ = 61 × 56.5 μA ≈ 3.45 mA（UCEQ = 12 − 3.45×3 ≈ 1.7 V，放大区）。
rbe = 300 + 61 × 26/3.45 ≈ 760 Ω。
Au = (1+β)RE / [rbe + (1+β)RE] = 61×3k / (0.76k + 61×3k) ≈ 183/183.8 ≈ +0.996（略小于 1，同相）。
Ri = RB // [rbe + (1+β)RE] = 200k // 183.8k ≈ 96 kΩ。
Ro = RE // (rbe + Rs)/(1+β) ≈ 3k // (760/61) ≈ 12.5 Ω。
IEQ ≈ 3.45 mA；Au ≈ +1（同相），Ri ≈ 96 kΩ，Ro ≈ 13 Ω
点评：射随的三张名片全在这——增益 1、输入百 kΩ、输出十几 Ω。"增益换阻抗"：电压增益牺牲到 ≈1，换来阻抗两头的大反差，这就是缓冲级的全部意义。Ro 公式里除以 (1+β) 把 rbe 缩小 61 倍，是"输出电阻小"的根源。
例 6★★★失真分析 · 期末大题

承例 3 电路（空载，ICQ ≈ 2.3 mA，UCEQ = 5.1 V，RC = 2 kΩ）：① 输入信号逐渐增大，输出先出现顶部削平还是底部削平？② 判断为何种失真、Q 点偏高还是偏低？③ 给出调整方案。

展开解法
量化两个方向的不失真空间（空载交流负载 RL′ = RC = 2 kΩ）：
截止方向（输出向上摆）：ICQ × RL′ = 2.3 m × 2 k = 4.6 V。
饱和方向（输出向下摆）：UCEQ − UCES = 5.1 − 0.3 = 4.8 V。
比较：4.6 < 4.8 → 输出向上摆动先触顶 → 顶部先削平 → 截止失真，Q 点偏低。
调整：抬 Q 点——RB1 减小（或 RB2 增大）→ VB↑ → ICQ↑，把向上空间撑大。理想目标是两个空间接近相等，输出摆幅才最大。
先顶部削平 = 截止失真（Q 偏低）；方案：RB1↓ 或 RB2↑ 抬高 Q 点
点评：失真判断的高配版是"量化比较"而不是背口诀——两个空间 ICQ·RL′ 与 UCEQ−UCES 谁小谁先失真。若两值接近（本例 4.6 vs 4.8），说明 Q 点设计得当；差得越多越浪费摆幅。这是期末大题的压轴语言。

伍限时训练 × 10

整段计时 45 分钟，不看书不翻笔记。做完再对答案，每题都有错因对照。

练 1★电流分配

放大状态的硅三极管 β = 100，测得 IB = 20 μA。求 IC、IE 与 α。

对答案
IC = 100 × 20 μA = 2 mA；IE = IB + IC = 2.02 mA；α = β/(1+β) = 100/101 ≈ 0.99。
IC = 2 mA，IE = 2.02 mA，α ≈ 0.99
错因对照：IE = IB + IC 是加法不是 IC = β IE（那是 α 的关系）。三式中 IE 最大、IB 最小，数量级自检一句。
练 2★★三管三态速判

三只 NPN 硅管各测得一组电位，快速判断工作状态：
A：VB = 6.7 V，VE = 6 V，VC = 12 V；
B：VB = 6.7 V，VE = 6 V，VC = 6.5 V；
C：VB = 0.3 V，VE = 0 V，VC = 12 V。

对答案
A：发射结 0.7 正偏；VC > VB 集电结反偏 → 放大。
B：发射结 0.7 正偏；VC = 6.5 < VB = 6.7 集电结正偏 → 饱和（UCE = 0.5 V）。
C：VBE = 0.3 V < 死区 0.5 V，发射结未开启 → 截止。
A 放大，B 饱和，C 截止
错因对照：C 最容易误判——0.3 V 是"正偏方向"但不到开启电压，等于没导通。"正偏"要看是否跨过死区，这是 C 组的考点；B 组看集电结那一下不能省。
练 3★★固定偏置 · 饱和陷阱

固定偏置共射：VCC = 12 V，RB = 400 kΩ，RC = 4 kΩ，β = 150，UBE = 0.7 V。求 IC 与 UCE，判断工作状态。

对答案
IBQ = 11.3/400k ≈ 28.3 μA。若直接套放大：IC = 150 × 28.3 μ ≈ 4.24 mA → UCE = 12 − 4.24×4 = −4.95 V < 0，矛盾！
矛盾说明管子不可能在放大区 → 饱和。饱和时 UCE ≈ UCES = 0.3 V，电流由外电路决定：
IC(sat) = (12 − 0.3)/4k ≈ 2.93 mA（< β IB = 4.24 mA，自洽）。
饱和状态：IC ≈ 2.93 mA，UCE ≈ 0.3 V
错因对照：β 大 = IC 大 = Q 点被顶进饱和——"β 越大越好"是错觉，固定偏置电路 β 过大反而死机。防坑动作：算完 UCEQ 必查是否 > 0.3 V；出现负值立即改按饱和求。
练 4★★分压偏置 · Q 点

分压偏置：VCC = 12 V，RB1 = 40 kΩ，RB2 = 20 kΩ，RC = 2 kΩ，RE = 2 kΩ，β = 50，UBE = 0.7 V。求 ICQ 与 UCEQ。

对答案
VB = 12 × 20/60 = 4 V → VE = 3.3 V → IEQ = 3.3/2k = 1.65 mA ≈ ICQ。
UCEQ = 12 − 1.65 m × (2k + 2k) = 12 − 6.6 = 5.4 V。
ICQ ≈ 1.65 mA，UCEQ = 5.4 V
错因对照：UCEQ 回路里是 (RC + RE) = 4 k 而不是只有 RC——漏加 RE 会得 8.7 V 的假答案。分压偏置四步流程走完顺手自检：Q 点里没有 β，这就是它抗温漂的证明。
练 5★★rbe 计算

三极管 β = 100，rbb′ = 300 Ω，静态 IEQ = 2 mA。求 rbe。

对答案
rbe = 300 + 101 × 26/2 = 300 + 1313 ≈ 1613 Ω ≈ 1.6 kΩ。
rbe ≈ 1.6 kΩ
错因对照：三个坑——漏乘 (1+β)（得 326 Ω）、用 IBQ 而非 IEQ（差百倍）、忘加 300 Ω 基区体电阻。rbe 由 Q 点决定，Q 点错它必错，后面 Au 全错——这是"先直流后交流"的因果报应。
练 6★★固定偏置 · 全动态参数

固定偏置共射（RE 无）：VCC = 12 V，RB = 300 kΩ，RC = 3 kΩ，β = 50，UBE = 0.7 V，rbb′ = 300 Ω，空载。求 rbe、Au、Ri、Ro。

对答案
IBQ ≈ 37.7 μA → IEQ = 51 × 37.7 μ ≈ 1.92 mA。
rbe = 300 + 51 × 26/1.92 ≈ 990 Ω ≈ 1 kΩ。
Au = −50 × 3k/0.99k ≈ −151；Ri = 300k // 0.99k ≈ 0.99 kΩ；Ro ≈ 3 kΩ。
rbe ≈ 1 kΩ，Au ≈ −151，Ri ≈ 1 kΩ，Ro ≈ 3 kΩ
错因对照：Ri 要并 RB，但 300 k ≫ 1 k，并联后几乎不变——共射输入电阻小的根源在 rbe，不在偏置电阻。此结论直接决定后级接入时增益的折损评估。
练 7★★★失真判断 · 概念陷阱

NPN 共射放大电路（发射极旁路电容在），示波器观察到输出电压波形顶部削平。判断：何种失真？Q 点偏高还是偏低？给出两种电路各自的调整电阻方案。

对答案
推理链：vo 顶部 = vCE 最大 = iC 最小（反相）→ iC 谷底削平 = 管子进入截止方向 → 截止失真，Q 点偏低。
固定偏置：RB ↓ → IBQ ↑ → 抬 Q。
分压偏置：RB1 ↓ 或 RB2 ↑ → VB ↑ → ICQ ↑ → 抬 Q。
截止失真（Q 偏低）；固定偏置调 RB↓，分压偏置调 RB1↓ 或 RB2↑
错因对照："顶部削平 = 饱和"是最高频错误答案——直觉跳过了"反相"这一步。必须先想输出顶部对应集电极电流的哪一头，再下结论。底部削平才是饱和失真（Q 偏高），方向正好相反。
练 8★★射极跟随器 · 动态

射随电路：VCC = 12 V，RB = 200 kΩ，RE = 3 kΩ，β = 60，UBE = 0.7 V，rbb′ = 300 Ω，信号源内阻忽略。求 Au、Ri、Ro。

对答案
IBQ = 11.3/200k ≈ 56.5 μA → IEQ ≈ 3.45 mA → rbe = 300 + 61×26/3.45 ≈ 760 Ω。
Au = 61×3k/(0.76k + 61×3k) ≈ +0.996（同相、略小于 1）。
Ri = 200k // (0.76k + 183k) ≈ 96 kΩ；Ro ≈ rbe/(1+β) = 760/61 ≈ 12.5 Ω。
Au ≈ +1（同相），Ri ≈ 96 kΩ，Ro ≈ 13 Ω
错因对照：Au 恒小于 1（分母多一个 rbe），答"等于 1"扣步骤分；Ro 别忘了也可并上 RE（3k ≫ 13 Ω，影响可忽略但要说明）。射随"增益≈1 但电流增益 61 倍"——功率放大靠的是后者。
练 9★★组态选型 · 概念

三个工程场景，各选最合适的组态（共射 / 共集 / 共基）：
① 多级放大器的中间电压放大级；② 高内阻信号源（如麦克风）的输入级；③ 高频 / 宽频带放大电路。

对答案
① 要电压增益大且反相无所谓 → 共射（电压、电流增益均 > 1，唯一全能选手）。
② 信号源内阻大 → 输入级必须"少取电流、大输入电阻" → 共集（射随）。
③ 频带要宽 → 共基（没有密勒等效带来的高频劣化，高频特性三种组态中最好）。
① 共射　② 共集　③ 共基
错因对照：② 容易选共射（以为"输入级=放大"）——但 Ri 只有 1 k 量级，接 100 k 内阻的源时信号全掉在内阻上，增益形同虚设。选型先看接口（源内阻 vs Ri、负载 vs Ro），再看增益。
练 10★★★综合压轴 · 带负载

承例 3 电路，现接负载 RL = 2 kΩ（rbe ≈ 876 Ω 已由例 4 求得，Q 点不变）。求：① 带负载后的 Au；② 最大不失真输出电压峰值 Uom。

对答案
① RL′ = RC // RL = 2k // 2k = 1 kΩ → Au = −50 × 1/0.876 ≈ −57。
② 带负载后交流负载线变陡，两个空间：截止方向 ICQ·RL′ = 2.3 m × 1k = 2.3 V；饱和方向 UCEQ − UCES = 5.1 − 0.3 = 4.8 V。
Uom = min(2.3, 4.8) = 2.3 V（先触截止端）。
Au ≈ −57（较空载 −114 腰斩），Uom ≈ 2.3 V
错因对照：两件事分开算——带负载后增益按 RL′ 折半，但最大摆幅由两个方向空间的较小者决定（也随 RL′ 变小而收缩）。空载算出的 4.6 V 在这里不适用，直接搬用是本题埋的雷。
