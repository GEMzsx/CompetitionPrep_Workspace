集成运放与运算电路

黑盒子合盖课：第 4 课拆开的"前三排"（FET 差分输入 → BJT 共射中间级 → 射随输出）在本课合上盖子，只剩同相端、反相端、输出端和两条黄金法则——虚短、虚断。比例、加减、积分微分电路全靠这两板斧撑起期末"必拿分"大题；电压比较器则是运放的非线性另一半，考研与期末双高频出题区。

16 题 · 6 例题精讲 + 10 限时训练 限时训练建议 45 分钟 期末 85+ · 运算电路必拿分

壹本课定位：合上黑盒子，两板斧走天下

第 4 课练 10 拼出了运放的内部结构——本课把盒子合上，只谈端口特性。

期末卷上的分量：运算电路是"必拿分"计算大题（反相 / 同相比例、加减法几乎年年出现在综合题里），积分微分是波形变换压轴小题，比较器（单限 / 滞回）是选择与分析题高频。本章公式量极小，但每一分都靠"虚短虚断"两条法则挣来——法则用错一步，整题全错。

与前课的连接一图流：差分输入级（第 4 课）给了运放极高的差模增益 Aod（10⁵ 起步）和极高的输入电阻——正因为增益大到离谱，线性工作时两个输入端的压差才能被压到≈0，"虚短"不是新知识，是 Aod → ∞ 的算术推论。而"虚地"就是虚短在"同相端接地"时的特例（u− ≈ u+ = 0）。本课学法主线：先立两板斧的成立条件（负反馈 → 线性区），再用节点方程把六类电路一次打通——不背模板，模板自己长出来。

贰理想运放：虚短虚断的来源与边界

两个考点：① 理想参数的推论（概念题）；② 虚短的成立条件（判断题最爱挖的坑）。

理想运放参数与三条推论

理想化条件典型实际值直接推论
Aod → ∞（差模增益）10⁵ ~ 10⁷线性区 u+ − u− → 0 → 虚短
rid → ∞（差模输入电阻）MΩ ~ GΩ（FET 输入级）输入电流 → 0 → 虚断
ro → 0（输出电阻）几十 ~ 几百 Ω输出电压与负载无关，带载不衰减（对比第 2 课分立电路的"带载折损"）
KCMR → ∞80 ~ 120 dB共模输入不产生输出（第 4 课差分给的底子）
虚短：u+ ≈ u−　（线性区：uo = Aod(u+ − u−) 有限，Aod → ∞ ⟹ u+ − u− → 0） 成立前提：运放工作在线性区——只有引入深度负反馈（输出经反馈网络接回反相端）才可能；"短"是电位近似相等，不是物理短接
虚断：i+ ≈ i− ≈ 0　（rid → ∞） 由输入电阻极大直接推出，线性区、饱和区都成立——比较器里虚短失效，虚断照用
两个工作区——判断题的第一坑：运放输出不可能超过电源摆幅。① 线性区：负反馈闭环，输出未饱和，虚短虚断都成立，uo 由外电路决定；② 饱和区：开环或正反馈，uo = ±Uom（正负电源摆幅），u+ ≠ u−，虚短不成立（只剩虚断）。考试给一个电路问"能否用虚短"，判断动作就一条：找反馈——负反馈接回反相端 → 线性区；开环 / 反馈接回同相端 → 比较器，无虚短。
两板斧使用手册——四步节点方程法 ① 确认负反馈 → 线性区，虚短虚断生效；② 用虚短写出 u−（反相比例电路里同相端接地 → u− = 0，这就是虚地）；③ 在反相端列 KCL：所有流入节点的电流 = 流出（i− = 0，输入端不吃电流）；④ 代入欧姆定律解出 uo。六类运算电路全部走完这四步——不背模板，模板自己长出来；就算电路长得再怪（多输入、梯形网络），四步照走。
平衡电阻——概念题常客：为消除输入偏置电流在两个输入端外接电阻不对称时产生的附加误差，工程上取同相端对地电阻 = 反相端外接全部电阻的并联（如反相比例：R₂ = R₁∥Rf）。理想运放模型下它不影响 uo，考试只在概念题里考"为什么"。

叁六类运算电路 + 电压比较器速查

全部公式都能用贰的四步法现场推出——先看懂，再默写，最后到"扫一眼电路就出公式"。

电路输出表达式关键特征
反相比例uo = −(Rf/R₁)·uiu− 为虚地；Ri = R₁（虚地锁定输入电阻）
同相比例uo = (1 + Rf/R₁)·ui无虚地（u− = ui）；Ri → ∞；有共模输入
电压跟随器uo = ui同相比例的 Rf → 0、R₁ → ∞ 特例；阻抗变换之王
反相加法uo = −Rf·(ui1/R₁ + ui2/R₂ + …)虚地下各路电流叠加（KCL），加权系数 = Rf/Rik
减法器uo = (Rf/R₁)·(ui2 − ui1)条件 R₁/Rf = R₂/R₃（匹配）；"运放版差分"——放大差、压共模
积分uo = −(1/RC)∫ui dt方波 → 三角波；初值由电容起始电压定
微分uo = −RC·dui/dt积分的 RC 互换；三角波 → 方波；放大噪声，实用需加小电阻限幅
反相比例：uo = −(Rf/R₁)·ui，Ri = R₁　｜　同相比例：uo = (1 + Rf/R₁)·ui 同相的"1 +"来自反馈分压点 u− = uo·R₁/(R₁+Rf)；两式的平衡电阻都取 R₁∥Rf
同相输入为什么"有共模"——接第 4 课 KCMR：反相电路 u− 虚地，两输入端电位≈0，无共模；同相电路 u+ = u− = ui，整个信号变成运放输入端的共模电压——共模分量 = ui，差模分量才是驱动输出的（ud → 0 的极限过程）。所以同相电路要求运放 KCMR 高，这正是第 4 课差分输入级死磕 KCMR 的回报现场。选择"反相还是同相"，就是在"要不要虚地 / 怕不怕共模"之间做取舍。
积分：uo = −(1/RC)∫ui dt（阶跃 ui = U 时，uo = −U·t/RC，斜直线）　｜　微分：uo = −RC·dui/dt 波形变换对：积分把方波→三角波（削平顶）、把阶跃→斜坡；微分管反。记忆锚点：电容在反馈路 = 积分，电容在输入路 = 微分

电压比较器——运放的非线性另一半

运放开环（或输出经电阻接回同相端成正反馈）使用：Aod 极大 → u+ 与 u− 差毫伏级就使输出摆到饱和，于是 uo 只取 ±Uom 两态，翻转发生在 u+ = u− 的瞬间。虚短不成立、虚断照用（比较器分析的口诀）。

单限比较器：门限 UT = UREF（参考电压）　｜　滞回（施密特）：UTH = +Uom·R₁/(R₁+Rf)，UTL = −Uom·R₁/(R₁+Rf) 反相滞回原型：ui 接反相端，输出经 Rf 正反馈到同相端、R₁ 接地；门限 = 反馈分压点电位。回差 ΔU = UTH − UTL = 2Uom·R₁/(R₁+Rf)
为什么工程上偏爱滞回——抗噪 单限比较器输入在门限附近抖动（噪声 ±几十 mV），输出跟着高频翻转（误触发）；滞回比较器有两个分离的门限，输出翻转后必须等输入"越过另一个门限"才会翻回——回差区间内输出记忆原状态。噪声幅度 < 回差/2 就完全免疫。这就是 555 施密特触发、电机驱动、欠压保护都用滞回的原因。

每题先自己 3 分钟，再看解法。例 1、例 2 的比例电路会在练 1、练 2 变形复用；例 3、例 4 的多输入电路参数会在练 5、练 6 复用——吃透两条流程，六类电路全覆盖。

例 1★反相比例 · 虚地三连问

反相比例电路：R₁ = 10 kΩ，Rf = 100 kΩ，同相端经平衡电阻 R₂ 接地，ui = 0.5 V。求：① 反相端电位与流过 R₁ 的电流；② uo 与输入电阻 Ri；③ 平衡电阻取值。

展开解法
虚地：负反馈闭环 → 线性区 → 虚短 + 同相端接地 → u− ≈ 0（虚地）。i₁ = (ui − 0)/R₁ = 0.5V/10k = 50 μA。
虚断 + KCL：i₁ 全部流入 Rf（i− = 0）→ uo = u− − if·Rf = −50μA × 100k = −5 V（用公式验算：−(Rf/R₁)·ui = −10×0.5 = −5 V ✓，两条路互检）。
Ri：从输入端看进去是 R₁ 直通虚地点 → Ri = 10 kΩ（虚地把输入电阻"钉死"在 R₁——Rf 再大也帮不上忙）。
③ R₂ = R₁∥Rf = 100/11 k ≈ 9.1 kΩ（取标称值）。
u− = 0（虚地），i₁ = 50 μA；uo = −5 V，Ri = 10 kΩ；R₂ ≈ 9.1 kΩ
点评：反相比例的三件套"虚地、Ri = R₁、增益 −Rf/R₁"一次拿齐。最高频错误：把 Ri 答成 R₁+Rf 或"R₁∥Rf"——虚地点电位为 0，从入口看只有 R₁，跟 Rf 无关。if = i₁ 这一步是后面加法器、积分器的共用骨架。
例 2★同相比例 + 跟随器

同相比例电路：R₁ = 10 kΩ，Rf = 90 kΩ，ui = 0.2 V 从同相端输入。求：① uo 与反相端电位；② 若把 Rf 短路、R₁ 开路（跟随器），uo = ？；③ 本电路两输入端的共模电压多大，为什么反相电路没有？

展开解法
① 虚短：u− = u+ = ui = 0.2 V（无虚地！）；反馈分压 u− = uo·R₁/(R₁+Rf) = uo/10 → uo = (1 + Rf/R₁)·ui = 2 V。
② 跟随器是 (1 + Rf/R₁) 的 Rf→0、R₁→∞ 特例 → 增益 = 1，uo = 0.2 V。
③ 共模分量 uc = (u+ + u−)/2 = 0.2 V——同相电路把整个输入信号原样压在两输入端上；反相电路 u+ = u− = 0，共模恒为 0。所以同相电路的精度吃 KCMR（第 4 课例 5 算过 88 dB 的那个指标），反相电路不吃。
uo = 2 V，u− = 0.2 V；跟随器 uo = 0.2 V；共模 = 0.2 V（反相电路共模恒 0）
点评：同相与反相的"1 +"之差常被死记——用"反馈分压点 = u− = ui"现场推一遍就永远不忘。比较记忆：反相（虚地、Ri = R₁、无共模、输出反相）vs 同相（无虚地、Ri→∞、有共模、输出同相、增益 ≥ 1）——四个维度对齐记，选择题秒杀。
例 3★★反相加法器

反相加法电路：ui1 = 0.4 V 经 R₁ = 20 kΩ、ui2 = 0.3 V 经 R₂ = 30 kΩ 接反相端，Rf = 60 kΩ。求 uo 与平衡电阻；并问若要实现 uo = −(3ui1 + 2ui2)，各电阻比例怎么配？

展开解法
虚地 + KCL：i₁ = 0.4/20k = 20 μA，i₂ = 0.3/30k = 10 μA，if = i₁ + i₂ = 30 μA → uo = −30μA × 60k = −1.8 V（公式验算：−(60/20×0.4 + 60/30×0.3) = −(1.2+0.6) = −1.8 V ✓）。
平衡电阻：R₃ = R₁∥R₂∥Rf：1/20 + 1/30 + 1/60 = 3/60+2/60+1/60 = 6/60 → R₃ = 10 kΩ（三电阻凑成漂亮整数）。
配比：uo = −Rf(ui1/R₁ + ui2/R₂)，系数 = Rf/Rik → 要系数 3 和 2，取 Rf = 60 kΩ、R₁ = 20 kΩ、R₂ = 30 kΩ 即可（正是本题——本题就是按这个"配方"设计的）。
uo = −1.8 V；平衡电阻 10 kΩ；系数 = Rf/Rik（Rf=60k，R₁=20k，R₂=30k）
点评：加法器 = 虚地下多条支路电流在反相端"汇流"——KCL 一列就完，加权系数由各支路电阻独立设定、互不干扰，这是它比直接并联相加优越的工程理由。设计类题（"实现某某表达式"）全是 Rf/Rik 的凑数游戏，先定 Rf 再拆系数。
例 4★★减法器 · 叠加定理推导

差分输入电路：ui1 经 R₁ = 10 kΩ 接反相端、Rf = 40 kΩ 反馈；ui2 经 R₂ = 10 kΩ 接同相端、R₃ = 40 kΩ 接地。ui1 = 0.2 V，ui2 = 0.6 V。求 uo，并用叠加定理分解验证。

展开解法
匹配检查：R₁/Rf = 10/40 = R₂/R₃ → 匹配条件成立，可用简式 uo = (Rf/R₁)(ui2 − ui1) = 4×(0.6−0.2) = 1.6 V。
叠加验证①（ui1 单独，ui2 置零接地）：u+ = 0 → 反相比例：uo′ = −(Rf/R₁)·ui1 = −4×0.2 = −0.8 V。
叠加验证②（ui2 单独，ui1 置零）：u+ = ui2·R₃/(R₂+R₃) = 0.6×40/50 = 0.48 V → uo″ = (1 + Rf/R₁)·u+ = 5×0.48 = 2.4 V。
合成：uo = −0.8 + 2.4 = 1.6 V ✓ 与简式一致——"反相减一份、同相放大一份"，匹配条件正是让两个系数咬合成 (ui2 − ui1) 的倍数。
uo = 1.6 V（= 4 × (ui2 − ui1)）
点评：减法器是"运放版差分"——放大两输入之差、抑制共模（ui1 = ui2 时输出为零，练习里会算），第 4 课的 ud/uc 语言在这里原样适用。叠加验证是处理"非匹配"变形题的万能路：不管电阻配不匹配，"反相路 + 同相路分别算再相加"永远正确；简式只有匹配时才准。
例 5★★积分电路 · 方波→三角波

反相积分电路：R = 10 kΩ，C = 0.1 μF（反馈路），ui 为 ±2 V 方波，周期 2 ms（半周期 1 ms），t = 0 时 uo(0) = +1 V。求一个周期内 uo 的波形（各时刻电位与斜率）。

展开解法
τ = RC = 10k × 0.1μF = 1 ms。ui = +2 V 期间：uo = uo(0) − (ui/RC)·t = 1 − 2t/ms → 斜率 −2 V/ms，从 +1 V 直线降到 −1 V（t = 1 ms）。
ui = −2 V 期间：uo = −1 + 2t/ms → 斜率 +2 V/ms，从 −1 V 升回 +1 V（t = 2 ms）。稳态输出 = ±1 V 三角波，与输入方波反相（积分自带负号）。
验算：半周期幅度变化 = ui·(T/2)/RC = 2×1ms/1ms = 2 V = 峰峰值 ✓；三角波线性升降，正是电容恒流充电的形状（i = ui/R 恒定 → 积分器把"恒压"变"恒流再变三角"）。
τ = 1 ms；三角波 ±1 V：+2V 段斜率 −2 V/ms（+1→−1 V），−2V 段斜率 +2 V/ms（−1→+1 V）
点评：积分题两步定形——斜率 = −ui/RC，初值 = 电容起始电压。最高频错误：忘带负号（反相积分），或用错 τ（kΩ×μF = ms 这个量纲速算要练到条件反射）。"方波→三角波"这组波形变换对在波形题里出镜率最高，配合第 2 课的失真判断，波形题全线打通。
例 6★★★滞回比较器 · 门限与传输特性

反相滞回比较器：ui 接反相端；输出经 Rf = 30 kΩ 正反馈接同相端，同相端经 R₁ = 10 kΩ 接地；输出限幅 ±Uz = ±6 V。求：① 上门限 UTH、下门限 UTL 与回差；② 描述传输特性；③ 若 ui 为幅度远大于门限的正弦波，输出是什么波形？在哪些时刻翻转？

展开解法
① 翻转条件：u− = u+，而 u+ = uo·R₁/(R₁+Rf) = ±6×10/40 = ±1.5 V → UTH = +1.5 V（uo = −6V 时）… 先别急：输出为 −6 V 时 u+ = −1.5 V，输出为 +6 V 时 u+ = +1.5 V → UTH = +1.5 V，UTL = −1.5 V，回差 ΔU = 3 V。
② 传输特性：ui 从负向正上升时，必须越过 UTH = +1.5 V 才从 +6 V 翻到 −6 V；从正向负下降时，必须跌破 UTL = −1.5 V 才翻回 +6 V——两条竖直跳变沿之间隔着 3 V 回差，输出在回差区间内"记忆"原状态。
③ 正弦输入 → 输出方波：上升沿在 ui = +1.5 V 处翻转，下降沿在 ui = −1.5 V 处翻转；若输入叠加幅度 < 1.5 V 的噪声，翻转点附近不再误抖（回差 3 V > 2×噪声）。
UTH = +1.5 V，UTL = −1.5 V，回差 3 V；输入正弦 → 输出在 ±1.5 V 处翻转的方波
点评：滞回题的骨架三问：门限（= 正反馈分压点电位）、回差（两门限之差 = 2Uom·R₁/(R₁+Rf)）、抗噪（噪声 < 回差/2 免疫）。易错点：把门限写成固定值忘了它随输出状态切换（+6V 时门限 +1.5V、−6V 时门限 −1.5V）——"门限跟输出走"是滞回的灵魂，也是它和单限的全部区别。

练 1★反相比例速算

反相比例电路：R₁ = 20 kΩ，Rf = 60 kΩ，ui = 0.4 V。求 uo、Ri、反馈电流 if 与平衡电阻。

对答案
uo = −(60/20)×0.4 = −1.2 V；Ri = R₁ = 20 kΩ。
if = i₁ = ui/R₁ = 0.4/20k = 20 μA（虚断把反馈电流锁等于输入电流）；平衡电阻 = R₁∥Rf = 20×60/80 = 15 kΩ。
uo = −1.2 V，Ri = 20 kΩ，if = 20 μA，R₂ = 15 kΩ
错因对照：增益 3 却算出 −2.4 V 的人是把 R₁、Rf 代反了——写公式前先标"谁是 R₁"（输入路）"谁是 Rf"（反馈路），标完再代数。平衡电阻 R₁∥Rf 若答成 20+60 也常见——是并联。
练 2★同相比例速算

同相比例电路：R₁ = 10 kΩ，Rf = 40 kΩ，ui = 0.3 V。求 uo 与反相端电位；若同一组电阻改接成反相比例，uo 又是多少？

对答案
同相：uo = (1 + 40/10)×0.3 = 1.5 V；u− = ui = 0.3 V（虚短无虚地）。
改反相：uo = −(40/10)×0.3 = −1.2 V——同一组电阻，"1 +"和"−"之差。
同相：1.5 V（u− = 0.3 V）；改反相：−1.2 V
错因对照：同相增益误写 40/10 = 4（丢"1 +"）是本电路第一大错——用分压点验算：u− = 1.5×10/50 = 0.3 V = ui ✓。快速自检习惯：算完 uo，反代分压式看是否还原回 ui，半秒钟排除 80% 的代数错。
练 3★跟随器 · 阻抗变换应用

高内阻信号源 Us = 0.75 V、Rs = 100 kΩ，负载 RL = 20 kΩ。① 直接连接，负载上得到多少伏？② 中间加电压跟随器，负载上得到多少伏？③ 跟随器在这里的职能是什么（用第 2 课射随的语言）？

对答案
① 分压：0.75×20/(100+20) = 0.125 V——内阻吃掉 5/6，信号几乎全军覆没。
② 跟随器 Ri → ∞（信号源不分压）、Ro → 0（负载不分压）→ uo = ui = 0.75 V。
③ 与射随完全同款职能：阻抗变换 / 缓冲隔离——"增益换阻抗"（增益 1 分不要，Ri 从 20k 换成 ∞、Ro 换成 0）。射随是"晶体管版"，跟随器是"运放版"，公式骨架同源。
① 0.125 V　② 0.75 V　③ 阻抗变换缓冲（Ri→∞ 进、Ro→0 出）
错因对照：② 误答"0.75×20/(0+20) = 0.75V 但仍要乘跟随器增益 0.99"——理想运放下跟随器增益精确为 1（不是射随的 ≈1），别把第 2 课的近似习惯带过来。① 的 0.125 V 是命题人给的"痛点铺垫"，看到它就条件反射"上缓冲"。
练 4★★虚短成立条件 · 概念判断

判断对错并说理：① 运放引入深度负反馈工作在线性区时，虚短成立；② 开环电压比较器中，虚短成立；③ "虚短"指两个输入端被短接在一起；④ 虚断在线性区和饱和区都成立；⑤ 反相比例电路中"虚地"是虚短加同相端接地的直接结果。

对答案
① 对——负反馈把输出拉回未饱和区，uo = Aod(u+−u−) 有限 ⟹ u+ ≈ u−。
② 错——开环时 uo = ±Uom 饱和，u+ − u− = uo/Aod ≈ mV 级不为零（只是小）；虚短按定义不成立（比较器正是利用这个差来翻转）。
③ 错——是"电位近似相等"，绝非物理短接（物理短接了运放就没法工作了）；"虚"字就是"近似、并非真"。
④ 对——虚断只依赖 rid → ∞，与输出是否饱和无关；比较器分析就靠它。
⑤ 对——虚短给出 u− = u+，同相端接地 → u+ = 0 → u− = 0 = 虚地。
① 对　② 错　③ 错　④ 对　⑤ 对
错因对照：②③ 是两大高频坑——②混淆"输入差很小"与"虚短成立"（成立条件是线性区，不是差小）；③把"虚"字丢掉。判断动作固定化：先找反馈类型，再谈虚短；先看 rid，才谈虚断。
练 5★★承例 3 · 加法器变输入

承例 3 电路（R₁ = 20 k，R₂ = 30 k，Rf = 60 k）。改输入 ui1 = 0.5 V，ui2 = −0.3 V。求 uo，并问该电路对 ui2 的增益是多少、什么符号？

对答案
uo = −(60/20×0.5 + 60/30×(−0.3)) = −(1.5 − 0.6) = −0.9 V。
节点法验算：i₁ = 0.5/20k = 25 μA，i₂ = −0.3/30k = −10 μA，if = 15 μA → uo = −15μA×60k = −0.9 V ✓。
对 ui2 的增益 = −Rf/R₂ = −2（负号——反相端输入，各路都带负号；"加法"加的是带符号加权和）。
uo = −0.9 V；ui2 路增益 = −2
错因对照：负输入进来时最常见的错是符号处理——加权和中 −Rf/Rk 这个"整体负号"要贯穿每一路，别只在第一路带。另一个坑：认为 ui2 路增益是 −Rf/R₂ 与 ui1 路无关就"各路独立"，方向对——但前提是虚地把两路电流隔离在各支路里，虚地是加法器互不串扰的机制根源。
练 6★★减法器 · 共模视角

四电阻全取 10 kΩ 的差分输入电路：ui1 = 2.5 V 接反相路，ui2 = 4.5 V 接同相路。① 求 uo；② 输入的共模分量多大？③ 为什么说减法器是"运放版差分"？

对答案
① 匹配（R₁/Rf = R₂/R₃ = 1）→ uo = 1×(ui2 − ui1) = 4.5 − 2.5 = 2 V。叠加验算：u+ = 4.5/2 = 2.25 V，uo = 2×2.25 − 2.5 = 2 V ✓。
② uc = (2.5+4.5)/2 = 3.5 V（第 4 课公式原样搬来）。
③ 输出只认差模（ud = 2 V×1 倍），共模被电路结构抵消（ui1 = ui2 时 uo = 0）——与差分放大"放大差、压共模"完全同构；差别是运放的 KCMR 靠内部差分输入级保证，电阻匹配靠外部精度保证（匹配破坏时共模泄漏，正好接第 4 课"对称性是免费的精度"）。
uo = 2 V；共模 3.5 V；输出 = 差模 ×1，共模理想为零
错因对照：① 若用"增益 = Rf/R₁ = 1"却写出 uo = ui1 − ui2（方向反）——减法器输出永远是同相端信号减反相端信号的 Rf/R₁ 倍；②忘记共模公式对运放电路同样适用。跨章提示：第 4 课的 ud/uc 分解语言在本课是"通用语"。
练 7★★两级运放级联

两级运放级联：第一级反相比例 R₁ = 10 k、Rf = 100 k；第二级反相比例 R₁ = 10 k、Rf = 40 k。ui = 0.1 V。求总增益与 uo；并回答：级间需要像分立电路那样考虑"带载折损"吗？

对答案
Au1 = −100/10 = −10；Au2 = −40/10 = −4 → Au = (−10)×(−4) = +40（负负得正，两级反相级联同相——第 4 课级联相位规则照用）。
uo = 40×0.1 = 4 V。
不需要——理想运放 ro → 0（第一级输出是理想电压源，被接多少负载都不掉电压）+ rid → ∞（第二级输入不取电流）→ 级间零负载效应。这正是运放电路级联总增益 = 各级增益直乘的原因，与第 4 课例 2 分立级联的"带载折损"形成鲜明对照——分立级联"1+1<2"，运放级联"1+1=2"。
Au = +40，uo = 4 V；级间无负载效应（ro→0 且 rid→∞）
错因对照：把第 4 课的"从后往前、带载重算"硬搬过来是知识迁移过度——先判断"理想运放还是分立电路"，再选级联规则。但相位规则通用：奇数级反相 → 反相。考试挖坑方式：给分立级联问要不要重算带载（要），给运放级联也问（不要）——一句话判据"输出电阻为不为零"。
练 8★★积分器 · 三角波幅度

反相积分电路：R = 10 kΩ，C = 0.05 μF，ui = ±3 V 方波，周期 1 ms（半周期 0.5 ms），稳态工作。求：① τ；② 输出三角波的峰峰值与幅度；③ 输出与输入的相位关系；④ 若把 R、C 位置互换，电路变成什么、输出表达式如何？

对答案
① τ = RC = 10k × 0.05μF = 0.5 ms。
② 半周期幅度摆动 = ui·(T/2)/τ = 3×0.5/0.5 = 3 V → 稳态三角波 ±1.5 V（峰峰值 3 V）。
③ ui = +3 V 期间 uo 下降、−3 V 期间上升 → 输出相对输入反相（积分自带负号，例 5 同款）。
④ R、C 互换 → 微分电路：uo = −RC·dui/dt——对三角波输入输出方波。记忆锚点：电容在反馈路积分、在输入路微分。
τ = 0.5 ms；三角波 ±1.5 V（峰峰 3 V）；反相；互换后为微分电路 uo = −RC·dui/dt
错因对照：峰峰值算成 1.5 V 的人漏了"半周期摆动 = 3 V、半边才是 1.5 V"的换算——三角波幅度定义先问清楚（幅度 / 峰峰值差一倍）。④ 的互换判断常被记反，回到机制想：电容充放电"慢"的那一侧决定积分、串在输入"取变化率"的那一侧决定微分。
练 9★★单限比较器 · 传输特性

单限比较器：ui 接反相端，同相端接参考电压 UREF = 2 V，运放输出 ±Uom = ±12 V（开环）。① 画出 / 描述传输特性；② ui 从 0 V 缓慢升到 5 V，输出如何变化？③ 此电路里虚短、虚断各是什么状态？

对答案
① ui < 2 V 时 u+ > u− → uo = +12 V；ui > 2 V 时 → uo = −12 V；跳变沿在 ui = UT = 2 V 处（门限 = 参考电压）。
② 0 → 2 V 段保持 +12 V；越过 2 V 瞬间跳到 −12 V，此后保持——输出只与"ui 在门限哪一侧"有关，与幅度大小无关。
③ 开环 → 饱和区 → 虚短不成立（翻转瞬间 u+ = u− 只是临界点，不是工作常态）；虚断仍成立（rid → ∞ 与接法无关）。比较器分析口诀："没有虚短，只有虚断，比较两端谁高"。
门限 2 V：低于 +12 V、高于 −12 V；ui 升过 2 V 时从 +12 V 跳 −12 V；虚短不成立、虚断成立
错因对照：输出方向搞反（ui > UREF 时答 +12 V）——反相端输入的规则是"输入高、输出低"，跳变方向由输入接哪个端决定，画传输特性前先标端。③ 是比较器与运算电路的分水岭判断题，练 4 的延续。
练 10★★★滞回比较器 · 抗噪设计

反相滞回比较器：输出限幅 ±Uz = ±6 V，同相端经 R₁ = 20 kΩ 接地、经 Rf = 20 kΩ 接输出。① 求 UTH、UTL、回差；② 若输入信号叠加幅度 1 V 的噪声，输出会误翻转吗？③ 要让回差变为 4 V，R₁ 或 Rf 怎么调？

对答案
① u+ = uo·R₁/(R₁+Rf) = ±6×20/40 = ±3 V → UTH = +3 V，UTL = −3 V，回差 6 V。
② 翻转要求输入越过另一个门限：输出为 −6 V 时门限 +3 V，噪声 1 V 只能把有效输入推到门限 ±1 V 之内，够不着另一侧门限（间距 6 V）→ 不误翻转（判据：噪声 < 回差/2 即免疫，1 < 3 ✓）。
③ 回差 = 2Uz·R₁/(R₁+Rf)：要 4 V → R₁/(R₁+Rf) = 1/3 → Rf = 2R₁（如 R₁ = 20 k、Rf = 40 k，或保持 Rf = 20 k 把 R₁ 减到 10 k）。
UTH = +3 V，UTL = −3 V，回差 6 V；噪声 1 V < 3 V 不误翻转；调 Rf = 2R₁（比值 1/3）回差变 4 V
错因对照：③ 最常见的错是把回差公式写成 Uom·R₁/(R₁+Rf)（丢系数 2——回差是两个门限之差，门限各带一个 ±Uom）。② 的判据"噪声 < 回差/2"要理解成：门限附近抖动 ±噪声，只要抖动范围不出回差区间就不误翻——设计题常反向问"回差至少取多少"，答案 = 2×噪声幅度。

陆过关自测清单

  • 理想运放四参数与推论：Aod→∞ 出虚短、rid→∞ 出虚断、ro→0 带载不衰减、KCMR→∞ 共模零输出
  • 虚短 = 电位近似相等（非短接），只在线性区（负反馈）成立；虚断两区都成立——先找反馈再谈虚短
  • 四步节点方程法：判反馈 → 写 u− → 反相端 KCL → 解 uo；虚地 = 虚短 + 同相端接地的特例
  • 反相比例：−(Rf/R₁)ui、虚地、Ri = R₁、无共模；同相比例：(1+Rf/R₁)ui、无虚地、Ri→∞、有共模（吃 KCMR）
  • 跟随器：增益 1、阻抗变换之王（Ri→∞ 进、Ro→0 出）——高内阻源必配缓冲
  • 反相加法：−Rf·Σ(uik/Rk)，虚地隔离各路、系数独立可配；平衡电阻 = 反相端外接电阻全并联
  • 减法器：匹配时 uo = (Rf/R₁)(ui2−ui1)；"运放版差分"，共模理想为零；非匹配用叠加拆两路
  • 积分 −(1/RC)∫uidt（方波→三角波，斜率 = −ui/τ）；微分 −RC·dui/dt（三角→方波）；τ = RC 量纲速算 kΩ·μF = ms
  • 比较器：开环/正反馈 → 无虚短有虚断；单限门限 = UREF；滞回门限随输出切换，回差 = 2Uom·R₁/(R₁+Rf)
  • 滞回抗噪判据：噪声 < 回差/2 免疫；设计题反算回差 = 2×噪声；能说清跟随器与射随、减法器与差分的同构关系
