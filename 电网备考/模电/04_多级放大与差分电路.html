多级放大与差分电路

从单级到系统的第一步：一级共射只有 −100 倍，电压表放大 1 μV 级信号要 10⁵ 倍——必须级联；级联引入耦合问题，直接耦合又带来零点漂移，差分电路用对称性给出漂亮答案。本课还是集成运放的"内部结构预演"：输入级差分 + 中间级共射 + 输出级跟随——第 5 课的"黑盒子"在这里拆开看。

16 题 · 6 例题精讲 + 10 限时训练 限时训练建议 45 分钟 期末 85+ · 运放内部结构

壹本课定位：为什么要"多级"，为什么要"差分"

两个工程问题引出全章：增益不够 → 级联；级联用直接耦合 → 温漂逐级放大 → 差分。

期末卷上的分量：差分放大是高频大题（差模增益 + 共模增益 + KCMR 三连问几乎每年一题），多级级联是中频常规题（总增益与 Ri/Ro），耦合方式与零漂是概念选择 / 判断题的常客。本章计算的"原料"全部来自第 2、3 课——Q 点估算、微变等效、rbe、gm，没有新公式负担，只有新组装规则和新概念（差模 / 共模、KCMR）。

学法上，本课有一条主线贯穿："对称性是一种免费的精度"——差分电路不加任何元件，靠两边对称就把共模干扰 / 温漂抵消掉；这条思路在数字电路（差分信号线）、电力系统（差动保护！继保科的原理同名远亲）里反复出现。对电力电子的接口意义：直接耦合 + 差分 + 恒流源，这三件套就是集成运放内部的"前三排"，第 5 课运放所有"虚短虚断"的魔法，都建立在本课的差分输入级上。

贰多级放大：耦合方式与级联计算

两个考点：① 三种耦合方式选谁（概念题）；② 级联计算三规则（计算题）。

级联计算三规则

规则一：Au总 = Au1 × Au2 × … × Aun（注意：前级的增益必须按"带后级负载"算） 第 2 课例 6 的"带载折损"在每一级交界处发生：RL1′ = RC1 // Ri2，Ri2 就是第一级的负载
规则二：Ri = 第一级的输入电阻　　规则三：Ro = 最后一级的输出电阻 "入口看第一级，出口看最后一级"——中间级只以"负载"和"放大器"两种身份出现

增益乘出来还要看相位：奇数个反相级（共射 / 共源）总增益为负（反相），偶数个为正（同相）——两级共射"负负得正"，这是级联题里最爱考的一步。多级增益常用分贝累加：20 lg|Au总| = Σ 20lg|Aui|，乘法变加法。

组合套路——运放内部的"前三排" 输入级用差分（抗共模、抗温漂、FET 版输入电阻 MΩ 级）→ 中间级用共射（高 gm 撑总增益，第 3 课"BJT 做增益"的分工）→ 输出级用射随 / 源随（低 Ro 带负载）。第 5 课集成运放的"黑盒子"拆开就是这三排，本课先把它当多级放大器逐排理解。

叁差分放大：对称性抵消一切"两边相同"的干扰

本章大题主角。三个新概念（差模 / 共模 / KCMR）+ 一张四种接法对照表，全部考点在内。

差模与共模：任意输入的分解

差模分量：ud = ui1 − ui2　　　共模分量：uc = ( ui1 + ui2 ) / 2 ui1 = uc + ud/2，ui2 = uc − ud/2——任何一对输入都能唯一分解；输出 = Ad·ud + Ac·uc

物理直觉：差模 = 想要的信号（两边一增一减，方向相反）；共模 = 不想要的（两边同涨同落）——温漂、电源纹波、工频干扰都是共模（它们同时、等量作用于两边）。差分的全部设计目标：放大差模，绞杀共模。

长尾式差分电路（典型电路，大题原型）

结构：两个对称的共射电路，发射极连在一起经长尾电阻 RE 接 −VEE，两个基极输入、两个集电极输出。Q 点由 −VEE + RE 钳定（对每管：IEQ ≈ VEE/2RE）。

对差模：RE 上电流不变（一管增大多少另一管就减小多少）→ 发射极公共点交流地 → RE 不出场 差模增益走"纯共射"通道：双端输出 Ad = −β·RC / ( rbe + Rb )，与单管共射同款公式（RE 消失）
对共模：两边电流同涨同落，全部流过 RE → 每管等效"发射极串 2RE 的共射"（RE 上的压降翻倍计） 双端输出：两边完全对称，uo1 = uo2 → Ac = 0（理想对称时共模全抵消）；单端输出：Ac = −β·RC / [ rbe + 2(1+β)RE ]，靠 2(1+β)RE 这只大手把 Ac 压到极小

共模抑制比 KCMR 与四种接法

KCMR = | Ad / Ac |，常用分贝：KCMR(dB) = 20 lg KCMR 衡量"放差模、杀共模"的综合本领，越大越好；集成运放 80–120 dB 起步
接法差模增益 Ad共模增益 AcKCMR特点 / 用途
双入双出−βRC/(rbe+Rb)（= 单管共射）= 0（对称抵消）→ ∞（理想）增益最大、抑制最强，集成运放输入级原型
双入单出减半≠ 0，靠 2(1+β)RE 压低大（有限）需一端接地时用；RE 越大越好 → 上恒流源
单入双出同双入双出= 0→ ∞单端信号也能差分放大（分解成差模+共模理解）
单入单出减半≠ 0大最"经济"，但牺牲一半增益与抑制
恒流源差分——KCMR 的终极形态：单出时 KCMR ∝ RE，但 RE 调大受 Q 点限制（RE 太大 → IEQ 被压小 → 管 β 还没干活就饿死）。解法：用恒流源替代 RE——恒流源直流压降不大（Q 点保住）、交流电阻极大（Ac 压到近零），"直流当小电阻、交流当大电阻"两头通吃。镜像电流源是其中最常用的一种（两只匹配 BJT，IC2 ≈ IREF，还顺带当有源负载把增益再抬一个量级）。期末考"如何提高 KCMR"，标准答案就是这句。
概念一次看清——发射极公共点的三种身份 ① 差模输入时是虚地（一增一减电流抵消，RE 上无变化）；② 共模输入时是"深负反馈点"（同涨同落全过 RE，反馈电阻等效 2RE）；③ 求静态工作点时是"分流基准"（总电流 VEE/RE 对半分）。同一个节点，三种身份对应三类题——先问自己在算什么，再决定 RE 怎么出场。

每题先自己 3 分钟，再看解法。例 2 的两级参数会在练 2、练 3 复用，例 4 的差分参数会在例 5、例 6 连用——两套电路吃透两套流程。

例 1★耦合方式选择

三个放大任务，各选最合适的耦合方式并说一句理由：① 放大热电偶输出的缓变直流（mV 级，频率近零）；② 音频功放前级（20 Hz – 20 kHz，各级 Q 点需独立调整）；③ 集成电路内部的级间耦合。

展开解法
① 必须直接耦合——直流 / 缓变信号过不了电容，阻容耦合直接把信号隔死；代价是必须处理零漂（信号本来就小，温漂淹没风险最高，所以热电偶仪表放大器输入级必是差分）。
② 阻容耦合——音频不含直流成分，电容隔直让各级 Q 点完全独立、设计互不干扰；低频端电容取大即可（下限频率 = 1/2πRC）。
③ 直接耦合——芯片里造不出 μF 级大电容（硅片面积），也造不出变压器；集成电路天然全直接耦合，所以零漂问题必须由差分输入级解决——这就是运放输入级的由来。
① 直接耦合　② 阻容耦合　③ 直接耦合
点评：这道概念题背后是三条因果链——直流信号 → 必须直接耦合 → 必有零漂 → 必上差分。期末判断题常把它拆开来考（"阻容耦合能放大直流"“变压器耦合便于集成"都是×），把因果链背顺，怎么拆都不慌。
例 2★★两级级联 · 总增益与阻抗

两级共射阻容耦合放大器：第一级 β₁ = 50，rbe1 = 1 kΩ，RC1 = 3 kΩ，偏置网络 RB1 = 20 kΩ；第二级 β₂ = 50，rbe2 = 1 kΩ，RC2 = 2 kΩ，偏置网络 RB2 = 20 kΩ。空载。求各级电压增益、总增益（含相位判断）、Ri、Ro。

展开解法
第二级先算（空载）：Au2 = −β₂RC2/rbe2 = −50×2 = −100。
第二级的输入电阻 = 第一级的负载：Ri2 = RB2//rbe2 = 20k//1k ≈ 0.95 kΩ → RL1′ = RC1//Ri2 = 3k//0.95k ≈ 0.72 kΩ。
第一级带载增益：Au1 = −β₁RL1′/rbe1 = −50×0.72 = −36（空载本有 −150，被第二级吃掉一大半——"带载折损"在级间交界处发生）。
总增益：Au = (−36)×(−100) = +3600——两级共射负负得正，输出与输入同相。
Ri = 第一级输入电阻：RB1//rbe1 = 20k//1k ≈ 0.95 kΩ；Ro = 末级输出电阻：RC2 = 2 kΩ。
Au1 = −36（带载），Au2 = −100，Au总 = +3600（同相）；Ri ≈ 0.95 kΩ，Ro = 2 kΩ
点评：级联计算的标准顺序是"从后往前"——先算末级（它没有后级负载，最自由），它的 Ri 作为前级负载往前推。若第一级先按空载算成 −150 再乘，本题直接错一倍以上。本例参数在练 2、练 3 复用，把"从后往前"固化成动作。
例 3★★直接耦合 · Q 点牵连

直接耦合两级放大器：第一级 NPN 共射（VCC = 12 V，RC1 = 5.1 kΩ，ICQ1 = 1 mA），集电极直接接第二级 NPN 管基极；第二级发射极串 RE2 = 2 kΩ 后接地。求：① VB2 = VC1；② IEQ2；③ 若第二级发射极直接接地（RE2 = 0），会发生什么？

展开解法
① VC1 = VCC − ICQ1·RC1 = 12 − 1×5.1 = 6.9 V。
② VB2 = 6.9 V → VE2 = 6.9 − 0.7 = 6.2 V → IEQ2 = 6.2/2k = 3.1 mA（Q 点由两级共同确定——牵连）。
③ RE2 = 0 时 VE2 = 0 → VB2 被钳在 0.7 V → 第一级的 UCEQ1 被压到 0.7 V（临近饱和），同时第二级基极电流剧烈增大（6.2 V 全部砸在 be 结上）——两级都无法正常工作。
VB2 = 6.9 V；IEQ2 = 3.1 mA；RE2 = 0 时第一级被拖入饱和，电路失效
点评：直接耦合"各级 Q 点牵连"就考这一手——RE2 在这里的职能是电平配置（抬高第二级发射极电位，给第一级留出 UCE 空间）。对照阻容耦合各级 Q 完全独立：这是两种耦合在计算题里的分水岭。
例 4★★差分双入双出 · 差模参数

长尾式差分放大电路：VCC = 12 V，−VEE = −12 V，RC = 10 kΩ，RE = 10 kΩ（长尾），两管 β = 100，rbe = 2 kΩ（Q 点已求得：每管 ICQ ≈ 0.55 mA）。基极回路电阻忽略。求双端输出的差模增益 Ad、差模输入电阻 Rid、输出电阻 Ro，并写出共模增益 Ac。

展开解法
差模半电路：发射极公共点对差模是虚地，RE 不出场 → 每边就是一个纯共射。
Ad = −β·RC/rbe = −100×10k/2k = −500。
Rid：从两输入端看进去是两个 rbe 串联（中间虚地）→ Rid = 2rbe = 4 kΩ。
Ro：双端输出从两个集电极看 → Ro = 2RC = 20 kΩ。
Ac：双端输出 + 理想对称 → 两边输出相等相减 → Ac = 0，共模全抵消。
Ad = −500，Rid = 4 kΩ，Ro = 20 kΩ，Ac = 0
点评：差分大题的"半电路分析法"——差模走虚地半电路（共射公式直接用），共模走 2RE 半电路。Rid = 2rbe、Ro = 2RC 这两个"×2"是双端专属，单端输出时不乘 2——高频扣分点。本例参数在例 5、例 6 连用。
例 5★★★单端输出 · 共模增益与 KCMR

承例 4 电路改为单端输出（从 T₁ 集电极取输出）。求：① 单端输出的差模增益 Ad；② 共模增益 Ac；③ KCMR（倍数与 dB）；④ 若把 RE 换成恒流源（动态电阻 500 kΩ），Ac 与 KCMR 变成多少？

展开解法
① 单端只取一边输出，差模增益减半：Ad = −β·RC/2rbe = −250。
② 共模半电路：每管等效发射极串 2RE = 20 kΩ → Ac = −β·RC/[rbe + 2(1+β)RE] = −100×10/(2 + 2×101×10) k = −1000/2022 ≈ −0.49（近似 −RC/2RE = −0.5）。
③ KCMR = |Ad/Ac| = 250/0.49 ≈ 505 ≈ 20lg505 ≈ 54 dB。
④ 恒流源后：Ac ≈ −1000/(2 + 2×101×500) ≈ −0.0099；KCMR = 250/0.0099 ≈ 25000 ≈ 88 dB——KCMR 抬了 34 dB，差模增益一分没动。
① Ad = −250　② Ac ≈ −0.49　③ KCMR ≈ 505（54 dB）　④ Ac ≈ −0.0099，KCMR ≈ 88 dB
点评：③④ 两问就是"如何提高 KCMR"的定量版——增大 RE（换恒流源）只压 Ac，不动 Ad，KCMR 纯赚。近似式 Ac ≈ −RC/2RE（β 大时）可当速算验算用。注意单端输出的 Ro = RC（不乘 2），且从 T₁ 输出为反相、从 T₂ 输出为同相——选择题常设"单出相位"坑。
例 6★★★任意信号分解 · 输出合成

承例 4 / 例 5 的差分电路（双出：Ad = −500，Ac = 0；单出：Ad = −250，Ac = −0.49）。输入 ui1 = 10 mV，ui2 = 6 mV。求：① 差模、共模分量；② 双端输出 uo；③ 单端输出 uo1，并算出其中共模贡献占比。

展开解法
① ud = 10 − 6 = 4 mV；uc = (10+6)/2 = 8 mV（验算：ui1 = 8+2 = 10 ✓，ui2 = 8−2 = 6 ✓）。
② 双出：uo = Ad·ud + Ac·uc = −500×4m + 0×8m = −2 V（共模分量被对称性完全抹掉）。
③ 单出：uo1 = −250×4m + (−0.49)×8m = −1000m − 3.9m ≈ −1.004 V。
共模贡献占比：|−3.9 mV| / |−1003.9 mV| ≈ 0.39%——差模贡献是共模的约 255 倍（= KCMR 的物理含义本身）。
① ud = 4 mV，uc = 8 mV　② uo = −2 V　③ uo1 ≈ −1.004 V（共模贡献仅 0.39%）
点评：任意输入分解是差分章的"万能入口"——单端输入、比较输入、干扰叠加全都先分解再各走各的通道。KCMR 的物理含义就在③里现形：它就是输出端"差模贡献与共模贡献的倍数比"。期末大题常按"分解 → 双出/单出分别求 → 算占比"三步给分。

练 1★耦合概念速判

判断并说理：① 阻容耦合放大器不能放大直流信号；② 直接耦合各级静态工作点相互独立；③ 变压器耦合便于集成；④ 阻容耦合放大器的零点漂移会被逐级放大。

对答案
① 对——电容隔直，直流 / 缓变信号过不去（低频端增益按 1/ωC 衰减）。
② 错——恰恰相反，直接耦合各级 Q 点相互牵连（例 3），需要电平配置；相互独立是阻容耦合的性质。
③ 错——变压器体积大、无法集成，集成电路里只能直接耦合。
④ 错——零漂是缓变直流量，电容把它隔断在各级之内，不会被逐级传递放大；逐级放大零漂的是直接耦合。
① 对　② 错　③ 错　④ 错
错因对照：④ 是最高频错误——把"直接耦合的命门"错记到阻容耦合头上。记忆锚点：谁通直流，谁传零漂。
练 2★★承例 2 · 三级级联

承例 2 的两级（Au1 = −36 带载，Au2 = −100）末端再加一级射极跟随器（Au3 ≈ 0.99，其输入电阻作为第二级负载后 Au2 变为 −80）。求总增益与输出相位；若用 dB 表示，前两级共多少 dB？

对答案
Au总 = (−36)×(−80)×0.99 ≈ +2851（两反相级负负得正，射随同相 → 输出与输入同相）。
前两级：20lg|36×80| = 20lg2880 ≈ 69.2 dB；含射随总增益 ≈ 20lg2851 ≈ 69.1 dB。
Au总 ≈ +2851（同相）；约 69 dB
错因对照：坑在"其输入电阻作为第二级负载后 Au2 变为 −80"——加射随后第二级增益变了，必须用新值相乘；直接拿 −100 去乘（得 3564）就掉坑。加任何一级，前一级都要按带载重算——规则一的完整含义。射随增益 ≈ 1 却"白拿"阻抗变换，这就是它当输出级的价值。
练 3★★承例 2 · 阻抗归属

承例 2 电路（Ri ≈ 0.95 kΩ，Ro = 2 kΩ）。若把第一级换成 FET 共源（Ri = 1 MΩ，Au = −8，其余不变）：① 新的 Ri？② 总增益约多少（第二级作为其空载负载已算得增益 −100）？③ 这印证了第 3 课练 9 的哪条结论？

对答案
① Ri = 第一级的输入电阻 = 1 MΩ（末级不变，Ro 仍为 2 kΩ）。
② Au = (−8)×(−100) = +800——FET 级自身增益小，但它输入阻抗高、且几乎不消耗前级（这里无前级）/自身带载能力强弱由 RD 定；组合增益仍可观。
③ 印证"FET 做接口、BJT 做增益"——第一级 FET 提供高输入阻抗扛高内阻信号源，第二级 BJT 共射提供大增益。这正是运放输入级 FET 差分 + 中间级 BJT 共射的微缩版。
① Ri = 1 MΩ　② Au ≈ +800（同相）　③ FET 做接口、BJT 做增益
错因对照：常见错误是把 Ri 答成"两级输入电阻的乘积/并联"——多级 Ri 只由第一级决定，后级输入电阻只以"负载"身份影响前级增益，不改变系统入口。同理 Ro 只由末级决定。
练 4★★信号分解速算

分解以下输入为差模 + 共模：① ui1 = 15 mV，ui2 = 5 mV；② ui1 = 8 mV，ui2 = 0（单端输入）；③ ui1 = ui2 = 10 mV（纯共模）。并说明 ② 证明了差分电路的什么能力。

对答案
① ud = 10 mV，uc = 10 mV。
② ud = 8 mV，uc = 4 mV——单端输入 = 一半差模 + 一半共模，差分照常放大（单入双出增益与双入相同）。
③ ud = 0，uc = 10 mV——纯共模，理想双出输出为零，单出只剩极小的 Ac·uc。
② 证明差分不要求两路平衡输入：任何单端信号自动分解出差模分量被放大——这就是"单入双出"接法能用的原因，也是差分接口灵活性的来源。
① ud = 10 mV，uc = 10 mV　② ud = 8 mV，uc = 4 mV　③ ud = 0，uc = 10 mV
错因对照：② 最常见错误是认为"单端输入没有差模"——差模定义是 ui1 − ui2，与是否双端驱动无关。验算习惯：分解后必须能还原（uc + ud/2 = ui1）。
练 5★★虚地概念 · 差模通道

长尾式差分（RE = 10 kΩ）输入差模信号时，发射极公共点的电压变化量是多少？为什么？由此说明 RE 对差模增益的影响。

对答案
公共点电压不变（ΔuE = 0，虚地）：差模下一管 iE 增大 Δi、另一管减小 Δi，流过 RE 的总电流恒定 → RE 上压降不变。
因此 RE 对差模信号完全不产生反馈、不出现在差模增益公式里——差模增益就是纯共射的 −βRC/rbe。
对照：共模时两管电流同向，RE 上变化 2Δi，等效每管串 2RE——同一个电阻对差模隐身、对共模翻倍，这就是差分"放差模杀共模"的机制核心。
ΔuE = 0（虚地）；RE 不影响差模增益，只压制共模
错因对照：把 RE（或 2RE）写进差模增益公式是本章计算第一大错——差模半电路里 RE 必须消失。反过来，共模公式忘乘 2 是第二大错。判定动作：先问"差模还是共模"，再画半电路。
练 6★★单出 vs 双出对比

同一长尾差分（β = 100，rbe = 2 kΩ，RC = 10 kΩ，RE = 10 kΩ）。分别求双出与单出（T₁ 侧）的 Ad、Ac、KCMR，并说明各自输出相位。

对答案
双出：Ad = −100×10/2 = −500（ui1 正半周时 uo 反相）；Ac = 0；KCMR → ∞。
单出：Ad = −250（差模增益减半，T₁ 侧反相）；Ac ≈ −0.49；KCMR ≈ 505（54 dB）。
相位：双出以 ui1−ui2 为参考反相；单出从 T₁ 取反相、从 T₂ 取同相（增益绝对值同 250）——"换个集电极取输出，相位翻 180°"，差分自带反相/同相两个输出端。
双出：−500 / 0 / ∞；单出：−250 / −0.49 / 505（T₁ 反相，T₂ 同相）
错因对照：① 单出差模增益忘除 2；② 以为单出 KCMR 也是 ∞（只有理想对称双出才是）；③ 相位只记"反相"不问从哪边取。三个坑都在"双出→单出"的转换动作里，转换口诀：增益减半、共模现身、相位看边。
练 7★★★KCMR 物理含义

某差分放大器 Ad = 1000，KCMR = 80 dB。① 求 Ac；② 输入含差模 1 mV + 共模 100 mV（强干扰环境），求输出中信号与干扰各占多少；③ 由此说明 KCMR 的工程意义。

对答案
① 80 dB → KCMR = 10^(80/20) = 10⁴ → Ac = 1000/10⁴ = 0.1。
② 信号输出 = 1000×1m = 1 V；干扰输出 = 0.1×100m = 10 mV——干扰虽强 100 倍，输出端只占 1%。
③ 工程意义：KCMR 就是"信噪比改善倍数"——它把"输入端干扰/信号比"压缩 10⁴ 倍再输出。工业现场共模干扰（工频耦合、地电位差）往往比信号大几个量级，没有高 KCMR 信号直接被淹没；这就是仪表放大器、运放输入级死磕 KCMR 的原因。
① Ac = 0.1　② 信号 1 V，干扰仅 10 mV（1%）　③ KCMR = 信噪比改善倍数
错因对照：dB 换算错（80 dB 误当 80 倍）会让全题崩盘——电压比 dB = 20lg，10⁴ 才是 80 dB。② 的算式顺序也常反：是先分别放大再比，不是先算输入端比值（100:1）——输出端比值 = 输入端比值 ÷ KCMR，方向别除反。
练 8★★恒流源差分 · 概念论证

长尾差分把 RE 换成恒流源 I₀ = 1.1 mA（动态电阻 ro = 500 kΩ）。说明：① 为什么 Q 点不受影响甚至更稳？② 为什么差模增益不受影响？③ 为什么 KCMR 大幅提高？④ 镜像电流源"两只管子电流相等"靠什么实现？

对答案
① 恒流源给每管提供恒定 IEQ = I₀/2 = 0.55 mA，且恒流源的直流压降可在合理范围设置（不像大 RE 会吃掉全部负电源）；电流恒定 → Q 点"钉死"，温漂、电源波动都推不动。
② 差模下公共点仍是虚地（两管电流一增一减、总和 = I₀ 恒定）→ 恒流源对差模隐身，Ad = −βRC/rbe 不变。
③ 共模下等效发射极电阻 = 2ro = 1 MΩ ≫ 2RE = 20 kΩ → Ac 被压低约 50 倍，KCMR 抬高同样倍数（例 5 ④ 已算：54 dB → 88 dB）。
④ 镜像电流源靠两只管子的制造对称性 + VBE 相等：参考管把 VBE "复制"给输出管，同工艺同参数 → IC 相等——集成电路里相邻管子天然匹配，这正是"对称性是免费的精度"的又一次兑现。
① 电流恒定钉死 Q 点　② 差模下公共点虚地，恒流源隐身　③ 共模等效 2ro 巨大，压低 Ac　④ VBE 复制 + 制造对称
错因对照："提高 KCMR 为什么不直接加大 RE"——答"也可以"只对一半：RE 大到一定程度负电源电压不够维持 Q 点电流（−VEE ≈ 2IEQRE）；恒流源才是"交流大电阻 + 直流小压降"的两全解。判断题在此设坑。
练 9★★差分 Q 点估算

长尾差分：VCC = 12 V，−VEE = −12 V，RE = 11 kΩ，RC = 10 kΩ，两管对称。估算：① 每管 ICQ；② 每管 UCEQ（提示：UE ≈ −0.7 V）。

对答案
① 流过 RE 的总电流 IRE ≈ [VE − (−VEE)]/RE = (−0.7 + 12)/11k ≈ 1.03 mA → 每管 IEQ = ICQ ≈ 0.52 mA。
② VC = 12 − 0.52×10 = 6.8 V；UCEQ = VC − VE = 6.8 − (−0.7) = 7.5 V（Q 点居中偏上，健康）。
速算锚点：发射极电位被 be 结钳在 ≈ −0.7 V（两基极近似接地时），所以长尾电流基本只由 VEE 和 RE 决定，与管子参数几乎无关——这正是差分 Q 点稳的第一层原因。
ICQ ≈ 0.52 mA，UCEQ ≈ 7.5 V
错因对照：① 忘除 2（把总电流当单管电流）是最常见错；② 求 UCEQ 时把 VE 当 0 V（漏 −0.7）或忘减负电源。注意这套估算法则与第 2 课"分压偏置四步"不同源：差分 Q 点走"VEE–RE 钳流"路线，别把发射极接地共射的套路硬搬过来。
练 10★★★运放内部结构 · 跨章压轴

用本章知识"拼"出集成运放的内部结构并回答：① 输入级为什么用差分而不直接用单管共射？② 输入级为什么常用 FET 差分（连接第 3 课）？③ 中间级为什么用 BJT 共射（连接第 3 课练 10）？④ 输出级为什么用射随？⑤ 运放"两个输入端"对应差分的什么？

对答案
① 直接耦合的运放全电路无电容隔直，单管共射的零漂会被后级放大 10⁵ 倍级淹没信号；差分靠对称性把共模（温漂）抵消——双出 Ac = 0，这是"能做直流放大"的前提。
② FET 差分输入电阻 MΩ~GΩ 级、几乎零偏置电流——信号源内阻再高也不衰减；BJT 差分 rbe 只有 kΩ 级且要基极电流（第 3 课 Ri 对照：10.3 MΩ vs 0.79 kΩ）。
③ 中间级要总增益（运放开环增益 10⁵ 起步）：BJT 的 gm = ICQ/26mV 约 88 mS，FET 只有几 mS（第 3 课练 10 的 22 倍差距）——BJT 做增益引擎，再配镜像电流源当有源负载把增益再抬一个量级。
④ 输出级要带负载：射随 Ro 小（十几 Ω）、电流驱动能力强——"增益换阻抗"（第 2 课例 5）。
⑤ 运放的同相 / 反相输入端对应差分的两个基极：u+ − u− 就是差模输入 ud——第 5 课"虚短"成立的前提（Aod → ∞ 时 ud → 0），黑盒子里装的就是本课的差分。
① 抗零漂/共模　② 高输入阻抗　③ 高 gm 高增益　④ 低输出阻抗带负载　⑤ 同相/反相端 = 差分两基极，ud = u+ − u−
错因对照：各问的"标准答案关键词"——① 差分抵消温漂（不是"增益大"）；② 阻抗（不是"噪声小"为主）；③ gm/增益（不是"速度快"）；④ 带负载。第 5 课学运放时若对"虚短虚断"感到突兀，回来重做本题——运放的全部"魔法"都是本课 + 第 2、3 课的物理组合。

陆过关自测清单

  • 三种耦合方式一句话对比：阻容（隔直、Q 独立）、直接（通直、Q 牵连、零漂）、变压器（阻抗变换、难集成）
  • 零点漂移定义 + 因果链：温漂 → 直接耦合逐级放大 → 第一级危害最大 → 差分输入级解决
  • 级联三规则：总增益连乘（前级按带后级负载算）、Ri 看第一级、Ro 看末级；计算顺序"从后往前"
  • 两级共射负负得正（同相）；dB 累加：总 dB = 各级 dB 之和
  • 任意输入分解：ud = ui1 − ui2，uc = (ui1 + ui2)/2，输出 = Adud + Acuc
  • 发射极公共点三身份：差模虚地（RE 隐身）、共模 2RE（深负反馈）、静态钳流（VEE/RE 对半分）
  • 双出 Ad = −βRC/rbe、Ac = 0；单出增益减半、Ac ≈ −RC/2RE；Rid = 2rbe（双出专属 ×2）
  • KCMR = |Ad/Ac|，dB = 20lg；物理含义 = 输出端信噪比改善倍数
  • 提高 KCMR 标准答案：恒流源替代 RE（交流大电阻 + 直流小压降，差模增益不损失）
  • 能复述运放"前三排"：FET 差分输入（抗漂移 + 高阻）→ BJT 共射中间级（高 gm）→ 射随输出（低 Ro），ud = u+ − u− 是虚短伏笔
