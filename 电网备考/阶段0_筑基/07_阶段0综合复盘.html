阶段 0 筑基 · 综合复盘 · 2026-10-08

六课武功，合成一套

六课学的是零件，复盘装成整机：先对照知识地图自查每课的"毕业标准"，再打一场 10 题跨课混合测试——每一题都要同时调用两门以上课程工具。这是阶段 0 课程链的毕业典礼。

预计 1.5 – 2 小时 知识地图 + 6 大陷阱 + 10 题混合测试 六课全过关后解锁

?本页怎么用

  1. 过地图（约 20 分钟）：对照下表逐课自问"加粗的这几样我还能不能不看书写出来"——写不出的课，先回去翻对应课程页再回来。
  2. 打测试（整卷限时 60 分钟）：10 题全部手算，做完再统一翻答案。每题右侧标注了它调用哪几课的工具。
  3. 定去向（约 5 分钟）：全对 → 汇报教练，正式切换"跟课内 + 周复盘"模式；有错 → 按错题定位回炉，然后重做该题。
复盘的意义：六课过关只说明"每门单独考我都会"；南网笔试从不单课设问——一道三相功率题里同时藏着相量、阻抗、功率因数。链条上任何一环掉链子，整题报废。

图知识地图：六课是一条链

第 6 课结尾说过，六课的顺序不是随机的：

复数 （工具） → 相量 （语言） → 阻抗 （元件脾气） → 相量法 （解题框架） → 功率 （能量账本） → 谐振与三相 （电网母语）
课角色毕业标准：不看笔记还能默写的
01 复数与相量运算工具代数式 ⇌ 极坐标式 ⇌ 指数式互化；负实部 → 辐角在 90°–180°（象限陷阱）；除法 = 模相除、辐角相减；共轭
02 正弦量与相量表示语言三要素（幅值 / 频率 / 初相）；有效值 = 幅值 / √2（220 V 的真身）；相位差判超前 / 滞后；正弦量相加 = 相量相加
03 R、L、C 与阻抗元件脾气ZR = R、ZL = jωL、ZC = −j/(ωC)（负号！）；阻抗三角形 |Z|² = R² + X²；φ = arctan(X/R)
04 相量法解正弦稳态解题框架五步法：正弦量→相量 → 算总阻抗 → 解复数代数（串并联 / 分压分流）→ 反变换回时域 → 相量图验证
05 功率与功率因数能量账本P = UIcosφ、Q = UIsinφ、S = UI、S² = P² + Q²；cosφ 低 → 线路损耗大；补偿容量 QC = P(tanφ₁ − tanφ₂)
06 谐振与三相电网母语f₀ = 1/(2π√LC)；串联谐振：Z 最小、I 最大、元件电压 QU；Y：U线 = √3U相；△：I线 = √3I相；P = √3U线I线cosφ
一题通吃：下面混合测试的 Q10 就是"整条链调用"的活样本——读正弦量（第 2 课）→ 求每相阻抗（第 3 课）→ Y/△ 换算（第 6 课 √3）→ 算总功率（第 5 + 6 课公式）→ 用复数模验证（第 1 课）。考的从来不是记忆，是工具箱的调用顺序。

坑六大陷阱：血泪与高频

前六课你踩过的坑 + 南网笔试的埋雷点，按"再踩一次代价"排序。测试前先过一遍，测试中它们还会出现。

  1. 象限陷阱（第 1 课）：负实部复数的辐角在第二象限（90°–180°）。例：−0.5 + j3.5 的辐角是 98.1°，不是 −81.9°，更不是 81.9°。正确姿势：实部为负，arctan 出来先加 180°。
  2. 有效值 ≠ 幅值（第 2 课）：220 V 是有效值，幅值 311 V。功率计算永远用有效值；绝缘耐压设计才关心幅值。正确姿势：看到"220 V"先问自己——√2 乘不乘？
  3. 容抗负号（第 3 课）：ZC = 1/(jωC) = −j/(ωC)。丢了负号，X 永远算正，谐振条件 XL = XC 永远"不成立"。正确姿势：j 在分母 = 乘 −j 上去。
  4. 补偿量的条件（第 5 课 Q7 教训）：QC = P(tanφ₁ − tanφ₂) 里，tanφ₂ 由目标功率因数决定；"全补偿"= cosφ₂ → 1、tanφ₂ = 0、QC = P·tanφ₁。正确姿势：先问"补到多少"，再动公式。
  5. √3 的方向（第 6 课）：Y 接电压差 √3、△ 接电流差 √3；功率公式线量进线量出。方向记反，三相题全灭。正确姿势：口诀"星压角流"，功率公式认准 U线I线。
  6. 谐振 = 隐身 ≠ 消失（第 6 课）：谐振时 UL 与 UC 反相抵消、对电源"隐身"，但各自电压 = QU，可达电源电压的几十上百倍。说"电感电压为零"是错的。正确姿势：抵消发生在总电压层面，元件电压一个都不小。

测跨课混合测试（整卷限时 60 分钟）

10 题手算，做完再展开答案。每题右侧标签标注调用课程。评分：10/10 毕业；8–9 道对，回炉错题对应课；≤7 道对，说明链条有环节松动，按错误分布重看第 3、4 课（最常松的两环）。

Q1把 (3 + j4)/(1 − j1) 化成极坐标式。考 01点击展开 ▾

除法 = 模相除、辐角相减，但先化成乘法更稳：(3 + j4)/(1 − j) = (3 + j4)(1 + j)/|1 − j|² = (−1 + j7)/2 = −0.5 + j3.5。

模 = √(0.25 + 12.25) = √12.5 ≈ 3.54；实部为负、虚部为正 → 第二象限，辐角 = 180° − arctan(3.5/0.5) = 180° − 81.9° = 98.1°。

≈ 3.54 ∠ 98.1°

陷阱 1 原题重现：负实部 → 辐角加 180°。答 −81.9° 或 81.9° 都是被同一块石头绊倒。

Q2i₁ = 10√2 sin(ωt + 30°) A，i₂ = 10√2 sin(ωt − 60°) A。求总电流 i = i₁ + i₂ 的瞬时表达式。考 01·02点击展开 ▾

化相量：İ₁ = 10∠30° = 8.66 + j5；İ₂ = 10∠−60° = 5 − j8.66。

相加：İ = 13.66 − j3.66，模 = √200 ≈ 14.14，辐角 = arctan(−3.66/13.66) = −15°，即 İ = 14.14∠−15° A。

反变换（有效值 × √2 回幅值）：i = 14.14√2 sin(ωt − 15°) = 20 sin(ωt − 15°) A。

i = 20 sin(ωt − 15°) A

正弦量相加永远"先化相量再算"，硬套和角公式容易翻车；把有效值直接相加（10 + 10 = 20 A）也是错的——20 是算出来的幅值，纯属巧合的数字面具。

Q3R = 30 Ω 与 XL = 40 Ω 串联。求 Z、|Z|、功率因数与电路性质。考 03点击展开 ▾

Z = 30 + j40，|Z| = √(30² + 40²) = 50 Ω，φ = arctan(40/30) ≈ 53.1°。

cosφ = R/|Z| = 30/50 = 0.6；X = XL − XC = 40 − 0 > 0 → 感性。

Z = 50∠53.1° Ω，cosφ = 0.6，感性

这就是 3-4-5 直角三角形——电路题里出现 30/40/50、6/8/10 这类勾股数组，是命题人留的"算术善意"，也是检查自己有没有算错的锚点。

Q4RLC 串联电路接 u = 100√2 sin(314t) V，R = 40 Ω，XL = 30 Ω，XC = 25 Ω。求 i(t)，并判断电路性质。考 03·04点击展开 ▾

Z = 40 + j(30 − 25) = 40 + j5，|Z| = √(1600 + 25) ≈ 40.3 Ω，φ = arctan(5/40) ≈ 7.1°。

İ = U̇/Z = 100∠0°/40.3∠7.1° ≈ 2.48∠−7.1° A。

反变换：i ≈ 2.48√2 sin(314t − 7.1°) A；X = +5 > 0 → 感性。

i ≈ 3.5 sin(314t − 7.1°) A（有效值 2.48 A），感性

电路里有电容 ≠ 电路呈容性——性质只由 X = XL − XC 的符号决定，这是判断题的常驻嘉宾。

Q5感性负载 Z = 40 + j30 Ω 接在 U = 200 V 电源上。求电流、P、Q、S、cosφ。考 04·05点击展开 ▾

|Z| = 50 Ω → I = 200/50 = 4 A；cosφ = 40/50 = 0.8，sinφ = 0.6。

P = UIcosφ = 200 × 4 × 0.8 = 640 W；Q = UIsinφ = 200 × 4 × 0.6 = 480 var；S = UI = 800 VA。

验算：S² = P² + Q² → 640² + 480² = 640 000 = 800² ✓（勾股自洽）。

I = 4 A，P = 640 W，Q = 480 var，S = 800 VA，cosφ = 0.8

另一条路验证：P = I²R = 16 × 40 = 640 W ✓。一道题两个独立算法互相咬合，才是"真的会"——考场上这就是你的验算本能。

Q6某感性负载 P = 1000 W、cosφ₁ = 0.5。要把功率因数提到 cosφ₂ = 0.8，需要补偿多少无功？考 05点击展开 ▾

cosφ₁ = 0.5 → φ₁ = 60°，tanφ₁ = 1.732；cosφ₂ = 0.8 → φ₂ = 36.9°，tanφ₂ = 0.75。

QC = P(tanφ₁ − tanφ₂) = 1000 × (1.732 − 0.75) ≈ 982 var。

约 982 var（欠补偿到 0.8，不必到 1）

Q7 修正案的原班人马：先看清目标 cosφ 再动公式。工程上"全补偿"反而不做——过补偿会让电路变容性、抬高电压，补偿到 0.8–0.95 才是常态。

Q7R = 10 Ω、L = 100 μH、C = 100 pF 串联。求谐振频率 f₀、特性阻抗 ρ、品质因数 Q；若电源电压 10 V 且频率恰为 f₀，电容电压多大？考 06点击展开 ▾

ω₀ = 1/√(LC) = 1/√(10⁻⁴ × 10⁻¹⁰) = 1/10⁻⁷ = 10⁷ rad/s → f₀ = ω₀/2π ≈ 1.59 MHz。

ρ = √(L/C) = √(10⁻⁴/10⁻¹⁰) = √10⁶ = 1000 Ω；Q = ρ/R = 1000/10 = 100。

谐振时 UC = QU = 100 × 10 = 1000 V。

f₀ ≈ 1.59 MHz，ρ = 1000 Ω，Q = 100，U_C = 1000 V（电源的 100 倍）

Q = 100 是通信级的高品质因数（选频极尖锐、通频带极窄）——收音机锁台靠的就是它。同一个公式，电网人看到的是"过电压烧设备"，通信人看到的是"频道隔离"——这就是第 6 课说的工程两面性。

Q8R = 10 Ω、XL = XC = 40 Ω 串联，接 U = 100 V（频率恰使 XL = XC）。求电流 I 与电感电压 UL。考 04·06点击展开 ▾

电抗互相抵消：Z = 10 + j(40 − 40) = 10∠0° Ω → I = U/|Z| = 100/10 = 10 A（与电源同相）。

UL = I·XL = 10 × 40 = 400 V——电源电压的 4 倍。UC 同为 400 V，两者反相抵消，对外"隐身"。

I = 10 A（同相），U_L = 400 V = 4U

KVL 没有失效：各元件电压相量求和才是 100 V（400∠−90° + 400∠90° + 100∠0° = 100∠0° ✓）。相量的"和"不等于"模的和"——这是第 4 课相量图给你的最深一课。

Q9对称三相 Y–Y 电路，电源相电压 220 V，每相负载 Z = 22∠60° Ω。求线电流与三相总有功功率。考 02·03·05·06点击展开 ▾

Y 接：U相 = 220 V 直接加在每相负载上 → I相 = U相/|Z| = 220/22 = 10 A；Y 接 I线 = I相 = 10 A。

三相功率（相量版）：P = 3U相I相cosφ = 3 × 220 × 10 × cos60° = 3 × 220 × 10 × 0.5 = 3300 W = 3.3 kW。

线量版验证：U线 = 220√3 ≈ 381 V，P = √3 × 381 × 10 × 0.5 ≈ 3300 W ✓。

I 线 = 10 A，P = 3.3 kW

cosφ 就是每相负载的阻抗角余弦（60° → 0.5），与接法无关。两个功率公式算同一道题必须咬合——这就是"一题通吃"的完整版。

Q10把 Q9 的同一负载改为 △ 接，接回同一线电压（U线 = 220√3 V）。求相电流、线电流与三相总功率——功率变为几倍？考 04·06点击展开 ▾

△ 接每相直接承受线电压：U相 = U线 = 220√3 V → I相 = 220√3/22 = 10√3 ≈ 17.32 A。

△ 接 I线 = √3 I相 = √3 × 10√3 = 30 A。

P = 3U相I相cosφ = 3 × 220√3 × 10√3 × 0.5 = 3 × 220 × 10 × 3 × 0.5 = 9900 W = 9.9 kW。

对比 Q9：9.9/3.3 = 3 倍。

I 相 = 10√3 ≈ 17.32 A，I 线 = 30 A，P = 9.9 kW —— 同一线电压下 △ 是 Y 的 3 倍

"√3 × √3 = 3"的整活：相电压涨 √3 倍、相电流再涨 √3 倍，功率两次涨 → 3 倍。三相电动机"星三角降压起动"就靠这一手：起动时 Y 接把电流功率压到 1/3，转起来再切 △——这就是你未来工作中最常见的一个电路操作。
