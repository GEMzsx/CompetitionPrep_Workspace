阶段 0 筑基 · 第 2 课

正弦量与相量表示

上一课磨好了复数这把刀，这一课把刀用在正弦交流电上：把 u = Um·sin(ωt + φ) 变成相量 U∠φ —— 从此交流电路的加减计算降维成复数四则运算。这是整个正弦稳态分析的第一块基石。

预计 1.5–2 小时 5 个知识块 · 4 道例题 · 8 道练习 承接第 1 课复数运算

?先认识主角：电网的心跳是正弦波

中国电网的电压是 50 Hz 正弦交流电 —— 每秒完成 50 次完整的振荡，电压从 0 涨到峰值、回落穿过零、反向到负峰值、再回到 0，如此往复。发电厂的发电机转一圈，就送出一个完整的正弦周期：正弦波不是"选择"，而是旋转发电的天然产物。

为什么正弦这么好用？数学上有条黄金性质：同频率的正弦量做加、减、求导、积分，结果仍是同频率的正弦量（只变幅值和初相）。这意味着整个线性交流电路里，所有电压电流"长得一样"，唯一区别是大小和先后 —— 而大小与先后，恰好是复数的模与辐角。相量法就是利用这一点，把微积分方程降维成代数方程。
南网考点电路科目考纲的「相量法与正弦稳态」与「三相电路」两章全部建立在本课之上；"三要素、有效值、相位差"三个概念更是直接出题的常客。

1正弦量三要素：幅值、角频率、初相位

一个正弦电压的完整写法：

u(t) = Um · sin(ωt + φ)
Um —— 幅值（最大值）　 ω —— 角频率（rad/s）　 φ —— 初相位

知道这三个量，这个正弦量就被完全确定 —— 所以叫三要素。逐个看：

  • 幅值 Um：波峰的高度。注意它不是"220V"—— 见知识块 3。
  • 角频率 ω：振荡的快慢。ω = 2πf = 2π/T（T 是周期）。中国电网 f = 50 Hz，所以：
ω = 2π × 50 = 100π ≈ 314 rad/s　　T = 1/f = 0.02 s
这两个数是电力行业的"常识级"数字，见到 314 就要想 50Hz，反之亦然
  • 初相位 φ：t = 0 时刻波形所处的"起跑位置"。φ > 0 波形左移（提前起跑），φ < 0 右移。

同频率的三个正弦量长什么样

图 1：同频率、不同初相位的三个正弦量。初相越大越"提前"，波形越靠左。

2相位差：谁超前、谁滞后

两个同频率正弦量的相位之差，等于初相之差（ωt 相互抵消）：

φ = φ₁ − φ₂
约定取 |φ| ≤ 180°（超过 180° 就换个方向说）
  • φ > 0：前者超前后者 φ；φ < 0：前者滞后。
  • "u 超前 i 90°" 与 "i 滞后 u 90°" 是同一句话的两种说法。
  • 特殊关系：φ = 0 同相；φ = ±180° 反相；φ = ±90° 正交。
南网考点相位差判断是电路科目的经典送分/送命题。最强坑位："u 滞后 i 30°"等价于"i 超前 u 30°"，选项里两种说法都可能出现在正确/错误位置，务必眼明心亮。另外记住伏笔：感性电路 u 超前 i（0~90°）、容性电路 u 滞后 i（0~90°）—— 第 3 课将解释为什么。

3有效值：为什么插座上的 220V 不是波峰值

正弦电压每一瞬间都在变，那"220V"指的是什么？指的是有效值（方均根值，RMS）：把交流通进电阻 R，一个周期发的热，与某个直流 I 通同样时间发的热相等，这个 I 就是交流电流的有效值。

两步推导（考试可再现）

  1. 正弦平方后：sin²(ωt) = (1 − cos 2ωt)/2 —— 一个周期内 cos 2ωt 的平均值是 0，所以平方的平均值是 1/2；
  2. 有效值 = 平方平均后开根：I = √(Im²/2) = Im/√2。
U = Um√2 ≈ 0.707 Um　　Um = √2 · U ≈ 1.414 U
√2 ≈ 1.414、1/√2 ≈ 0.707 —— 这两个乘数必须像乘法口诀一样熟
  • 家用插座 220V 是有效值，真实波峰是 220 × 1.414 ≈ 311V；
  • 380V（线电压）波峰 ≈ 537V；
  • 万用表交流档读的就是有效值；电器铭牌上写的电压电流也都是有效值。
南网考点"正弦电压有效值 220V，其幅值是多少？"（311V）以及反向考法，是概念题常客。同时记住：相量的模用的是有效值（见知识块 4）。

4相量：给正弦量拍一张"定妆照"

核心洞察分两步：

  1. 在一个确定频率的电路里（比如整个 50 Hz 电网），所有正弦量的 ω 都相同 —— ω 根本不用参与计算，真正区分它们的只有大小和初相两个数；
  2. "大小 + 角度" —— 这正是第 1 课极坐标式复数的长相！

于是定义相量（记号：大写字母上加一个点）：

u(t) = Um sin(ωt + φ)　⇒  　U = U∠φ　（取有效值作模）
例：u = 311 sin(314t + 60°) V　⇒　U = 311/√2 = 220 V　⇒　U̇ = 220∠60° V

反过来，从相量恢复正弦量，就是把模乘 √2 变幅值、把角度放进 sin：

U = 100∠60° V（f = 50 Hz）　⇒  　u(t) = 141.4 sin(314t + 60°) V

相量图：把"全家福"拍在同一张照片里

把电路中各电压电流相量画在同一复平面上：箭头长度 = 有效值，与实轴夹角 = 初相位。谁的角度大（逆时针在前），谁的波形就超前。

图 2：相量图示例。两个箭头的夹角就是相位差；逆时针方向上"走在前面"的相量，波形上超前。

三条纪律（判断题最爱）

  1. 相量只对同频率正弦量有意义—— 频率不同的两个正弦量没有固定相位差，不能画在同一相量图上；
  2. 相量 ≠ 正弦量本身：相量只携带"大小 + 初相"，丢掉了频率信息（靠约定补回）。严格说"相量表示正弦量"，说"相量等于正弦量"是错的；
  3. 模用有效值是电力系统惯例（也可用幅值相量，但必须前后一致、看清题目约定）。

5相量法的威力：正弦相加 = 复数相加

同频正弦量相加，用三角函数展开要算到手软；用相量，就是第 1 课的复数加法 —— 化成代数式，实虚部分别相加（或画相量图用平行四边形合成）。

串联电压相加的完整链条（本课最重要的一张图）：两个元件串联，总电压 u = u₁ + u₂ ⇒ 相量相加 U = U₁ + U₂ ⇒ 代数式相加 ⇒ 结果转回极坐标式 ⇒ 读出总电压大小与初相。全程无三角函数恒等式，只有复数四则运算。
南网考点这一"降维打击"正是电路教材正弦稳态一章的全部地基。下一课学完 R、L、C 的阻抗后，你将第一次完整解出一道正弦稳态电路题。

例例题精讲

例 1 · 读三要素

u = 311 sin(314t − 30°) V。求三要素、有效值与频率。

  1. 幅值 Um = 311 V；有效值 U = 311/√2 = 220 V（311 本来就是 220√2）；
  2. 角频率 ω = 314 rad/s ⇒ f = ω/2π = 314/314 = 50 Hz，T = 0.02 s；
  3. 初相位 φ = −30°（波形整体右移 30°，"晚起跑"）。
Um = 311 V　ω = 314 rad/s　φ = −30°　U = 220 V　f = 50 Hz

看到 311 立即反应 220V 有效值；看到 314 立即反应 50Hz —— 两对换算要形成条件反射。

例 2 · 正弦量 → 相量

i = 14.14 sin(ωt + 45°) A，写出它的相量（有效值相量）。

  1. 有效值：I = 14.14/√2 ≈ 10 A（14.14 就是 10√2）；
  2. 辐角取初相位 +45°。
İ = 10∠45° A

换算只发生在"模"上（√2 倍关系），角度原样照搬。电力题目爱用 √2 的整数倍：311、14.14、7.07、100，都是为了换算后得到整数。

例 3 · 相位差判断

u = 100 sin(ωt + 60°) V，i = 10 sin(ωt − 30°) A。求相位差并判断超前滞后关系。

  1. 同频率（同一个 ω），可以比较。相位差 = φu − φi = 60° − (−30°) = 90°；
  2. φ > 0：电压超前电流 90°，两者正交；
  3. 等价说法：电流滞后电压 90°。
φ = 90°，u 超前 i 90°（正交）

"u 超前 i 90°" 与 "i 滞后 u 90°" 必须能在两种说法间自由切换 —— 选择题两个说法都可能出现，一个对一个错。

例 4 · 相量相加（串联电压合成）

串联电路中 U̇₁ = 100∠0° V，U̇₂ = 100∠60° V。求总电压相量 U̇ = U̇₁ + U̇₂ 及其瞬时值表达式（f = 50 Hz）。

  1. 化成代数式：U̇₁ = 100 + j0；U̇₂ = 100cos60° + j100sin60° = 50 + j86.6；
  2. 实虚部分别相加：U̇ = 150 + j86.6；
  3. 转回极坐标：模 = √(150² + 86.6²) = √30000 ≈ 173.2 V；辐角 = arctan(86.6/150) = 30°；
  4. 写回瞬时值：幅值 = 173.2 × √2 ≈ 245 V，ω = 314。
U̇ = 173.2∠30° V　　u(t) ≈ 245 sin(314t + 30°) V

检验：几何上 100∠0° 与 100∠60° 是等腰三角形的两条边，合力方向必然在正中间 —— 30° ✓。另注意：两个"100V"加起来是 173.2V 而不是 200V —— 相位不同，不能直接算术相加，这是交流电路与直流最大的思维转换。

练练习（先做再看答案）

拿草稿纸手算。Q1–Q4 概念换算，Q5–Q8 相位差与相量运算，每题 1 分钟内。

Q1u = 220√2 sin(100πt + 45°) V。写出幅值、有效值、频率、初相位点击展开 ▾

幅值 = 220√2 ≈ 311 V；有效值 = 220 V；ω = 100π ⇒ f = 50 Hz；初相 = 45°。

Um ≈ 311 V　U = 220 V　f = 50 Hz　φ = 45°

220√2 与 311 是同一个数的两种写法，考试两种都出现。

Q2f = 50 Hz，求 ω 和周期 T点击展开 ▾

ω = 2πf = 100π ≈ 314 rad/s；T = 1/f = 0.02 s。

ω ≈ 314 rad/s　T = 0.02 s

50Hz ↔ 314 rad/s ↔ 0.02s，三位一体，任意一个推出另外两个。

Q3幅值为 100 V 的正弦电压，其有效值是多少？点击展开 ▾

U = 100/√2 ≈ 70.7 V。

U ≈ 70.7 V

除以 √2 即乘 0.707。反向考法：有效值 100V ⇒ 幅值 141.4V。

Q4i = 28.28 sin(314t − 120°) A，写出相量点击展开 ▾

I = 28.28/√2 = 20 A；辐角取初相 −120°（第三象限的角度，作为"初相位"直接保留，不必加 180°—— 它本来就是 −120°，不是算出来的 arctan）。

İ = 20∠−120° A

第 1 课的象限陷阱出现在"代数式→极坐标"的换算中；从正弦量直接取初相则没有这个问题。

Q5u = 310 sin(ωt + 30°) V，i = 5 sin(ωt − 15°) A。相位差多少？谁超前谁？点击展开 ▾

φ = 30° − (−15°) = 45° > 0，电压超前电流 45°。

φ = 45°，u 超前 i 45°

相位差与有效值无关 —— 310 与 5 只是干扰项。

Q6"电流滞后电压 90°"还有几种等价说法？点击展开 ▾

① 电压超前电流 90°；② u 与 i 正交；③ 相位差 φui = +90°（若定义 φ = φu − φi）。

u 超前 i 90° ／ 两者正交

这也是纯电感元件的 u-i 关系（下一课主角），先把说法练熟。

Q7相量 U̇ = 100∠60° V（f = 50 Hz），写回瞬时值表达式点击展开 ▾

幅值 = 100 × √2 ≈ 141.4 V；ω = 314 rad/s；初相 = 60°。

u(t) ≈ 141.4 sin(314t + 60°) V
Q8İ₁ = 3∠0° A，İ₂ = 4∠90° A，求总电流 İ = İ₁ + İ₂点击展开 ▾

代数式：İ₁ = 3 + j0，İ₂ = 0 + j4；相加：İ = 3 + j4。

İ = 5∠53.13° A

3-4-5 勾股数又登场了 —— 3 + j4 = 5∠53.13° 是整个交流分析里出镜率最高的复数，第 1 课练的口算在这里直接变现。

  • 我能在正弦量与相量之间双向换算（√2 只作用于模，角度原样搬运）

  • 我能用代数式相加（或相量图合成）求两个同频正弦量之和
  • 我能说出相量法的两条纪律：只管同频率；相量表示而非等于正弦量
