阶段 0 筑基 · 第 3 课

R、L、C 与阻抗

成型之战：电阻、电感、电容是电路的三大基本元件，它们在正弦交流下的"脾气"各不相同。这一课把前两课的复数工具和相量方法合成真正的电路分析能力 —— 学完你就能独立解出第一道完整的正弦稳态电路题。

预计 2 小时 5 个知识块 · 4 道例题 · 8 道练习 承接第 1、2 课

一句话记住相位关系：电感"压流"（电压在前），电容"流压"（电流在前），电阻"同步走"。第 2 课埋的伏笔——"感性电路 u 超前 i、容性电路 u 滞后 i"——本课将给出完整解释。
南网考点感抗 / 容抗公式、相位差 90°、阻抗角与电路性质判断，是电路科目客观题的超高频考点；阻抗计算更是所有正弦稳态大题的第一步。

1电阻 R：老实人，同进同退

欧姆定律在相量世界原样成立，连角度都不用动：

U = R · I
例：İ = 2∠30° A 流过 R = 50 Ω　⇒　Ù = 100∠30° V —— 模相乘，角度不变
  • 电压电流同相位：相量图上两个箭头方向完全一致；
  • 阻值与频率无关：50Hz 下 50Ω，5kHz 下还是 50Ω；
  • 唯一真正耗能的元件：把电能变成热（P = UI，第 5 课细讲功率）。

2电感 L：线圈，"阻止电流变化"

电感（导线绕成的线圈）的物理本能是抵抗电流变化——电流想变，它就感应出反向电压阻拦。正弦电流一直在变，所以电感一直在"对抗"，表现为对交流的阻碍作用：感抗。

XL = ωL = 2πfL　（单位：Ω）
L 的单位是亨利 H；频率越高、电感越大，阻碍越强

相量关系里，j 正式登场（第 1 课"乘 j 转九十度"在此变现）：

U = jXL · I = XL∠90° · I
电压模 = 感抗 × 电流模；电压角度 = 电流角度 + 90° —— 电压超前电流 90°

两个极限，一句话成语

  • 直流稳态（ω = 0）：XL = 0，电感相当于短路；
  • 频率极高（ω → ∞）：XL → ∞，电感相当于开路；
  • 合起来就是中学那句"通直流、阻交流"，现在你能写出它的数学根据了。
图 1：纯电感的相量图。以电流为参考（0°），电压逆时针超前 90° —— "乘 j" 的几何含义。

3电容 C：两块极板，"阻止电压变化"

电容的脾气与电感镜像对称：它抵抗的是电压变化——电压想变，极板就充放电抵消。表现为容抗：

XC = 1ωC = 12πfC　（单位：Ω）
C 的单位是法拉 F；频率越高、电容越大，阻碍越弱 —— 与感抗的趋势正好相反

相量关系中，第 1 课的 1/j = −j 在此落地：

ZC = 1jωC = −j · 1ωC = −jXC
Ù = −jXC·İ —— 电压角度 = 电流角度 − 90°：电压滞后电流 90°（即电流超前电压 90°）

两个极限，另一句成语

  • 直流稳态（ω = 0）：XC = 1/0 → ∞，电容相当于开路（充完电就断路）；
  • 频率极高（ω → ∞）：XC → 0，电容相当于短路；
  • 这就是"隔直流、通交流"的数学本质。
南网考点容抗公式里的 −j 是判断题高发区："电容电压超前电流 90°"（×，滞后）；"1/(jωC) = jωC⁻¹"（×，负 j）。相位关系记口诀：感压容流——电感的电压在前，电容的电流在前。两个极限（直流下 L 短路 C 开路）则是"换路 / 稳态"类题目的钥匙。

4阻抗 Z：把 R、L、C 拧成一根绳

RLC 串联时，总电压是三个元件电压的相量和，结果是所有作用拧成的一个总阻碍 —— 阻抗：

Z = R + jX = R + j(XL − XC)　，　X = XL − XC
X 叫电抗：感抗减容抗。感性、容性在此"相消"—— 数值大的说了算

这正是第 1 课例 4 的"阻抗三角形"，现在三个边都有了物理名字：

图 2：阻抗三角形。三条边分别是 R、X、|Z|；阻抗角 φ 同时是电压超前电流的角度。

电路性质由 X 的正负一锤定音：

条件性质阻抗角u 与 i 的关系
X > 0（XL > XC）感性φ > 0u 超前 i（0~90°）
X < 0（XL < XC）容性φ < 0u 滞后 i（0~90°）
X = 0（XL = XC）纯阻性φ = 0同相（串联谐振，第 5 课）
南网考点"判断电路性质 / 阻抗角正负 / 电压电流超前滞后"三位一体，全是同一件事：看 X 的符号。给出 Z = a ± jb，直接读符号 —— b 前为 + 感性，b 前为 − 容性。

5频率特性总表 + 一个"必背"数值

元件阻碍（Ω）频率 f 升高直流稳态（ω=0）高频极限
电阻 RR不变RR

最后记住一组"电网人"数字：50 Hz 下，1 H 电感的感抗 ≈ 314 Ω，1 F 电容的容抗 ≈ 0.00318 Ω。反过来，想在 50Hz 下得到 1Ω 的容抗需要多大的电容？C = 1/(ω·XC) ≈ 3183 μF —— 电容"个头"往往很大，这也是电容器为什么长得像"油桶"的原因之一。

例例题精讲

例 1 · 纯电感电路

电压 Ù = 100∠0° V 加在纯电感上，XL = 5 Ω。求电流相量。

  1. 相量欧姆定律：İ = Ù / (jXL)；
  2. 除法（第 1 课）：模相除 100/5 = 20；角相减 0° − 90° = −90°。
İ = 20∠−90° A

电流滞后电压 90° —— 与"电感电压超前"完全一致，两种说法一个事实。j 在分母照样按"模 1、角 90°"处理即可。

例 2 · RLC 串联阻抗（性质判断）

R = 30 Ω、XL = 80 Ω、XC = 40 Ω 串联。求总阻抗，并判断电路性质。

  1. 电抗：X = XL − XC = 80 − 40 = +40 Ω；
  2. 阻抗：Z = R + jX = 30 + j40 Ω；
  3. 极坐标：|Z| = √(900+1600) = 50 Ω，φ = arctan(40/30) ≈ 53.13°（3-4-5 又来了）；
  4. X > 0 ⇒ 感性，u 超前 i 53.13°。
Z = 30 + j40 = 50∠53.13° Ω，感性

先算 X 再合成 Z，是标准流程；判断性质只看 j 前的正负号。若把 XC 改成 120 Ω，X = 80 − 120 = −40，Z = 30 − j40 = 50∠−53.13°，立刻翻转为容性。

例 3 · 第一道完整的正弦稳态题

接例 2 电路（Z = 50∠53.13° Ω），电源电压 Ù = 100∠0° V。求电流相量，并写回瞬时值（f = 50 Hz）。

  1. 相量欧姆定律：İ = Ù / Z；
  2. 除法：模 100/50 = 2 A；角 0° − 53.13° = −53.13°；
  3. 写回瞬时值：幅值 = 2 × √2 ≈ 2.83 A，ω = 314，初相 = −53.13°。
İ = 2∠−53.13° A　　i(t) ≈ 2.83 sin(314t − 53.13°) A

三步闭环：Ù 已知 → 除以 Z 得 İ → 乘 √2 回瞬时值。这道题打通了第 1 课（复数除法）、第 2 课（相量↔正弦量）、第 3 课（阻抗）—— 你已经具备解正弦稳态电路的全部基础零件。

例 4 · 从阻抗反读性质（概念综合）

某二端网络的阻抗 Z = 6 − j8 Ω。求 |Z|、阻抗角，说明电路性质与 u-i 相位关系。

  1. 模：|Z| = √(36+64) = 10 Ω；
  2. 角：φ = arctan(−8/6) ≈ −53.13°（b 为负，第四象限，负角直接取）；
  3. j 前为负 ⇒ 容性；φ < 0 ⇒ u 滞后 i 53.13°（等价：i 超前 u 53.13°）。
|Z| = 10 Ω，φ = −53.13°，容性，u 滞后 i 53.13°

注意区分两个"负号"：这是阻抗角的负（容性），不是第 1 课象限陷阱的负实部（那才需要 +180°）。实部 6 > 0，第四象限，arctan 直接用。

练练习（先做再看答案）

前 4 题概念与公式，后 4 题综合计算。单位换算小心：1 mH = 10⁻³ H，1 μF = 10⁻⁶ F。

Q1L = 0.1 H，f = 50 Hz，求感抗点击展开 ▾

XL = ωL = 314 × 0.1 = 31.4 Ω。

XL = 31.4 Ω

50Hz 下感抗口算 = 314 × L（H）。电感量常用 mH 计：10 mH → 3.14 Ω。

Q2C = 100 μF，ω = 314 rad/s，求容抗点击展开 ▾

XC = 1/(ωC) = 1/(314 × 100×10⁻⁶) = 1/(0.0314) ≈ 31.85 Ω。

XC ≈ 31.85 Ω

先把 μF 化成 F（×10⁻⁶）再进分母 —— 单位错一位，答案差千倍，这是实操中最常见的翻车点。

Q3纯电感上，电压与电流的相位关系？纯电容呢？点击展开 ▾

纯电感：u 超前 i 90°；纯电容：i 超前 u 90°（u 滞后 i 90°）。

感压容流 —— 电感电压在前，电容电流在前

判断题喜欢把"电容电压超前电流"当正确说法，注意别被带偏。

Q4直流稳态下，电感和电容分别相当于什么？点击展开 ▾

ω = 0 时：XL = ωL = 0 → 电感相当于短路；XC = 1/ωC → ∞ → 电容相当于开路。

L → 短路　C → 开路

"稳态下 L 短路、C 开路"是分析直流稳态电路（如电容电压计算）的第一刀。

Q5Z = 4 + j3 Ω。求 |Z| 与阻抗角，判断性质点击展开 ▾

|Z| = √(16+9) = 5 Ω；φ = arctan(3/4) ≈ 36.87°；j 前为正，感性。

Z = 5∠36.87° Ω，感性

3-4-5 与 4+j3：角度 36.87°（第 1 课 Q1 的老朋友）。

Q6Z = 8 − j6 Ω。求 |Z| 与阻抗角，判断性质点击展开 ▾

|Z| = √(64+36) = 10 Ω；φ = arctan(−6/8) ≈ −36.87°；j 前为负，容性；u 滞后 i 36.87°。

Z = 10∠−36.87° Ω，容性

与 Q5 成对记忆：±j 换的是角度符号和性质，模不变。

Q7R = 3 Ω、XL = 10 Ω、XC = 4 Ω 串联。求 Z 与电路性质点击展开 ▾

X = XL − XC = 10 − 4 = 6 Ω；Z = 3 + j6 Ω；|Z| = √(9+36) = √45 ≈ 6.71 Ω；φ = arctan(6/3) ≈ 63.43°。

Z = 3 + j6 ≈ 6.71∠63.43° Ω，感性

标准流程：先合并电抗 X，再进阻抗。XL 与 XC 直接作差，不用先各自写进 Z。

Q8Ù = 100∠30° V，Z = 10∠53.13° Ω。求 İ点击展开 ▾

除法：模 100/10 = 10；角 30° − 53.13° = −23.13°。

İ = 10∠−23.13° A

这就是例 3 的翻版：电压初相不是 0 也没关系，模相除、角相减，机械执行即可。
