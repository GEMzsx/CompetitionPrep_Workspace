阶段 0 筑基 · 第 1 课

复数与相量运算

交流电路的全部计算都建立在复数四则运算之上 —— 阻抗、三相功率、功率因数，每一道南网笔试的交流题都在用它。这一课从零开始，把「工具」磨快，后面电路课才能跑得动。

预计 1.5–2 小时 4 个知识块 · 4 道例题 · 8 道练习 电路课的前置工具课

?为什么第一课是复数？

  1. 它是交流电路的"货币"。正弦电压电流的加减、阻抗的串并联、三相功率的计算，在相量法下全部变成复数四则运算。复数算不快，电路题就做不快。
  2. 它直接出现在考卷上。电路科目考纲中的"相量法与正弦稳态"、"三相电路"，每一步都是复数运算；给定阻抗求电流这类题，90% 的时间花在复数上。
  3. 它只有一层窗户纸。你需要掌握的只有：三种写法互相转化 + 加减乘除规则。高中数学学过皮毛，现在只需要两个小时把它变成肌肉记忆。
南网考点复数运算本身很少单独出题，但作为底层工具渗透在电路、电分（如短路电流计算）、电机（如同步电机相量图）等科目的题目中。本课目标：互化与四则运算 30 秒内一题。

1j 是什么：一个"转 90°"的动作

数学里虚数单位叫 i，但电工学里写 j —— 因为 i 已经被电流占用了。它满足：

j² = −1

但这不是重点。重点是它的几何意义：乘以 j，就是把一个数逆时针旋转 90°。

  • 1 × j = j —— 从实轴正向（东）转到虚轴正向（北）；
  • j × j = −1 —— 再转 90°，指向实轴负向（西）；
  • (−1) × j = −j —— 继续转，指向虚轴负向（南）；
  • 再乘一次 j，转回 1 —— 转一整圈。
为什么电工非要它不可？因为交流电是"旋转"的：正弦波每时每刻的值，就是一根旋转的箭头在实轴上的投影。电容让电流"超前"电压 90°、电感让电流"滞后"电压 90° —— 这些 90° 的关系，用 j 一乘一除就表达了，纯实数运算永远做不到。

必须秒答的四个小算式

j × j = −1   ·   j × (−j) = 1   ·   1/j = −j   ·   j/(−j) = −1
提示：1/j 的推导 —— 分子分母同乘 j：j/j² = j/(−1) = −j
南网考点1/j = −j 是电路课的常客：电容的阻抗 1/(jωC) = −j/(ωC)，那个负号就是这么来的。见到 1/j 不假思索写 −j，是你未来的下意识动作。

2复平面：把数画成箭头

横轴叫实轴（Re），纵轴叫虚轴（Im）。复数 z = a + bj 就是平面上的一个点 (a, b)，或者从原点指向它的一支箭头。

  • 模 r —— 箭头的长度：r = |z| = √(a² + b²)
  • 辐角 θ —— 箭头与实轴正方向的夹角：θ = arctan(b/a)（注意象限，见下）

例如 3 + j4：向右 3、向上 4，箭头长度 √(9+16) = 5，与实轴夹角 arctan(4/3) ≈ 53.13°。

背下两套勾股数：3-4-5（角度 53.13°）和 5-12-13（角度 67.38°）。笔试里的复数运算十有八九落在这两套三角形上，角度基本就是 37°/53° 或 23°/67° 一带 —— 认出它们，互化就是口算。

3三种写法与互化（本课核心）

同一个复数有三种"衣服"，场合不同换着穿：

形式长相擅长使用场合
代数式z = a + bj加减串联阻抗相加、相量逐项求和
极坐标式z = r∠θ乘除阻抗÷电压求电流、功率计算
指数式z = r·ejθ理论推导公式推导、理解欧拉公式

互化公式

极坐标 → 代数：a = r·cos θ，b = r·sin θ
例：10∠60° = 10cos60° + j·10sin60° = 5 + j8.66
代数 → 极坐标：r = √(a² + b²)，θ = arctanba
例：3 + j4 = 5∠53.13°

象限陷阱 —— 考试最爱挖的坑

arctan 计算器只会给出 −90° ~ +90° 的答案。当 a < 0（点在左侧两个象限）时，必须手动修正：

复数位置例子计算器给出正确辐角
第一象限（a>0, b>0）3 + j453.13°53.13°（直接用）
第二象限（a<0, b>0）−3 + j4−53.13°−53.13° + 180° = 126.87°
第三象限（a<0, b<0）−3 − j453.13°53.13° − 180° = −126.87°
第四象限（a>0, b<0）3 − j4−53.13°−53.13°（直接用，负角合法）
南网考点阻抗为负实部（如 Z = −3 + j4）的判断题、电容性/电感性判断，都藏在这个象限陷阱里。口诀：a 为负，角加 180。

4四则运算与共轭

加减 —— 换成代数式，实虚部分别算

(a + bj) ± (c + dj) = (a ± c) + j(b ± d)

乘除 —— 换成极坐标式：模相乘除，角相加减

(r₁∠θ₁) × (r₂∠θ₂) = (r₁·r₂)∠(θ₁ + θ₂)

r₁∠θ₁r₂∠θ₂ = r₁r₂∠(θ₁ − θ₂)

共轭 —— 虚部变号

z = a + bj  ⇒  z* = a − bj

z × z* = a² + b² = |z|²（模的平方，纯实数！）

共轭的最大用途：分母实数化 —— 分母里有复数时，分子分母同乘分母的共轭，分母立刻变成实数。

常用三角函数速查（互化的口算基础）

θ0°30°45°60°90°
cos θ1√3/2 ≈ 0.866√2/2 ≈ 0.7071/20
sin θ01/2√2/2 ≈ 0.707√3/2 ≈ 0.8661
欧拉公式（了解即可）：ejθ = cos θ + j·sin θ —— 指数式和极坐标式其实是一回事（ejθ 就是 ∠θ）。验证一下：θ = 90° 时 ej90° = cos90° + j·sin90° = j，正是"乘 j 转九十度"。它把"旋转"和"指数"连通了，是相量法的理论基石。

例例题精讲

例 1 · 基础互化（正角）

把 z = 3 + j4 化成极坐标式。

  1. 模：r = √(3² + 4²) = √25 = 5（3-4-5 勾股数）；
  2. 辐角：a = 3 > 0，第一象限，θ = arctan(4/3) ≈ 53.13°。
z = 5∠53.13°

3-4-5 是笔试第一勾股数，53.13°（或写成 53.1°）要形成条件反射。

例 2 · 象限陷阱（负实部）

把 z = −5 + j12 化成极坐标式。

  1. 模：r = √(25 + 144) = √169 = 13（5-12-13 勾股数）；
  2. 辐角：a = −5 < 0，第二象限！计算器给 arctan(12/−5) ≈ −67.38°，必须加 180°；
  3. θ = −67.38° + 180° = 112.62°。
z = 13∠112.62°

检验：辐角 112.62° 在 90°~180° 之间，第二象限 ✓ 与"负实正虚"一致。养成检验习惯：算完看一眼象限对不对。

例 3 · 乘除运算

已知 A = 6∠30°，B = 2∠45°，求 A × B 和 A ÷ B。

  1. 乘法：模相乘 6 × 2 = 12；角相加 30° + 45° = 75°；
  2. 除法：模相除 6 ÷ 2 = 3；角相减 30° − 45° = −15°（负角完全合法，表示顺时针转 15°）。
A × B = 12∠75°　　A ÷ B = 3∠−15°

未来电路课里"电压相量 ÷ 阻抗 = 电流相量"就是这个除法：模相除得到电流大小，角相减得到电流相位。

例 4 · 综合预演（阻抗的雏形）

电阻 R = 3 Ω 与电抗 X = 4 Ω 串联，总阻抗 Z = R + jX = 3 + j4 Ω。求它的模和辐角，并画在复平面上。

  1. 这就是例 1：|Z| = 5，θ = 53.13°；
  2. 几何意义：电阻 3 沿实轴、电抗 4 沿虚轴，合成箭头长 5、指向 53.13°；
  3. 这块"斜边"就是未来电路课的阻抗三角形：|Z|、R、X 三边勾股，θ 是阻抗角 = 电压与电流的相位差 = 功率因数角！
Z = 5∠53.13° Ω

四道例题连起来看：复数运算 → 阻抗 → 功率因数 → 三相功率，这就是南网笔试电路题的完整链条。

练练习（先做再看答案）

要求：拿草稿纸手算，每题目标 30–60 秒。点击题目展开解答。

Q1把 8 + j6 化成极坐标式点击展开 ▾

r = √(64+36) = √100 = 10；θ = arctan(6/8) = arctan(0.75) ≈ 36.87°（第一象限直接用）。

8 + j6 = 10∠36.87°

6-8-10 仍是 3-4-5 的倍数（×2），角度不变 36.87°——正是 53.13° 的余角。一对黄金角度：36.87° 与 53.13°，都来自 3-4-5。

Q2把 −8 + j6 化成极坐标式点击展开 ▾

模不变：r = 10。辐角：a = −8 < 0，第二象限，arctan(6/−8) ≈ −36.87°，加 180°。

−8 + j6 = 10∠143.13°

与 Q1 对比：只改了实部的符号，角度从 36.87° 跳到 143.13°。这就是"负实部加 180°"。

Q3把 10∠60° 化成代数式点击展开 ▾

a = 10·cos60° = 10 × 0.5 = 5；b = 10·sin60° = 10 × 0.866 = 8.66。

10∠60° = 5 + j8.66

cos 给实部、sin 给虚部。60° 是速查表里的常客，sin60° = √3/2 ≈ 0.866 必须背。

Q4把 4∠−30° 化成代数式点击展开 ▾

a = 4·cos(−30°) = 4 × 0.866 = 3.46；b = 4·sin(−30°) = 4 × (−0.5) = −2。

4∠−30° = 3.46 − j2

负角的 cos 是偶函数（不变号）、sin 是奇函数（变号）。虚部为负 = 容性，这在未来判断电路性质时天天用。

Q5计算 (3∠20°) × (4∠50°)点击展开 ▾

模相乘：3 × 4 = 12；角相加：20° + 50° = 70°。

(3∠20°)(4∠50°) = 12∠70°
Q6计算 20∠75° ÷ 4∠15°点击展开 ▾

模相除：20 ÷ 4 = 5；角相减：75° − 15° = 60°。

20∠75° ÷ 4∠15° = 5∠60°

将来这就是：电压模 20、超前 75°，阻抗模 4、超前 15° ⇒ 电流模 5、超前 60°。

Q7已知 z = 1 + j，求共轭 z*、模 |z|、以及 z × z*点击展开 ▾

共轭：虚部变号 z* = 1 − j；模：|z| = √(1+1) = √2 ≈ 1.414；乘积：z × z* = |z|² = 2。

z* = 1 − j　|z| = √2　z·z* = 2

z = 1 + j 的辐角是 45°，模 √2 —— 它乘自己（平方）就是 (√2∠45°)² = 2∠90° = 2j，很优雅的数。

Q8阻抗预演：R = 6 Ω 与感抗 X = 8 Ω 串联，写出阻抗的代数式与极坐标式点击展开 ▾

代数式：Z = R + jX = 6 + j8 Ω；极坐标式：|Z| = √(36+64) = 10，θ = arctan(8/6) ≈ 53.13°。

Z = 6 + j8 = 10∠53.13° Ω

这就是将来正弦稳态电路的第一类必考题。记住：感性 j 前为正，容性 j 前为负。
