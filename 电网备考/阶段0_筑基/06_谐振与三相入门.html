谐振与三相入门

上半场收伏笔：当 XL = XC，前五课积攒的全部能量在一瞬间总爆发——谐振；下半场开新世界：三相电路，电网的"母语"，南网笔试三相题的地基。阶段 0 的收官之战。

预计 2.5 小时 7 个知识块 · 4 道例题 · 8 道练习 阶段 0 最终章

?本课核心思想

本课分两半。上半场"谐振"：第 3 课说过 X = XL − XC，若某个频率下两者恰好相等，净电抗归零——电路"退化"成纯电阻，电流冲到最大，而电感电容内部却憋出远超电源的电压。这不是学术游戏：收音机选台、电网滤波、变压器烧毁事故，都在这一刻。下半场"三相"：真实电网不是单相而是三相——三个相位互差 120° 的电源协同工作，星形/三角形两种接法、线量与相量的 √3 关系，是读懂一切电力系统的字母表。

一句话记住：谐振回答"什么时候 L 和 C 会突然发飙"；三相回答"电网为什么长成这样"。一个管异常，一个管日常。
南网考点谐振的条件、公式、过电压特性是概念判断题高频区；三相的 √3 关系与功率公式是计算题绝对主力——南网笔试电路部分几乎每年必考一道三相计算。作为未来电网人，"为什么不能三相三线制给民用供电"这类问题面试也会问。

1谐振：XL = XC 的时刻

回顾第 3 课：感抗 XL = ωL 随频率上升，容抗 XC = 1/(ωC) 随频率下降。频率从低到高扫过去，两条线必有一个交点——交点处 X = XL − XC = 0，电路发生谐振（resonance）：

条件：ω0L = 1ω0C　⟹　谐振角频率 ω0 = 1√(LC)　，　谐振频率 f0 = 12π√(LC)
  • 谐振频率只由 L 和 C 决定（与 R、与电源电压无关）——这是"电路的固有属性"，就像音叉的固有音调。
  • R 只决定谐振峰的胖瘦（锐利程度），不决定位置。
图 1 · 感抗随频率上升、容抗随频率下降，交点即谐振频率 f₀

2串联谐振三大特点与品质因数 Q

R-L-C 串联电路在 f = f₀ 时，X = 0，Z = R（纯阻性）。三大特点：

特点结果说明
阻抗最小Z = R电抗完全抵消，只剩电阻
电流最大I₀ = U/R同电压下电路能达到的最大电流
L、C 上出现过电压UL = UC = QU元件电压可达电源的 Q 倍！

第三个特点最反直觉也最重要——电源明明只有 U 伏，电感和电容上却各自扛着 Q 倍电压。原因：UL 与 UC 反相（一个超前电流 90°、一个滞后 90°），相量求和抵消，总电压 Ù = ÙR；但每个元件自己的电压是 I·X，谐振时 I 很大、XL = XC 也不小，乘积自然惊人。其中 Q（品质因数）：

Q = ω0LR = 1ω0CR　（谐振时 ULU = UCU = Q）
为什么叫"电压谐振"：串联谐振的标志性现象是元件电压被放大——收音机天线回路里，微弱的电台信号在电容上被放大 Q 倍（几百倍），才够检波电路用。R 越小，Q 越大，选台越"灵"。
判断题高发"串联谐振时电感和电容两端电压为零"（×——为零的是总电抗电压 UL − UC，元件各自电压 = QU，往往远超电源电压）；"串联谐振时电路呈纯阻性"（✓）；"谐振频率与电源大小有关"（×——只由 L、C 决定）。

3并联谐振与工程两面性

电感与电容并联的电路在谐振频率下，两支路的无功电流抵消，总电流最小、总阻抗最大——标志性现象是"元件电流被放大"，故称电流谐振。与串联谐振刚好镜像：

对比项串联谐振并联谐振
谐振时阻抗最小（= R）最大
谐振时电流最大最小
放大的是元件电压（QU）元件电流
别名电压谐振电流谐振
典型应用收音机选台、信号选通滤波、阻波（阻高频、通工频）

工程的同一枚硬币：谐振在通信里是宝贝（选台、滤波），在电力系统里却常是事故源——电网里大量的线路电感与电缆/电容若在工频附近满足谐振条件，过电压会击穿绝缘、烧毁变压器。所以电力系统要做"谐振校核"和"消谐"设计。

记忆口诀：串联谐振"小阻抗、大电流、高电压"；并联谐振"大阻抗、小电流、大支路电流"——先记串联（考得多），并联按镜像反推。

4三相电源：电网的母语

把三个幅值相等、频率相同、相位互差 120° 的正弦电压源组合起来，就是三相电源：

uA = Umsin(ωt)　　uB = Umsin(ωt − 120°)　　uC = Umsin(ωt + 120°)

三个电压到达正峰值的先后次序叫相序，A→B→C 为正序。相序不是小事：三相电动机的转向由相序决定——把任意两相对调，电机反转，这是"倒相"检修的原理。

图 2 · 三相对称电压：三条波形形状相同，起点错开 120°（三分之一周期）
为什么全世界都用三相：①三相对称时瞬时总功率恒定不变（单相功率每周期两次过零，电机会抖）；②同样输电容量，三相用线最省；③三相电流能直接产生旋转磁场——电动机的物理基础（电机课伏笔）。这三条是"电网为什么长成这样"的第一性答案。

5星形（Y）连接：380/220 的来历

发电机三相绕组的末端接在一起（中性点 N），三个首端引出 A、B、C 三根相线（火线），从中性点再引一根中性线（零线）——共四根线，即三相四线制。

  • 相电压 U相：任一相线对中性线的电压（UAN 等，即每相绕组自己的电压）；
  • 线电压 U线：两根相线之间的电压（UAB 等）。

对称时两者的关系是本课最重要的公式之一：

Y 接：U线 = √3 × U相　（线电压超前对应相电压 30°）

我国低压配电网：相电压 220 V（家用），线电压 = 220 × √3 ≈ 381 V（标称 380 V，工程圆整）。插座里的 220 V 和工厂里的 380 V，是同一个三相电源的两种取法——取一根火线加零线得 220，取两根火线得 380。

必背数字220 × √3 ≈ 381 → 标称 380。计算题里若给 U线 = 380 V，则 U相 = 380/√3 ≈ 219.4 ≈ 220 V——两种写法都接受，但别把 380 当相电压（Y 接时这是最高频错误）。
中线的作用：三相负载对称时中线电流为零（三相对称抵消）；负载不对称（家家户户用电不同）时，中线把中性点"钉"在电源电位上，保证每相负载都稳稳拿到 220 V。所以中线绝不允许装熔断器/开关——中线一断，中性点位移，轻则电压失衡，重则烧毁家用电器。

6三角形（△）连接与速查表

三相绕组（或负载）首尾相连构成闭环，三个连接点引出三根线——无中性点、无中线、只有三根线（三相三线制）。此时每相绕组直接跨接在两根相线上：

△ 接：U相 = U线　，　I线 = √3 × I相　（线电流滞后对应相电流 30°）

把两种连接的四个关系放进一张速查表（笔试前必默）：

连接方式电压关系电流关系相位关系典型场景
星形 YU线 = √3 U相I线 = I相线电压超前相电压 30°低压配电网（四线制供 380/220）
三角形 △U相 = U线I线 = √3 I相线电流滞后相电流 30°高压系统、三相电动机绕组
记忆窍门：Y 接"压差线大"（线电压是 √3 倍）；△ 接"流差线大"（线电流是 √3 倍）——每组只有一个量被放大 √3，另一个相等。30° 的超前/滞后方向容易混，考试时不确定就在草稿上画三个 120° 相量现推。

7三相功率：一个公式打天下

对称三相负载，每相功率 P相 = U相I相cosφ（φ 是每相负载自己的阻抗角，与接法无关）。三相总计：

P = 3 U相I相cosφ = √3 U线I线cosφ
两个式子完全等价（√3 = 3/√3 做桥）；工程上多用后者——因为线电压线电流在设备铭牌和现场表计上直接可读
  • cosφ 里的 φ 永远是相电压与相电流的相位差 = 负载阻抗角，与 Y/△ 接法无关；
  • 同理有无功 Q = √3 U线I线sinφ、视在 S = √3 U线I线——结构照搬第 5 课；
  • 重要推论：同一负载、同一电网，从 Y 接改成 △ 接：相电压变 √3 倍 → 相电流变 √3 倍 → 功率变 3 倍（例 4 现场验证）。
计算题模板三相题八成长这样："对称三相负载，U线 = 380 V，每相 Z = R + jX，求线电流与三相功率"。三步走：①按接法换出相电压（Y 除 √3、△ 直接用）→ ②I相 = U相/|Z|，按接法换出线电流 → ③P = √3U线I线cosφ。φ 用阻抗三角形（第 3 课）求。

例例题精讲

例 1 · 串联谐振的"总爆发"

R = 10 Ω、L = 0.1 H、C = 10 μF 的串联电路接 U = 10 V 电源。求谐振频率、谐振时电流，以及电感两端电压。

  1. 谐振角频率：ω₀ = 1/√(LC) = 1/√(0.1 × 10×10⁻⁶) = 1/√(10⁻⁶) = 1000 rad/s，f₀ = ω₀/2π ≈ 159.2 Hz；
  2. 此时 XL = ω₀L = 100 Ω，XC = 1/(ω₀C) = 100 Ω ✓ 恰好抵消，Z = R = 10 Ω；
  3. 电流 I = U/R = 10/10 = 1 A（同电压下的最大电流）；
  4. 品质因数 Q = ω₀L/R = 100/10 = 10，故 UL = UC = QU = 100 V。
f₀ ≈ 159.2 Hz；I = 1 A；UL = UC = 100 V（电源的 10 倍！）

电源才 10 V，电感电容上却各有 100 V——两者反相抵消，总电压仍等于 UR = 10 V，KVL 完好无损。这就是"过电压"：若此电路工作在谐振频率，元件绝缘必须按 100 V 以上设计，否则击穿。

例 2 · 收音机选台

收音机调谐回路线圈 L = 250 μH，可变电容调到 C = 100 pF。它能选出哪个频率的电台？为什么其他电台"听不见"？

  1. f₀ = 1/(2π√(LC)) = 1/(2π√(250×10⁻⁶ × 100×10⁻¹²)) = 1/(2π × 1.581×10⁻⁷) ≈ 1.006 MHz ≈ 1 MHz——恰好中波段；
  2. 谐振时该频率信号在电容上呈现 Q 倍电压，被放大后送入检波；
  3. 偏离 f₀ 的其他电台：电路远离谐振，阻抗显著大于 R，电流大幅缩水，输出被抑制。
f₀ ≈ 1 MHz；旋钮转动改变 C，就改变了 f₀——这就是"调台"的全部秘密

一个公式连接了课本和收音机：调谐 = 扫描谐振频率。注意单位换算（μH、pF → H、F）是本题唯一的计算陷阱。

例 3 · Y 接对称负载（380/220 主场）

三相对称负载 Y 接，每相 Z = 30 + j40 Ω，接相电压 220 V 的电源。求线电流与三相总有功功率。

  1. Y 接：U相 = 220 V（线电压 = √3 × 220 ≈ 381 V，标称 380）；
  2. |Z| = √(30² + 40²) = 50 Ω，Z 的阻抗角 φ = arctan(40/30) = 53.13°，cosφ = 30/50 = 0.6；
  3. I相 = 220/50 = 4.4 A，Y 接 I线 = I相 = 4.4 A；
  4. P = 3 U相I相cosφ = 3 × 220 × 4.4 × 0.6 = 1742.4 W ≈ 1.74 kW。
I 线 = 4.4 A；P ≈ 1.74 kW

3-4-5 三角形第三次登场（Z = 30+j40 = 50∠53.13°）——前三课的功夫全部复用：阻抗角求法（第 3 课）、cosφ = R/|Z|（第 5 课）一个都没白学。φ 是负载自己的角，与 Y/△ 接法无关。

例 4 · 同一负载改 △ 接：功率翻 3 倍

例 3 的负载（每相 Z = 30 + j40 Ω）改接成三角形，仍接在 380 V 电网上。求相电流、线电流与三相功率，并与 Y 接比较。

  1. △ 接：U相 = U线 = 380 V；
  2. I相 = 380/50 = 7.6 A；I线 = √3 × 7.6 ≈ 13.16 A；
  3. P = 3 U相I相cosφ = 3 × 380 × 7.6 × 0.6 = 5198.4 W ≈ 5.2 kW；
  4. 对比 Y 接（1742.4 W）：5198.4 / 1742.4 ≈ 3 倍整。
I 相 = 7.6 A，I 线 ≈ 13.16 A，P ≈ 5.2 kW —— 恰为 Y 接的 3 倍

链条：相电压 ×√3 → 相电流 ×√3 → 功率 ×3。这个"3 倍"是三相计算的经典结论，也是异步电动机 Y-△ 降压起动的原理——起动时用 Y 接（功率和电流都降到 1/3，避免电流冲击），转起来后换 △ 接满功率运行（电机课再见）。

练练习题（手算，每题限时 90 秒）

Q1R = 5 Ω、L = 0.2 H、C = 80 μF 串联，谐振频率是多少？点击展开 ▾

ω₀ = 1/√(LC) = 1/√(0.2 × 80×10⁻⁶) = 1/√(1.6×10⁻⁵) = 1/(4×10⁻³) = 250 rad/s；

f₀ = ω₀/2π = 250/6.283 ≈ 39.8 Hz。

ω₀ = 250 rad/s，f₀ ≈ 39.8 Hz

注意 R 根本没出场——谐振频率只由 L、C 决定，这是判断题最爱考的"无关项"。√(1.6×10⁻⁵) 的算术：1.6×10⁻⁵ = 16×10⁻⁶，√ = 4×10⁻³，化成平方数就好算。

Q2串联谐振发生时，下列说法正确的是：A. 总阻抗最大　B. 电路呈容性　C. 电流最大且与电源电压同相　D. 电路呈感性点击展开 ▾

X = XL − XC = 0：Z = R 为最小（排除 A）；电抗归零呈纯阻性（排除 B、D）；I = U/R 最大，且电压电流同相位（纯阻性电路的标志）。

选 C —— 阻抗最小、纯阻性、电流最大、电压电流同相

"同相"这个细节别丢：第 2 课讲过纯电阻电路 u、i 同相——谐振时整个电路"退化"成纯电阻，相位差自然为零。

Q3例 1 电路（Q = 10，电源 10 V）中，若电源频率恰为谐振频率，电容两端电压是多少？点击展开 ▾

谐振时 UC = QU = 10 × 10 = 100 V。

UC = 100 V，为电源电压的 10 倍

这就是为什么谐振电路里电容、电感的耐压等级常要按远超电源电压设计——过电压是真实存在的物理现象，不是做题技巧。

Q4判断：串联谐振时，电感两端电压为零。点击展开 ▾

错。为零的是电抗上的总电压（UL 与 UC 反相抵消后对外表现的合电压），电感自己的电压 UL = QU 往往远超电源电压。

× —— U_L = QU ≠ 0（如例 1 中 U_L = 100 V）

换个角度验证：若 UL 真为零，那 I·XL = 0，可谐振时 I = U/R ≠ 0 且 XL = ω₀L ≠ 0——矛盾。反证法兜底。

Q5对称三相电源 Y 接，线电压 380 V，相电压是多少？家用插座取的是什么电压、怎么取的？点击展开 ▾

U相 = 380/√3 ≈ 219.4 ≈ 220 V。

插座取的是相电压 220 V：任一根火线 + 中性线；工厂动力电取线电压 380 V：任意两根火线。同一个三相电源，两种取法。

U 相 ≈ 220 V；插座 = 火线 + 零线（相电压）

精确值 219.4 与 220 的差异来自标称圆整（220×√3 = 381 标称 380）。答题写 220 V 即可，但推导时要能写出 380/√3。

Q6对称三相负载 △ 接，相电流 10 A，线电流是多少？若同一负载改 Y 接到同一电网，相电流又是多少？点击展开 ▾

△ 接：I线 = √3 × I相 = √3 × 10 ≈ 17.32 A。

改 Y 接：U相 缩为原来的 1/√3（U线 不变、Y 接 U相 = U线/√3），故 I相 也缩为 1/√3：I相 = 10/√3 ≈ 5.77 A（此时 I线 = I相 ≈ 5.77 A）。

△：I 线 ≈ 17.32 A；改 Y 后 I 相 = I 线 ≈ 5.77 A（缩为 1/√3）

与例 4 串起来记：Y ⇄ △ 之间，相电压差 √3 倍、相电流差 √3 倍、功率差 3 倍——三个数一组打包记忆。

Q7对称三相负载 Y 接，U线 = 380 V，线电流 5 A，功率因数 0.8（感性）。三相总有功功率是多少？点击展开 ▾

不需要换相量——线量直接进公式：

P = √3 U线I线cosφ = 1.732 × 380 × 5 × 0.8 ≈ 2633 W ≈ 2.63 kW。

P ≈ 2.63 kW

这就是"√3 公式打天下"的含金量：题给线量、公式用线量，一步到位。注意 cosφ 给了就直接用（它就是每相负载的阻抗角余弦，与接法无关）。

Q8概念题：为什么民用低压电网的中线（零线）上不允许安装熔断器？点击展开 ▾

民用负载不对称（每家每户用电随机），中线里流着不平衡电流，其作用是把负载中性点的电位"钉"在电源中性点上，保证每相负载都稳定获得 220 V。

若中线装了熔断器且熔断：中性点发生位移，三相相电压重新分配——有的相电压升到远超 220 V（烧家电），有的相电压跌落（设备欠压）。一处断线，全楼遭殃。

中线是三相不对称运行的"定海神针"，必须用机械强度高的可靠导体，严禁熔断器/开关

这是面试与笔试都爱问的"工程常识"题——答案的物理内核就一句话：不对称靠中线兜底。顺带理解规程里"零线截面不得小于相线的一半"这类规定的来历。
