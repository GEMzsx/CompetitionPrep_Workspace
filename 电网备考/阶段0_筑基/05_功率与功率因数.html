阶段 0 筑基 · 第 5 课

功率与功率因数

前四课解决"电流电压是多少"，本课解决"它们在干多少活"——有功 P、无功 Q、视在功率 S 与功率三角形；功率因数 cosφ 为什么是电网的生命线指标，无功补偿为什么是供电局的日常业务。

预计 2 小时 5 个知识块 · 4 道例题 · 8 道练习 承接第 3、4 课阻抗三角形

?本课核心思想

直流电路里功率只有一个：P = UI，干净利落。交流电路里电压电流有相位差，功率随之"裂变"成三种——真做功的（有功）、来回搬运不消耗的（无功）、以及两者的"总规模"（视在功率）。理解这三兄弟的关键，是前几课反复出现的那个角 φ：

阻抗角 φ 同时就是功率角——cosφ = R/Z = UR/U = P/S，同一个角统治了阻抗、电压、功率三个相似三角形。学到这里你会发现：整个正弦稳态一章，其实只围绕一个角在转。
南网考点功率与功率因数是笔试高频计算题（求 P/Q/S/cosφ）+ 概念判断题（单位、符号、谁吃有功）双重考点，更是面试经典工程题（"为什么电网要补偿无功"）。供电局日常业务（无功补偿、力率电费）全建立在本课概念之上。

1三大功率：P、Q、S

设某负载两端电压有效值 U、流过电流有效值 I、相位差 φ（电压超前电流为正，感性）：

有功 P = UI cosφ（单位 W，瓦）　　无功 Q = UI sinφ（单位 var，乏）　　视在 S = UI（单位 VA，伏安）
  • 有功功率 P：真正转化为热/机械能做功的功率——只有电阻吃有功（P = I²R）。电费单上计费的就是它。
  • 无功功率 Q：电感建立磁场、电容建立电场时与电源周期性交换的功率——一个周期内平均为零、不消耗能量，但电流是真实流过的。感性负载 Q > 0（吸收），容性 Q < 0（发出）。
  • 视在功率 S：电压电流的"总规模"，代表设备必须具备的容量——发电机、变压器的铭牌额定值用的就是 kVA 而不是 kW（因为出厂时不知道你接什么 cosφ 的负载）。
单位陷阱P 用 W、Q 用 var、S 用 VA——三者量纲相同却绝不允许混用单位或直接相加。"变压器容量 100 kVA 能带 100 kW 负载吗？"是判断题常客（能，且仅当 cosφ = 1）。

2功率三角形与"三兄弟"的统一

P（横边）、Q（竖边）、S（斜边）构成直角三角形，P 与 S 的夹角正是 φ：

S² = P² + Q²　　cosφ = PS　　tanφ = QP

更妙的是它与前两课的三角形是相似三兄弟——阻抗三角形乘以 I 得电压三角形，再乘以 I 得功率三角形：

图 1 · 相似三兄弟（数据取自例 1）：阻抗 ×I → 电压，×I → 功率；cosφ = 3/5 = 60/100 = 1200/2000 = 0.6
记忆锚点：三个三角形的底边都是"电阻侧"（R、UR、P——做功的）、竖边都是"电抗侧"（X、UX、Q——交换的）、斜边都是"总量"（Z、U、S）。看到任何一个三角形，就能反推出另外两个。

3功率因数 cosφ：电网的生命线

cosφ = PS = R|Z|　　（0 ≤ cosφ ≤ 1）

物理意义：总容量中真正做功的比例。三种典型值：

负载cosφ含义
纯电阻（电炉、白炽灯）1全部容量做功，理想
纯电感 / 纯电容0全部容量用于能量交换，一个瓦都不做
实际感性负载（电动机、变压器）0.6 ~ 0.85既做功也吸收无功，需要补偿

为什么 cosφ 低是"罪"：输送同样的有功 P，电流 I = P/(U·cosφ) 与 cosφ 成反比——cosφ 越低，电流越大，而线路损耗 (∝ I²) 和设备容量占用 (∝ I) 随之暴涨。两宗罪：①线路损耗白白发热；②发电机、变压器容量被无功挤占。

考核挂钩：供电局对大工业用户按功率因数调整电费（力率电费）——cosφ 高于标准（一般 0.9）有电费奖励，低于则罚款。这就是企业主动装补偿电容的经济动力，也是"为什么电网要补偿无功"这道面试题的标准答案骨架。

4无功补偿：并联电容的魔法

感性负载需要无功来建磁场，过去全部由电网远程输送；现在在负载旁边并联电容——电容发出的无功（QC < 0）就地抵消电感吸收的无功，电网只需输送差额：

需补偿容量：QC = Q1 − Q2 = P (tanφ1 − tanφ2)
  • 为什么并联不串联：并联不影响负载两端的电压（负载工作状态完全不变）；串联电容会改变负载电压，设备没法正常工作；
  • 补偿后什么不变什么变：负载的 P、QL、电压、电流全都不变；变的是电网侧——总无功 ↓、总电流 ↓、线路损耗 ↓、释放的变压器容量 ↑；
  • 补到多少合适：一般到 0.9 ~ 0.95，不追 1——过补偿（电流变超前）同样有害，且补到 1 所需电容的成本收益急剧恶化；
  • 电容值的换算（50Hz 时）：QC = U²ωC → C = QC/(ωU²)。
面试高频"为什么要提高功率因数 / 怎么提高"的标准答案 = 知识 3 的两宗罪 + 本节"并联电容就地平衡"原理 + 补偿前后负载侧不变、电网侧减负的完整图景。把例 3 的数字算过一遍，面试时你就不是背概念而是讲工程。

5功率计算的实战武器库

计算 P、Q、S 的公式家族（都用有效值，无 √2）：

对象有功 P无功 Q视在 S
任意二端网络UI cosφUI sinφUI
电阻 RI²R = U²/R0= P
电感 L0I²XL = U²/XL= |Q|
电容 C0−I²XC（发出）= |Q|
等效阻抗 Z = R + jXI²RI²XI²|Z|
  • 双路验证是防错神器：整体用 UI cosφ，元件用 I²R——两条路必须一致（例 1 演示）；
  • 功率守恒：整个电路的总有功 = 各电阻消耗之和（电阻是唯一的 P 源）；总无功 = 感性 − 容性（代数和）；
  • 复功率（进阶，识记即可）：Ṡ = Ùİ*，实部 P、虚部 Q——第 1 课的复数在这里完成最后的闭环。

例例题精讲

例 1 · RL 串联的功率全计算（双路验证）

R = 3 Ω、XL = 4 Ω 串联，接 U = 100 V（有效值）电源。求 cosφ、P、Q、S。

  1. 先备好弹药物（第 3、4 课已练熟）：Z = 3 + j4 = 5∠53.13° Ω，İ = 20∠−53.13° A（有效值 20A，φ = 53.13°）；
  2. 路线一：整体公式—— cosφ = 0.6； P = UI cosφ = 100 × 20 × 0.6 = 1200 W； Q = UI sinφ = 100 × 20 × 0.8 = 1600 var； S = UI = 2000 VA；
  3. 路线二：元件公式—— P = I²R = 400 × 3 = 1200 W ✓； Q = I²XL = 400 × 4 = 1600 var ✓； S = I²|Z| = 400 × 5 = 2000 VA ✓；
  4. 自检：S² = P² + Q²？2000² = 1200² + 1600² = 4×10⁶ ✓（3-4-5 家族：1200-1600-2000）。
cosφ = 0.6（感性）；P = 1200 W，Q = 1600 var，S = 2000 VA

考场上强烈建议双路都算（整体一遍、I²R 一遍，30 秒的事）——功率题数字大，一步除错很难靠感觉发现，两条独立路径互相印证才稳。

例 2 · 读三角形：由 S 和 P 反推全family

某负载 S = 2000 VA、P = 1200 W。求 cosφ、φ、Q；若已知流过电流 20A，求阻抗。

  1. cosφ = P/S = 1200/2000 = 0.6，φ = 53.13°（电流滞后，感性）；
  2. Q = √(S² − P²) = √(2000² − 1200²) = 1600 var（正 = 感性）；
  3. 阻抗：|Z| = U/I，而 U = S/I = 2000/20 = 100 V，|Z| = 100/20 = 5 Ω； 再由 cosφ = R/|Z|：R = 0.6 × 5 = 3 Ω，X = 0.8 × 5 = 4 Ω → Z = 3 + j4 Ω。
cosφ = 0.6、φ = 53.13°、Q = 1600 var、Z = 3 + j4 Ω

注意解题的"逆向"灵活性：功率 → 三角形 → 阻抗，反着走也通。考试常给铭牌数据（kW、kVA、cosφ）让你反推电路参数或电流——同一套三角关系的不同起点而已。

例 3 · 无功补偿经典题：0.6 提到 0.8

感性负载 P = 1200 W、U = 100 V、cosφ₁ = 0.6。欲将功率因数提高到 cosφ₂ = 0.8，需并联多大电容（f = 50 Hz）？补偿前后线路电流各多少？

  1. 补偿前（例 1 的负载）：tanφ₁ = 4/3，Q₁ = P·tanφ₁ = 1200 × 4/3 = 1600 var； S₁ = 2000 VA，I₁ = S₁/U = 20 A；
  2. 补偿后：cosφ₂ = 0.8 → φ₂ = 36.87°，tanφ₂ = 3/4； Q₂ = P·tanφ₂ = 1200 × 0.75 = 900 var（P 不变——电容不消耗有功）；
  3. 需补偿容量：QC = Q₁ − Q₂ = 1600 − 900 = 700 var；
  4. 电容值：C = QC/(ωU²) = 700 / (314 × 100²) ≈ 222.9 μF；
  5. 补偿后电流：S₂ = √(P² + Q₂²) = √(1200² + 900²) = 1500 VA（3-4-5 家族 ×300），I₂ = 1500/100 = 15 A。
QC = 700 var，C ≈ 222.9 μF；线路电流 20 A → 15 A（降 25%）

三件事看清"补偿只救电网、不动负载"：负载侧的 P（1200W）、QL（1600var）、电压、电流完全没变；变的是电网侧——总无功从 1600 降到 900，电流从 20A 降到 15A，线路损耗（∝I²）直降 44%。若线路电阻 r = 0.5Ω，每年 8760 小时省下的线损电费就是一笔真金白银——这就是力率电费制度存在的原因。

例 4 · 无功的账本：电容怎样"吐"无功

RLC 串联电路（第 4 课例 1 的原班数据）：R = 3 Ω、XL = 8 Ω、XC = 4 Ω、I = 20 A、U = 100 V。算清全部功率账目。

  1. 有功账：只有电阻吃有功——P = I²R = 400 × 3 = 1200 W；
  2. 无功账（分开记）： 电感吸收：QL = I²XL = 400 × 8 = 3200 var； 电容发出：QC = −I²XC = −400 × 4 = −1600 var； 净无功：Q = 3200 − 1600 = 1600 var；
  3. 总账：S = UI = 2000 VA，cosφ = 1200/2000 = 0.6； 验证 Q：√(2000² − 1200²) = 1600 ✓
  4. 透视：L 要的 3200 var 无功里，一半（1600 var）由电容就地提供，电网只输送差额——串联电路内部的"迷你版无功补偿"。
P = 1200 W；QL = +3200 var，QC = −1600 var，净 Q = 1600 var；S = 2000 VA，cosφ = 0.6

把例 3 和例 4 放在一起看就彻底通透了：无功补偿的本质 = 让电容与电感互相交换能量、与电网只结算差额——串联电路里这是自动发生的（电压分配层面），工程上是人为并联电容实现的（电流层面）。当 XL 恰好等于 XC，净无功为零、cosφ = 1——这就是下一课的主角：谐振。

练练习（先做再看答案）

前 3 题概念、中间 3 题计算、后 2 题工程应用。功率题务必双路验证。

Q1P、Q、S 的单位配对与含义（概念）点击展开 ▾

有功 P —— 瓦（W）—— 真正做功/耗散；无功 Q —— 乏（var）—— 与电源周期交换、不消耗；视在 S —— 伏安（VA）—— 容量总规模（设备铭牌用 kVA）。

W / var / VA 三单位严格区分，量纲同但不混用不相加

经典判断题："100 kVA 变压器最多带 100 kW 负载"（√，当且仅当 cosφ = 1；cosφ = 0.8 时最多 80 kW）。

Q2S = 2000 VA、P = 1200 W，求 cosφ、φ、Q点击展开 ▾

cosφ = 1200/2000 = 0.6；φ = 53.13°（感性，电流滞后）；Q = √(2000² − 1200²) = 1600 var。

cosφ = 0.6，φ = 53.13°，Q = 1600 var

3-4-5 家族：1200-1600-2000。这个家族在功率题里出现率极高——见 cosφ = 0.6 直接反应 sinφ = 0.8、tanφ = 4/3。

Q3纯电阻、纯电感、纯电容三种元件的 P 与 Q（概念）点击展开 ▾

纯电阻：P = UI、Q = 0（全部做功，cosφ = 1）；纯电感：P = 0、Q = +UI（吸收无功，cosφ = 0）；纯电容：P = 0、Q = −UI（发出无功，cosφ = 0）。

电阻吃有功；电感吃无功（+）；电容发无功（−）——没有第三个吃有功的元件

"电感的 Q 为正、电容的 Q 为负"配合第 3 课"X = XL − XC"一起记——符号体系一以贯之。

Q4U = 220 V、I = 5 A、cosφ = 0.8（感性），求 P、Q、S点击展开 ▾

S = UI = 1100 VA；P = 1100 × 0.8 = 880 W；sinφ = 0.6，Q = 1100 × 0.6 = 660 var。

S = 1100 VA，P = 880 W，Q = 660 var

顺序讲究：先算 S = UI（不涉及 φ），再用 cosφ、sinφ 拆出 P 和 Q——比硬套 UIcosφ 少一次乘法错位的机会。

Q5负载阻抗 Z = 6 + j8 Ω，求功率因数及电路性质点击展开 ▾

|Z| = √(6² + 8²) = 10 Ω；cosφ = R/|Z| = 6/10 = 0.6，φ = 53.13°。X = +8 > 0 → 感性，电流滞后电压。

cosφ = 0.6，感性（电流滞后 53.13°）

cosφ = R/|Z| 是阻抗侧最快的算法——连电流都不用求。性质判断只看 X 的符号：正感性、负容性、零（X=0）纯阻性。

Q6并联电容补偿后，下列量如何变化？（负载 P、负载 Q_L、电网总 Q、总电流、线损）点击展开 ▾

负载 P 不变；负载自身无功 QL 不变（负载工作状态完全没变）；电网总 Q 减小；总电流 减小；线路损耗 减小。

"两不变三减小"——负载侧不变，电网侧减负

高频多选题/判断题："并联电容后负载电流减小"（×——减小的是电网总电流，负载自己的电流分毫不动）。

Q7P = 800 W、cosφ = 0.8、U = 100 V 的感性负载，全补偿（cosφ→1）需多大 QC？补偿后线路电流、负载电流各是多少？点击展开 ▾

补偿前线路上：I₁ = P/(Ucosφ) = 800/80 = 10 A；φ₁ = 36.87°，tanφ₁ = 0.75，Q₁ = P·tanφ₁ = 800 × 0.75 = 600 var；

全补偿需 QC = Q₁ = 600 var；补偿后线路电流 I₂ = P/U = 800/100 = 8 A（纯有功分量）；负载电流不变，仍为 10 A；电容支路电流 IC = QC/U = 600/100 = 6 A。

相量验证：负载电流 10∠−36.87° = 8 − j6（有功 8A + 无功 −6A）；电容电流 +j6 恰好抵消无功分量；总电流 = 8 − j6 + j6 = 8∠0° ✓

QC = 600 var；线路电流 10 A → 8 A，负载电流仍为 10 A（不变）

关键区分：补偿后变的是"线路电流"，不变的是"负载电流"——Q6"两不变三减小"的现场验证。若把两者混淆，会得出与 Q6 矛盾的结论。工程上不追求补到 1：电容投资随补偿量非线性增长，且过补偿有副作用——0.9~0.95 是性价比区间。

Q8工程视角：线路电阻 r = 1 Ω，负载 P = 1320 W、U = 220 V、cosφ = 0.6，补偿到 1 后线损降多少？点击展开 ▾

补偿前：I₁ = 1320/(220×0.6) = 10 A，线损 = I₁²r = 100 W； 补偿后：I₂ = P/U = 1320/220 = 6 A，线损 = 36 W； 省下 64 W——降幅 64%。

线损 100 W → 36 W，降 64%

注意"电压 220V"是负载端电压——补偿电容装在负载旁，输电线路（r）上流的电流变小，发热才降。这正是供电局对企业按 cosφ 奖惩电费的底层逻辑：你的低 cosφ 让电网白白发热。
