阶段 0 筑基 · 第 4 课

相量法解正弦稳态电路

收官之战：零件已齐（复数、相量、阻抗），本课组装机器——基尔霍夫定律的相量形式、阻抗串并联、分压分流、解题五步法。学完之后，正弦稳态电路在你的眼里就是"带角度的直流题"。

预计 2 小时 5 个知识块 · 4 道例题 · 8 道练习 承接第 1–3 课全部内容

?本课核心思想

直流电路你早已会解：欧姆定律、串并联等效、分压分流、KCL/KVL。本课的全部内容可以用一句话概括——

把电阻换成阻抗、把电压电流换成相量，直流电路的全套方法原封不动地平移到正弦稳态。唯一的新纪律只有一条：所有加减乘除都在复数域进行，模不能直接加减。
南网考点本课是所有正弦稳态计算题的总入口：南网笔试电路部分的计算题（求电流/电压/等效阻抗）十有八九走这条流程。掌握五步法 = 拿下计算题的框架分。

1KCL / KVL 的相量形式

基尔霍夫定律的物理本质（电荷守恒、能量守恒）与元件性质无关，对正弦稳态照样成立——只是"电压""电流"要换成相量：

KCL：ΣI = 0　　KVL：ΣU = 0
节点上各支路电流相量的代数和为零；回路中各段电压相量的代数和为零
高频陷阱"和为零"指复数（相量）和，不是有效值（模）之和为零！三条支路各 10A 汇入一个节点，总电流完全可以不是 30A 甚至不是 10A——例如 10∠0° + 10∠90° + 10∠180° = 10j ≠ 0。同理，串联电路中各元件电压有效值之和一般大于总电压（例 1 将亲眼见证）。

2阻抗的串并联：复数版的电阻玩法

公式形态与电阻串并联完全一致，只是 R 换成 Z、实数运算换成复数运算：

串联：Z = Z1 + Z2 + …　　并联：1Z = 1Z1 + 1Z2 + …
两个阻抗并联的捷径：Z = Z₁Z₂ / (Z₁ + Z₂) —— 对应电阻并联的"积除和"
  • 串联：阻抗代数式直接相加——实部归实部（R 累加），虚部归虚部（X 累加）。感性 (+j) 与容性 (−j) 自动抵消，这就是第 3 课"X = XL − XC"的来源；
  • 并联：倒数相加再倒回来。两个相同阻抗 Z 并联 = Z/2（模减半）——与电阻规律一致；
  • 分压串联的直觉：|Z| 越大的元件分到的电压模越大，但相位上各元件电压方向不同。

3分压与分流：相量版公式

分压：U1 = Z1Z1 + Z2 · U　　分流：I1 = Z2Z1 + Z2 · I
分压看"自己占总"；分流相反——"对方占总"（谁的阻碍大，谁分到的电流小）
使用纪律：公式里的每个量都是复数，代入时统一用极坐标最顺——模相乘除、角相加减，正是第 1 课练熟的乘除法。切忌"模套公式"：|Ù₁| ≠ |Z₁|/(|Z₁|+|Z₂|) × |Ù|，分母是复数和，不是模之和。

4参考相量与解题五步法

参考相量：人为设定的"零度基准"

相量的角度是相对的，解题时通常设一个参考相量（取 0°）让全题角度统一基准。选谁做参考有固定套路：

  • 串联电路选电流：所有元件电压与电流的相位差都是已知角度（0°、±90° 或 φ），相量图最好画；
  • 并联电路选电压：各支路电流相对电压的相位差都是已知角度；
  • 混联电路：从离电源最远的支路往回推，通常设末端电压或末端电流为参考。

五步法：标准流程走天下

①画相量模型
R→R　L→jωL　C→−j/ωC
②选参考相量
串联选 İ，并联选 Ù
③用直流全套方法
串并联等效 / 分压分流 / KCL·KVL
④解出待求相量
统一极坐标运算
⑤回瞬时值（若题目要求）
乘 √2 加 ωt

第 ① 步的换装表：电阻原样；电感变成 jωL（模 ωL、角 +90°）；电容变成 −j/ωC（模 1/ωC、角 −90°）。第 ③ 步就是你在初中物理就会的那套——这是本课最解放思想的一点。

5相量图法：用几何直觉验证代数

计算做完后，画一张相量图核对，是老电力人的习惯——很多错误（象限搞反、加减搞混）在图上一眼现形。常用几何事实就三条：

  • 两个相位差 90° 的相量合成：模按勾股定理，合成的角度在两者之间（两个相等且互差 90° 的相量合成 = 模 × √2，角度取中点）；
  • 两个反相（180°）的相量相减：模直接相减，方向跟随大者——电感电压与电容电压天然反相，所以 XL、XC 是"抵消"关系；
  • 串联电路的电压三角形：电阻电压沿电流方向，电抗电压垂直于电流，总电压是斜边——与阻抗三角形相似（第 3 课图 2 的亲戚）。

例例题精讲

例 1 · RLC 串联完整解题（五步法首秀）

R = 3 Ω、XL = 8 Ω、XC = 4 Ω 串联，电源电压 Ù = 100∠0° V（有效值相量）。求电流及各元件电压相量，验证 KVL。

  1. 相量模型：ZR = 3，ZL = j8，ZC = −j4；
  2. 串联求等效阻抗：Z = 3 + j8 − j4 = 3 + j4 = 5∠53.13° Ω（第 3 课例 2 的数字回来了）；
  3. 求电流：İ = Ù / Z = 100∠0° ÷ 5∠53.13° = 20∠−53.13° A；
  4. 求各元件电压（相量欧姆定律，逐个乘）： ÙR = 3 × 20∠−53.13° = 60∠−53.13° V； ÙL = j8 × 20∠−53.13° = 160∠36.87° V； ÙC = (−j4) × 20∠−53.13° = 80∠−143.13° V；
  5. KVL 验证：化为代数式相加—— 60∠−53.13° = 36 − j48；160∠36.87° = 128 + j96；80∠−143.13° = −64 − j48； 三者之和 = (36+128−64) + j(−48+96−48) = 100 + j0 = 100∠0° ✓
İ = 20∠−53.13° A；ÙR = 60∠−53.13° V，ÙL = 160∠36.87° V，ÙC = 80∠−143.13° V

注意"模不能加"的震撼现场：60 + 160 + 80 = 300 V，但总电压只有 100 V——电感电压 (160V) 甚至比电源电压 (100V) 还大！这在直流电路中不可能，在交流中完全正常（电容电压在相位上"帮着抵消"）。另外注意 ÙL 与 ÙC 相位差恰好 180°，纯反相——第 3 课预告的谐振现象就藏在这里。

例 2 · 并联电路与总电流合成

电源 Ù = 100∠0° V 同时加在两条并联支路上：支路 1 为纯电阻 R = 5 Ω，支路 2 为纯电感 XL = 5 Ω。求各支路电流、总电流和等效阻抗。

  1. 并联选电压为参考（本题 Ù 已是 0°，正合适）；
  2. 支路电流： İ1 = 100∠0° ÷ 5 = 20∠0° A； İ2 = 100∠0° ÷ 5∠90° = 20∠−90° A（电感支路电流滞后 90°）；
  3. KCL 求总电流（复数相加）：İ = 20∠0° + 20∠−90° = 20 − j20 = 20√2∠−45° ≈ 28.28∠−45° A；
  4. 等效阻抗：Z = Ù / İ = 100∠0° ÷ (20√2∠−45°) = 3.54∠45° = 2.5 + j2.5 Ω（验证：两条 5Ω 支路并联，等效模 3.54Ω 小于单支路 5Ω，合理）。
İ1 = 20∠0° A，İ2 = 20∠−90° A，İ ≈ 28.28∠−45° A，Zeq = 2.5 + j2.5 Ω

两个相位差 90° 的等模相量合成：模 × √2、角度取中点——第 2 课例 4 的规律在这里实战兑现。总电流 (28.28A) 大于任一支路电流 (20A) 是正常的（两条支路都在送电流）；但若支路相位相反，总电流反而可能小于任一支路——并联谐振的伏笔。

例 3 · 分压公式：一道题的两种打开方式

Z1 = j4 Ω（电感）与 Z2 = 3 Ω（电阻）串联接 Ù = 100∠0° V。求 Z2 上的电压。

  1. 方法一：分压公式： Ù2 = [3 / (3 + j4)] × 100∠0°；分母 3 + j4 = 5∠53.13°； 3 ÷ 5∠53.13° = 0.6∠−53.13°；Ù2 = 0.6∠−53.13° × 100∠0° = 60∠−53.13° V；
  2. 方法二：先总后分： İ = Ù/Z = 100∠0° ÷ 5∠53.13° = 20∠−53.13° A； Ù2 = R × İ = 3 × 20∠−53.13° = 60∠−53.13° V ✓ 两条路殊途同归。
Ù2 = 60∠−53.13° V　（顺便：Ù1 = j4 × 20∠−53.13° = 80∠36.87° V，验证 60∠−53.13° + 80∠36.87° = 100∠0° ✓）

这正是第 3 课例 3 的同一道题换了个问法——数据完全复现。体会"分压公式"与"先求电流再算电压"是同一件事的两种包装，考场上哪种顺手用哪种。分压公式一步到位快，但先求电流更不容易错（中间量可复核）。

例 4 · 相量图法：几何验证一道计算

用相量图重新核验例 1 的结果（R=3Ω、XL=8Ω、XC=4Ω、İ = 20∠−53.13° A、Ù = 100∠0° V）。

  1. 换参考系：以电流为参考（İ = 20∠0°，全体系逆时针转 53.13°，结论等价）；
  2. 画三个电压：ÙR = 60V 沿电流方向（0°）；ÙL = 160V 垂直向上（+90°）；ÙC = 80V 垂直向下（−90°）；
  3. 几何合成：ÙL 与 ÙC 反向，先抵消成净电抗电压 160 − 80 = 80V 向上；再与 ÙR = 60V 勾股合成：|Ù| = √(60² + 80²) = 100V ✓，相位超前电流 arctan(80/60) = 53.13° ✓
几何结果与复数计算完全一致：100V、超前 53.13°

相量图法三秒出模值（垂直分量先抵消、再勾股），适合考场验算。把"电压三角形"（本例）与"阻抗三角形"（第 3 课）放在一起看：60V↔3Ω、80V↔4Ω、100V↔5Ω——两个三角形相似，比例系数正是电流 20A。这就是"串联电路电压三角形与阻抗三角形相似"定理的现场演示。

练练习（先做再看答案）

前 3 题概念、中间 3 题公式运用、后 2 题完整解题。完整题请严格走五步法。

Q1KCL 的相量形式说"节点电流之和为零"，对此的正确理解是？点击展开 ▾

流入节点各电流相量（复数）的代数和为零——不是有效值（模）之和为零。相位不同的电流会互相"错开"，模可以直接相加的情况只有各电流同相位时才成立。

Σİ = 0 是复数和为零；模一般不能直接相加

对应的经典判断题："三条支路各流入 10A，总流出必为 30A"（×）——支路相位关系未知。

Q2Z₁ = 3 + j4 与 Z₂ = 5 − j10 串联，求等效阻抗点击展开 ▾

串联直接代数式相加：实部 3+5=8，虚部 j4 − j10 = −j6。

Z = 8 − j6 = 10∠−36.87° Ω（容性）

串联合并是唯一"可以直接把实部虚部分开加"的运算——这也解释了为什么串联电路总是先算 X = XL − XC。

Q3两个 Z = j10 Ω 并联，等效阻抗是多少？若串联呢？点击展开 ▾

两个相同阻抗并联 = Z/2：j10 ∥ j10 = j5 Ω；串联 = 2Z：j10 + j10 = j20 Ω。

并联 j5 Ω；串联 j20 Ω

与电阻规律一致：并联减半、串联翻倍。但一般情况（不同阻抗）必须走复数运算——积除和公式 Z₁Z₂/(Z₁+Z₂)。

Q4Z₁ = 6 Ω 与 Z₂ = j8 Ω 串联接 Ù = 100∠0° V，求 Z₁ 上的电压点击展开 ▾

分压公式：Ù₁ = [6/(6+j8)] × 100∠0°；6+j8 = 10∠53.13°；6 ÷ 10∠53.13° = 0.6∠−53.13°。

Ù₁ = 60∠−53.13° V

易错算法：|Z₁|/(|Z₁|+|Z₂|) × 100 = 6/14 × 100 ≈ 43V（× 错）——分母必须先做复数和 6+j8=10∠53.13°，模是 10 不是 14。

Q5串联电路解题通常选什么做参考相量？并联呢？为什么？点击展开 ▾

串联选电流（各元件电压与电流的夹角都是已知角 0°/±90°/φ，相量图好画好算）；并联选电压（各支路电流与电压的夹角都是已知角）。

串联选 İ，并联选 Ù

混联电路从最远离电源的支路往电源方向推，参考相量通常设在末端。

Q6R = 4 Ω、XL = 3 Ω 串联，接 Ù = 100∠0° V。求电流相量与瞬时值（f = 50 Hz）点击展开 ▾

Z = 4 + j3 = 5∠36.87° Ω；İ = 100∠0° ÷ 5∠36.87° = 20∠−36.87° A；瞬时值幅值 20√2 ≈ 28.3A，ω = 314。

İ = 20∠−36.87° A；i(t) ≈ 28.3 sin(314t − 36.87°) A

五步法完整链路：相量模型 → 参考相量（Ù 已给定）→ 等效阻抗 → 除法 → 瞬时值。第 3 课练的是零件，本课练的是装配。

Q7串联电路中 ÙL = 60∠90° V、ÙC = 24∠−90° V、ÙR = 48∠0° V（以电流为参考）。求总电压点击展开 ▾

电抗电压反相先抵消：净电抗电压 = 60 − 24 = 36V（向上）；与电阻电压 48V 勾股合成：|Ù| = √(48² + 36²) = 60 V，角度 arctan(36/48) = 36.87°。

Ù = 60∠36.87° V

相量图法三步出结果：反相抵消 → 垂直勾股 → 读角度。验证用复数：j60 − j24 + 48 = 48 + j36 = 60∠36.87° ✓（3-4-5 三角形：48-36-60）。

Q8支路 1 为 R = 5 Ω，支路 2 为 XC = 5 Ω（纯电容），两支路并联接 Ù = 100∠0° V。求总电流点击展开 ▾

İ₁ = 100∠0° ÷ 5 = 20∠0° A；İ₂ = 100∠0° ÷ 5∠−90° = 20∠90° A（电容支路电流超前 90°）；İ = 20 + j20 = 20√2∠45°。

İ ≈ 28.28∠45° A（容性电路，电流超前电压 45°）

与例 2 完全镜像：电感换电容，−45° 变 +45°。90° 合成 √2 放大、角度取中点——把这对题放在一起记，考场直接报答案。
